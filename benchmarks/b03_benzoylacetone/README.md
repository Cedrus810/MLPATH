# b03 — 苯甲酰丙酮（1-苯基-1,3-丁二酮）的螯合烯醇

C10H10O2，22 原子，中性闭壳。反应是螯合环内的分子内质子转移 A ⇌ B ——
与 b01/b02 同一化学，不对称端基换成苯基/甲基。

**这一格打的轴**：芳香图 + 螯合 + 竞争异构体。它是 b00–b03 那条轴的最后一格；
再加一个装饰更多的 β-二酮买不到新信息（见 `../TAXONOMY.md` A 组）。

## 第 2 件：几何门已建

`preflight.py`。**它拦的是可达性，不是身份** —— 这个区分是 P3 探针那一轮最贵的教训。

实测（本轮，ETKDG 种子 `0xF00D`）：

| | closed (< 3.0 Å) | r(O···O) 范围 |
| --- | --- | --- |
| Z（本基准要求） | **169 / 300** | 2.328 – 4.073 Å |
| E（必须被拦） | **0 / 300** | 4.396 – 4.559 Å |
| 源结构 `p3_A_chelated` | — | **2.5193 Å** |
| 源结构 `p3_A_source` | — | **2.5287 Å** |

与 `P3_BENZOYLACETONE_PROBES.md` §1.1 原记录（151/300、2.615–4.223、4.334–4.667）
数值略有出入，是 ETKDG 种子与版本不同；**结论逐条一致**，E 仍然是 0/300。

**为什么必须单独有这道门。** 探针那一轮用 E 建的基准返回了一整套自洽、全绿的数字：
两端都是真极小、`chemical_key` 不同、`graph_hash` 不同、`event_key` 是干净的单质子事件、
ΔE = −128 meV。**每一个都是对的，而反应仍然不可能。**

身份层拦不住它，原因不是"E 和 Z 的图一样"——`locked_bond_parity` 记着那条 C=C 的
配置，两个 key 本来就不同（Z `8710064d12ce6a5a`，E `909db28462d72d1b`）。
真正的原因是**身份层按设计不回答可达性**：在 E 的图上，A→B 质子转移同样是一条合法的
跨节点反应，键差、事件键、方向商全都成立。它看不到"r(O···O) = 4.29 Å，质子过不去"。

所以这不是第二道身份检查，它回答的是另一个问题 —— 这正是它必须独立存在的理由。

## 第 3 件：OFF24 上的单侧连接失败 —— 记为该势能面的属性

**事实**（`docs/HANDOFF.md` §5）：双侧连接只在 POLAR-1 上拿到，
`connects_two_nodes = True`，鞍点两侧分别落回 A（`8710064d…`）和 B（`b1a4338a…`）。
在 MACE-OFF24 上 `side +1` 到不了 A，`quench_steps = 5000` 也不行 —— **不是预算问题**。

**跨模型对照指向那个近自由甲基转子**：OFF24 在 A 处的最软内坐标模 `0.00262`，
POLAR-1 是 `0.00470`，软将近一倍。

**收口方式：记为 MACE-OFF24 这张势能面的已知限制，不继续追。** 三条理由：

1. **它是势能面的属性，不是方法的。** 同一份代码在 POLAR-1 上拿到了完整的双侧连接。
2. **但仍非隔离归因** —— 两个模型差的不只是那一个数。这一句必须跟着结论走，
   任何引用都不得省略。
3. **P4 起统一用 POLAR-1**（用户 2026-09-04），所以这条限制不会传导到后面的格子。
   P0–P3 冻结在 OFF24 上、不重跑，因此它就停在这里。

**要重开这条，需要的是隔离实验**：在同一个模型上单独改那个转子的软度，
看双侧连接是否恢复。那不是本轮的范围。
