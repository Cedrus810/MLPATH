# 卡宾 + 烯烃的 ambimodal (2+1)/(4+1) 体系 —— b08 / b09 的来源与 POLAR-1 预检

来源：Tongkun Wang, Xiao-Song Xue, *J. Am. Chem. Soc.* 2026, 148, 8723–8735（doi 10.1021/jacs.5c13906）。
正文 `../../ja5c13906.pdf`，SI `../../ja5c13906_si_001 (1).pdf`。
DFT：驻点 M06-2X/def2-TZVP-SMD(PhCl 或 toluene)；QCMD M06-2X/def2-SVP-SMD，Progdyn，298 K（OMe 384 K），1 fs，500 fs。

编号（用户 2026-10-08 定，见 `../MANIFEST.md`）：
- **b08** = :CCl₂ + 1,2-双(亚甲基)环庚烷（7C），26 原子。从反应物出发两个鞍点：TS-CCl₂（ambimodal）与 TS-CCl₂-C4（只到 (2+1)）。
- **b09** = 二甲氧基卡宾 + 1-环己烯-1-甲醛（6O），29 原子。ambimodal TS-2OMe，竞争鞍点 TS-2OMe-cis、TS-2OMe-C2，重排 TS-2OMe-2。

## 2026-10-08 预检结果（183，POLAR-1，气相）

**DFT 几何上（`results/2026-10-08/all/`）**：所有 DFT 鞍点在 POLAR-1 上都不是驻点（最大力 0.2–0.7 eV/Å），
虚频只作参考。产物能量和 DFT 接近（7C-(2+1) / (4+1)：−71.0 / −100.3 对 −73.8 / −101.5 kcal/mol，电子能，DFT 含 SMD）。

**POLAR-1 上重优化之后（`results/2026-10-08/opt_analysis.log`）**：

| TS-CCl₂ | CONVERGED | **−230**（一个） | −158 | 1.02 | 2.16 / 2.73（DFT 图 5B：2.18 / 2.72） | −3.54 |

读法：
- **b09：四个鞍点在 POLAR-1 上都在**：各一个虚频，离 DFT 几何 0.07–0.18 Å，两两 RMSD ≥ 0.57 Å（互不相同）。
  能量顺序 TS-2OMe < -cis < -C2 与 DFT 的 G 顺序一致（DFT：+1.6、+14.9 kcal/mol；POLAR-1 电子能：+3.8、+16.0）。
  (2+1)→(4+1) 重排势垒：POLAR-1 电子能 29.7（0.70 − (−28.97)），DFT ΔG 29.8。
- **b08：上面这张表的鞍点对应关系标反了（10-08 当天更正，见下一节）**。表里"TS-CCl₂"那一行是从 DFT TS-CCl₂ 出发得到的
  POLAR-1 鞍点，但它对应的其实是 DFT 的 **TS-CCl₂-C4**。
- 两个"Dimethoxycarbene"条目（SI 里 G 不同）在 POLAR-1 上优化到同一结构，带一个 −81 cm⁻¹ 虚频（GAU 判据下的软模，未细查）。

## b08 鞍点身份核对（10-08，`scan_b08.py`、`classify_b08.py`）

两个 DFT 鞍点很接近：对称感知 RMSD 0.75 Å（Cl 互换、镜像都算在内），都攻击 C20=C16，成键距离几乎相同；
区别在卡宾朝向。C23–C17（C17 是另一端 CH₂，论文的 C4）在 TS-CCl₂（ambimodal，朝向 C4）里是 3.73 Å，
在 TS-CCl₂-C4（背向 C4）里是 4.23 Å。所以"有一个虚频"不够，要用朝向标记加上到**两个** DFT 鞍点的 RMSD 来定身份。

| POLAR-1 候选（起点） | 状态 | 虚频 (cm⁻¹) | C23–C20 / C23–C16 / C23–C17 (Å) | RMSD 到 DFT TS-CCl₂ / TS-CCl₂-C4 (Å) | 判为 |
| --- | --- | --- | --- | --- | --- |
| 从 DFT TS-CCl₂ | CONVERGED | **−230** | 2.160 / 2.729 / 4.099 | 0.971 / **0.486** | **TS-CCl₂-C4 的对应鞍点** |
| 从 DFT TS-CCl₂-C4 | CONVERGED | −4 | 2.932 / 3.194 / 4.864 | 0.856 / 0.226 | 背向 C4 的松散区（近乎平坦） |
| 从扫描 proximal d=2.5、2.6 | CONVERGED | **无**（极小） | 2.985 / 3.209 / 4.082 | 0.241 / 0.831 | 朝向 C4 的反应前复合物 |

约束扫描（`results/2026-10-08/scan_b08.log`，C23–C20 从 3.0 拉到 1.9 Å，其余弛豫）：朝向 C4 的那一支能量一路升到 d=2.5 Å，
到 2.4 Å 时卡宾转到背向 C4，能量下降；背向那一支在 2.3 Å 处跳到同一条路径。d ≤ 2.2 Å 两支完全重合。

**结论（POLAR-1，气相，未定论）**：找到的唯一一阶鞍点是 **TS-CCl₂-C4 的对应点**；DFT 上那个 ambimodal 的
**TS-CCl₂ 在 POLAR-1 上没有找到**。朝向 C4 的那一侧只找到一个反应前复合物（极小），靠近之后卡宾会转到背向 C4。
一共试了四次：从两个 DFT 几何各做一次 TS 优化、一次约束扫描、从扫描帧做两次 TS 优化。没找到不等于不存在。
DFT 上两个鞍点电子能只差 0.13 kcal/mol，DFT 含溶剂、这里是气相。
**后果**：如果 POLAR-1 上没有 ambimodal 的 TS-CCl₂，b08 在这个势能面上的 (4+1) 通道是否还能到达，只能靠动力学去看。
"两个鞍点"和"分岔"这两个问题在 b08 上都不一定成立。

## b09 鞍点身份核对（10-08，`classify_b09.py`）

同 b08 的做法：每个 POLAR-1 鞍点和**全部四个** DFT 鞍点比较，不按起点命名。只算重原子 RMSD（甲基转动会互换 H），考虑镜像。
标记：卡宾碳到两个环烯碳（Ca 带醛基，Cb 是相邻的烯 CH）和到醛氧（(4+1) 生成 O–C 键）的距离。
DFT 四个鞍点彼此的重原子 RMSD 为 0.48–0.80 Å，这是区分尺度。

| POLAR-1 鞍点（起点） | 虚频 (cm⁻¹) | C:–Ca / C:–Cb / C:–O_ald (Å) | DFT 同一鞍点的标记 | 到对应 DFT 鞍点的 RMSD (Å) | 到其余三个的 RMSD (Å) |
| --- | --- | --- | --- | --- | --- |
| TS-2OMe | −492 | 2.678 / 1.979 / 3.220 | 2.676 / 2.038 / 3.303 | **0.066** | 0.49–0.71 |
| TS-2OMe-cis | −539 | 2.526 / 1.898 / 4.108 | 2.617 / 1.951 / 4.301 | **0.111** | 0.47–0.79 |
| TS-2OMe-C2 | −547 | 1.819 / 2.270 / 3.161 | 1.814 / 2.317 / 3.266 | **0.051** | 0.68–0.77 |
| TS-2OMe-2 | −106 | 2.191 / 1.465 / 2.786 | 2.294 / 1.474 / 2.840 | **0.127** | 0.51–0.81 |

**结论**：四个 POLAR-1 鞍点和四个 DFT 鞍点一一对应。每个到"自己"的 RMSD 0.05–0.13 Å，到其他的都在 0.46 Å 以上，
POLAR-1 鞍点彼此之间 0.48–0.79 Å，没有两个收敛到同一点。TS-2OMe 与 -cis 的差别在醛氧朝向（C:–O_ald 3.2 对 4.1 Å），
-cis 那一侧醛氧够不到卡宾碳，所以只能走 (2+1)；-C2 是攻击另一个烯碳（C:–Ca 1.82 Å）。
b09 在 POLAR-1 上保留了 DFT 的多鞍点结构，可以作为多鞍点参照的候选。

**未做**：IRC / 双侧下降核对连接；b08 TS-CCl₂-C4 的进一步搜索（换起点、收紧判据、沿成键距离扫描）；
QM 单点对照（同几何比较 POLAR-1 与 DFT）；b09 的 DFT 电子能对照（SI 表里没有二甲氧基卡宾的 E）。
