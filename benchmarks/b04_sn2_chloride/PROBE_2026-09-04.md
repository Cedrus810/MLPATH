### ② `collateral_bond_A = 0.05 Å` —— 9/64 次拒绝，但**不是**门与化学冲突

> **2026-09-04 更正。** 本节初稿断言"门与重原子反应坐标按构造冲突"。**该断言不成立。**
> `perturbations.collateral_metrics`（`src/prrs/perturbations.py:205`）**已经排除当前 probe
> 的目标键**：
>
> ```python
> target_bond = {indices[0], indices[1]} if kind == "bond" else None
> for a, b in sorted(graph.edges):
>     if target_bond == {a, b}:
>         continue
> ```
>
> 所以被驱动的那根 C–Cl 从来就不受这个门约束。`stretch [0,1]` 那次被拒，
> 超限的是**附带的 C–H**，变化 **0.0502946 Å** —— 超出阈值 **0.6%**。
>
> 现有记录能证明的只有"**附带形变触发了门**"。它**不能**证明门与 SN2 冲突，
> 也不能用"SN2 本来就要动两根 C–Cl"事后把它们都算成已声明的驱动键 ——
> 搜索并没有声明第二根。

```
compress [2,5] amp=1.0   拖动 C–H 键 0.355 A
compress [4,5] amp=1.0   拖动 C–H 键 0.355 A
compress [1,3] amp=1.0   拖动 C–H 键 0.356 A
compress [1,4] amp=1.0   拖动 C–H 键 0.355 A
（同样四对在 amp=0.6 各一次，0.135–0.136 A）
stretch  [0,1] amp=0.6   拖动 C–H 键 0.050 A   ← 驱动反应的那个探针也被拒过
```

那个 0.05 的 `RATIONALE` 是在质子转移上量的，那里**不希望任何共价键被拉长**。
**SN2 的反应坐标本身就是重原子键的伸缩** —— 门和化学直接冲突。

最后一行尤其说明问题：`stretch [0,1]` 在 0.6 Å 被拒、在 1.0 Å 通过，
所以这个门**不是单调地越大越拒**，它取决于内坐标位移怎么被实现成笛卡尔位移。

### ③ 幅度阶梯没有形成 bracket —— **原因已更正（2026-09-05）**

> **本节初稿的解释是错的。** 我写的是"只有最高一级 1.0 反应，没有下一级可比"。
> 落盘数据不支持它：
>
> ```
> 0.1  completed → m0000   返回
> 0.3  completed → m0000   返回
> 0.6  rejected  ← collateral_bond      ← 空洞
> 1.0  completed → m0001   离开
> ```
>
> 细化只比较**相邻**样本（`search.py:1361`），所以三对是 (0.1,0.3)(0.3,0.6)(0.6,1.0)：
> 第一对两个都返回；后两对里 0.6 是拒绝点，**既不算返回也不算离开**。
>
> **真正的原因是那个 collateral 拒绝punched 出的空洞，隔断了唯一有效的"返回→离开"对 (0.3, 1.0)。**
> 若 0.6 有效返回，现有实现就能与 1.0 成 bracket，不需要加档也不需要改阶梯。
>
> **所以次序是：先修扰动交付（②），再评估是否还需要动扫描策略。**
> 它与能量上限（①）是不同的控制路径，但与 collateral 拒绝**不是独立问题**。
>
> 后续若仍有缺测区间，扫描要显式区分**返回 / 离开 / 被阻断 / 未知** ——
> 不得把拒绝当返回，也不得无记录地跳过。

### 附：collateral 的诊断已完成（2026-09-04）

**是位移实现，不是必要耦合。** 在 b04 输入上把 C–Cl 拉 0.600 Å：

```
C  移动 0.4482 Å      Cl 移动 0.1518 Å      三个 H 移动 0.0000 Å
每根 C–H 缩短 0.0628 Å
反事实：CH3 跟着 C 刚体平移 → C–H 变化 0.000000 Å
```

`internal.displace` 的步长是 `gradient / masses`，而 bond 的梯度**只在那两个原子上非零**，
所以其余原子原地不动，碳从自己的氢里走出去。
**torsion 已经避开了这个** —— `rotate_fragment` 移动整个刚体片段，
docstring 明说"preserves every bond length and bond angle exactly"。**bond 没有等价物。**

契约已钉：`test_the_collateral_gate_exempts_the_driven_bond_and_still_refuses_damage`
—— 被驱动的键豁免、其余键的损伤仍然拒绝。
改位移实现、引入通用复合驱动、或修订阈值，三条路都必须保住这两半。

**能量上限与前两条是不同的控制路径；bracket 与 collateral 不是独立问题**（见 ③ 的更正）。

1. **能量区域上限。** 它定义搜索被允许看的范围，不是预算。要改必须**事先**说明
   依据、适用范围与停止条件。从一次触顶反推数值是无效的。
2. **附带形变。** 门已经排除目标键，所以先要回答的是一个诊断问题：
   那 0.0503 Å 的 C–H 形变**来自位移实现，还是必要耦合**？
   复现这次位移就能判。在此之前先钉一条测试
   ——「目标键允许变化、非目标键损伤仍拒绝」——
   然后才决定是改位移算法、引入通用复合驱动支持、还是修订阈值。
3. **幅度阶梯没有形成 bracket。** 20 条扫描 `brackets=0`。
   **提高能量上限替代不了它**，这是独立的一条。
4. **每个决定按名记录**（§2 的"干预必须分别命名"），否则下一轮的改进归不到具体某一项。
