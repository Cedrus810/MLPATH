## 1. 两项比较（沿用暂停点，补足操作定义）

### 1.1 发现比较

| 臂 | 方法 | 输入与约束 |
| --- | --- | --- |
| D0 | 当前 PRRS 提案与响应流程 | 当前行为另存实现身份；同样接收共享 L0 起点 |
| D1 | 方案 B：共享姿态库 + 现有 pulse | pulse 的方向、幅度、交付时长、自由响应参数跑前冻结 |
| D2 | 方案 A：共享姿态库 + 通用意图 + 约束松弛分级 | 先便宜响应，后升级；MD 放后面 |
| DB | 外部鞍点搜索基线：Dimer / ART | 从同一 L0 集合及通用扰动种子出发，局部搜索后做两侧下降 |

共同固定 PES、电子态、L0 输入、认证规则、实际模型 forward 总上限、资源条件及重复设计。各臂独立冷启动，允许臂内按冻结规则缓存；不借用其他臂的结果、参考鞍点或 oracle 缓存。

**建议 DB 首轮选一种实现（优先核对现有环境中的 ASE Dimer）；若同时比较 ART，命名 DB-D / DB-A，分别完整付预算，不能在一个 DB 内事后取最好结果。** 初始方向来自冻结的随机/结构规则，不用参考负模；最低模跟随过程与最终完整 Hessian 认证分开。ASE 的方法依据见[官方 Dimer 文档](https://docs.ase-lib.org/ase/dimer.html)，本稿未验证本地实现能力或速度。

D0 在本比较中意为“现有搜索策略 + 共同起点”，不是历史 b09 单起点批的复现。D0 的既有 trial 上限另记；若它先耗尽该上限，报告停止原因，不能把剩余 forward 预算当作已花完。新发现比较是完整策略比较：D2−D1 同时包含探针和调度变化，不能单凭它宣称约束松弛的单因素因果收益。

当前 `search.py` 对输入先调用 `relax_source` 再注册来源；共同 L0 指共同输入，不意味着预处理后四臂仍在同一坐标。各臂保存输入→实际提案起点及其费用，D0 仍保留现有预处理。若需只比较交付器本身，另冻共同合格微态上的消融，不为保姿态而静默跳过 D0 的来源处理。

**R8（搜索时窗语义，[DECISIONS_PENDING](DECISIONS_PENDING.md) R8）：** 自由响应时窗 t_free 是 D0/D1 及 D2 的 L3 MD 的臂定义的一部分，跑前冻结并写入 manifest。v1 建议按 R8 选项 (c)：不改判定规则，报告声明“发现了什么”条件于该 t_free；C2 是静态认证，不随时窗变。用户另行裁决 R8 后同步修订本条。

证据等级按下表保存，同时保留证据来源：

| 等级 | 需要的证据 | 用途 |
| --- | --- | --- |
| 候选 | 几何/路径响应或局部爬鞍点初猜 | 进入精修；不进入召回分子 |
| C1 观测连接 | 实际执行的交付/响应/释放过程，端点通过极小与身份核验 | 单报观测连接及其来源；不等于自由 MD、静态鞍点或速率证据 |
| C2 鞍点认证连接 | 无偏 PES 上驻点收敛、内部恰一显著负模、两侧下降到达经确认的端点，事件与身份闭合 | 发现比较主评分 |

DB 可直接产生 C2，不要求先有 C1。约束扫描、pulse 强制段、释放淬火和自由 MD 分别记录；“连接”不能抹掉其干预条件。局部负曲率、约束能量峰、NEB 成功状态或 committor 接近 0.5 都不能独立升级为 C2。

未确认来源盆地的原始摆放姿态只支持“该受控初态到达这个端点”的响应记录，不单独构成盆地 C1；须能把准备来源、事件与已确认盆地关联后才标 C1。C2 的两侧端点必须独立确认，不依赖这种初态归属假设。

每体系冻结有限参照集合 S。主结果为独立鞍点召回率 R(B)，以及各参照项的首次 C2 命中成本；另报化学连接覆盖、C1、参照外新 C2、重复、错误接受与未决。评分定义见 §4。同端点多个鞍点分别计数；退化反应允许自环，不能要求两个不同化学节点。

### 1.2 选择比较

冻结同一原始候选池 P，再比较随机 K、最低能量 K、简单几何多样性、现行 PARS、ALG-02/11/15/16 修订后 PARS；mature A1 后续作为独立臂。各臂独立精修，预算包含端点优化/Hessian、NEB/CI、驻点和连接验证及失败；K 只是候选数上限，不代表成本相等。

沿用[解析双鞍点台](../benchmarks/pars_two_saddles/README.md)的冻结做法：**池、选择规则/顺序先保存，之后才做全池 oracle；臂内真正冷算，不能回放 oracle 的答案或成本。** 现有台的[原协议](../benchmarks/pars_two_saddles/protocol.json)保持原样，分子扩展另立协议，不照搬其外场刚体处理、数值阈值或 6000 force 上限。

建议按预定来源配额取发现比较的原始产出，包含未认证、低分、重复、失败初猜和不同路线；取池不按参考命中筛选。来源臂、批次、阶段、截断情况必须可追溯。池中用于选择的能量/几何特征必须已在候选生成阶段获得，新增特征求值付选择臂预算；不能偷用 oracle 精修后势垒。所有臂获得相同允许字段。

全池 oracle 定义“池中可认证鞍点集合”S_P。主结果为臂在预算内保住的 |H∩S_P| / |S_P|，另报 |S_P∩S| / |S|，将输入池覆盖与选择保留分开。如果 |S_P|=0，保留率为不适用，不填 0 或 100%。若 oracle 有未决，S_P 只是已确认下界，报告未决数，不能声称全池真实保留率已经确定。oracle 预算不足时按预先规则缩小并重新冻结池，或保留“不完整 oracle”结论，不静默丢掉困难项。

选择收益是条件于候选池的结论；发现成本单列，端到端收益再加回来源成本。分析用的外部漏失抽审不回灌选择器；若某臂包含救援升级，救援必须是跑前冻结策略，并计入该臂预算。

## 2. 成本账本（ALG-08）

### 2.1 主预算与辅助计量

建议首轮同一体系、同一模型、同一设备/精度下，**一个结构在一个模型成员上真正发起一次 forward 记 1 个主预算单位**。未发起的请求记 0；发起后异常或被拒的计算仍记 1 并标失败。能量与力共用一次 forward 只记 1；二次真实计算另记。committee 的每个成员分别计数。

首轮建议关闭跨候选 batching。若后续启用，一批 m 个结构、c 个成员记 m×c 个结构求值单位，同时保存真实模型调用数及 batch size，避免“一批算一次”的口径套利。另存 calculator 请求数、命中缓存数、能量/力/HVP/Hessian 类型、自动微分次数和 CPU/GPU 时间。解析台使用其外部势能/力计数器，不能把解析 force 次数混成 POLAR-1 forward 或跨 PES 比成本。

Hessian 有限差分中的每个扰动求值和负模交叉检查全部入账。复用计算图做高阶导数可能没有新 forward，但 backward、内存和设备耗时仍单列。**同 forward 只是相同模型求值预算，不保证相同时间**；时间结论必须同时给设备完成时间和墙钟，不能把 GPU 异步提交耗时当计算完成时间。

| 成本类别 | 包含 | 归属 |
| --- | --- | --- |
| 共同准备 P | 通用构象/姿态库制作、共同输入资格检查与已有特征 | 共享一份真实总账；每臂有效预算加同一份 P |
| 臂内 A | 谱提案、L1/L2、pulse/MD、quench、polish、Hessian、爬鞍点、下降、NEB/CI、shoot、去重所需新求值 | 发现臂总预算，失败/重算不豁免 |
| 参照 R | 参照驻点、连接、身份/数值认证及候选筛选 | 评分准备，不能被搜索免费访问 |
| oracle O | 全池核验、额外外部抽审 | 选择评分准备；不可回放给各选择臂 |
| 独立 QM Q | QM 重优化、频率、IRC/下降及失败 | 科学模型核验，按 QM 调用/时间另账 |

一个求值只归一个执行成本项，多个证据引用它不重复收费。参考匹配通常只读几何；若匹配需要新的 PES 计算，按臂内认证收费。共同准备只可来自冻结的通用规则；某臂专用谱、特征或初猜属于 A，不能移动到 P。报告项目实际总支出 P+ΣA+R+O+Q，以及每臂用于比较的 P+A；跨不同体系不直接相加 forward 后排序。

### 2.2 认证预算与曲线时间

建议发现总预算 B_A 内事先保留搜索和 C2 认证子额度；各臂额度规则相同，具体比例用零号成本测量确定。每个候选完整精修有硬上限；重试、换初猜与补两侧下降均在同一总预算内。备用候选按冻结队列推进，不能只统计成功任务成本。

首次命中成本是**该臂从开始到 C2 证据闭合时的累计 A 支出**，包含期间其他候选和失败。若第 800 次求值出现候选、到第 1300 次才完成 C2，则 R(1000) 不含它。总预算到点后做的额外离线核验属于诊断，不能把命中回填到预算内。参考与 oracle 的已有认证不能替臂内 C2 省钱。

每次真实求值先获得预算许可；已预留但未发起的许可归还。不可拆分的任务事先预留其最大新增单位，余额不足则拒绝发起；任务完成后结算真实支出。未知上限的过程按单次求值受控。发现和选择都不能在预算越界后完成昂贵认证再算成功。最后余额与因余额不足未发起的任务单报。

### 2.3 账本最小记录与中断

每条事件至少记录：run/block/arm、真实 hostId 和执行主机、task/attempt/retry、parent、来源微态/姿态/意图、阶段、模型成员、单位、请求/缓存/实际求值、导数类型、预算前后余额、开始/结束、结果或失败码、工件引用。阶段至少覆盖 `prepare/propose/probe/forced/free_response/quench/polish/minimum_check/saddle_refine/hessian/descent/neb/shoot`。

逻辑候选 ID、执行 attempt ID、求值 ID 分开。**恢复可回滚逻辑结果，不回滚已付成本**；断点重算发新 attempt，链回被中断记录。并行任务的支出与认证完成按协调器提交顺序记录，快照采用保守完整前缀。若崩溃导致实际求值数无法核对，记录预留上界与缺口；该批不能参加精确同预算主比较，不用成功次数估算遗漏成本。

成本验收先在解析台验证：缓存命中、能量/力共享、committee、Hessian、失败、预算边界、kill→resume、并行不重复结算。独立外部计数器与分阶段总账必须一致。真实模型再校准 forward/导数耗时分布；这是一项施工门，当前尚未完成。

## 3. 参照认证流程

### 3.1 体系与资格

| 体系 | 在本协议中的角色 | 当前需关闭的资格门 |
| --- | --- | --- |
| 解析双鞍点台 | 同映射端点、两几何鞍点的工程检验 | 沿用冻结原件；新发现比较另冻起点与提案域 |
| b04，Cl⁻ + CH₃Cl | 真实单通道/退化自环对照 | 明确复用的目标 PES 驻点与下降工件；遵守原冻结判据 |
| b05，叔丁基氯 + OH⁻ | 不同端点的取代/消除候选 | 两通道在目标 PES 上分别认证，未认证项不得充当答案 |
| N1，环戊二烯 + 丙烯醛 DA | 新双分子参照；考察 endo/exo 与构象路线 | 在 POLAR-1 上认证端点和独立鞍点；s-cis/s-trans 只是待核验路线假设 |
| N3，公开数据集单分子体系 | 留出单分子多通道验证 | 先按公开规则选体系，再独立认证，固定数据记录 ID |
| b09 | 最终压力测试 | 单独关闭参照、盲搜、入口、分支与 QM 门 |

b08 不进入中间参照。N1 的不同丙烯醛构象不自动等于“同端点”：必须报告化学态、构象微态和原子映射三个层次。若它只支持不同反应物微态之间的多入口，按实际连接分层；不能把 conformer 标签硬算成同微态两鞍点。

某候选轴在目标 PES 上认证失败时保留失败记录，不将文献 DFT 驻点直接放进 POLAR-1 分母。建议在正式盲搜前完成资格判定；不合格体系保留为诊断，不事后根据哪个搜索臂获胜挑替代。若所有中间体系都缺少真实同映射端点多鞍点参照，这一分子收益问题仍缺参照，解析台不能替代。

### 3.2 从文献线索到冻结参照

1. **登记来源与任务边界。** 记录文献/数据集版本、原子映射、构象、电子态、源 PES 与目标 PES；列出期望通道但不称已认证。参照团队可用已知端点/TS 生成初猜，搜索端仅见通用反应物输入与协议。
2. **目标 PES 驻点重优化。** 对每端点与 TS 初猜独立收敛；去掉扫描约束/偏置后测完整梯度。力门、优化上限、几何/模型域门预先写定，不能按搜索难度调。
3. **完整内部 Hessian。** 投影刚体模式，明确非线性/线性分子和外场例外；TS 恰一显著负模，端点无显著内部负模。差分步长、误差地板及负模交叉核验写定，软模不确定则 unresolved，不以频率名义掩盖数值噪声。
4. **独立两侧连接。** 从 ±负模位移开始执行有下降证据的轨迹/IRC与端点优化，确认两端极小和身份。位移尺度复核不得由已知产物强行判归；逃逸、额外中间体、两侧同微态或分支不清均单报。得到分步过程则认证每条局部边，不虚构一个直接鞍点。
5. **鞍点身份与去重。** 使用固定映射/允许对称置换下几何、负模方向（符号商掉）、端点连接和能量一致性；必要时把近邻重新优化以判断是否同驻点。仅键图或端点对相同不能去掉第二鞍点；歧义保留未决，不靠候选名称裁决。
6. **独立 QM 作为另一个轴。** 对协议指定的代表项做 QM 重优化、Hessian 和连接核验，明确 level、电子态与溶剂条件。QM 与 POLAR-1 的差异单报；QM 通过不替代目标 PES 的 C2，目标 PES 的 C2 也不自动具有 QM 科学资格。**模型适用域（v1）：** 每个参照鞍点及其两端做 QM 核验，沿用 [MANIFEST](../benchmarks/MANIFEST.md) P4+ 口径——结构对应与连接一致为 pass/fail，能垒差只记录；不过的体系保留作诊断，不进入 S。
7. **冻结参照注册表。** 每项保存驻点、负模、双侧轨迹、端点工件、映射、认证数值、费用和状态。正式比较前锁定 S 与匹配容差；全臂没找到的参照仍留在分母。

参照外新 C2 在独立核验后列为额外发现，不给本轮 S 扩分母或改召回曲线。它可以进入下一协议版本，修订需说明已看过哪些数据。静态连接只能支持结构结论；b09 的两产品去向/分支比例仍需独立冻结系综、时窗、终止和多 seed。

### 3.3 N3 的选择建议

建议优先从 Grambow 的单分子反应资料建立候选短名单，RGD1 作另一来源；本次只核对公开入口，**未下载、未挑定具体分子或认证驻点**。[Grambow 等的原始数据论文](https://www.osti.gov/servlets/purl/1817160)与[RGD1 作者仓库](https://github.com/zhaoqy1996/RGD1)用于来源定位，数据集条目是计算参照线索，不是实验测量或全 PES 完备答案。

筛选规则建议：同一单分子反应物身份有至少两个不同事件记录；元素/电荷/多重度在模型声明域内；原子映射和几何可获取；规模满足预定参照认证预算；可独立生成反应物构象。按固定规模排序及记录 ID 打破平手，预定短名单和替补次序。筛选不使用 D0/D1/D2/DB 的结果；资格失败记录全留，不能只保留利于 D2 的体系。正式留出分子不用于调探针、评分或阈值。

## 4. 收益怎么定量（先量重复噪声）

### 4.1 指标与分母

对体系 s、配对重复块 r、臂 a，令 H_a,r(b) 为累计臂内实际支出 ≤b 时已完成 C2 的独立鞍点集合：

`R_a,r(b) = |H_a,r(b) ∩ S_s| / |S_s|`。

每个鞍点首次命中成本 T_i 未发生则右删失于终止支出，不把预算上限当真实命中成本。主结果报告统一预算 B* 上的 R，以及固定预算网格的曲线。建议网格为 B* 的 0、1/8、1/4、1/2、3/4、1；可另报 `AUC = (1/B*) ∫[0,B*] R(b) db`，但不以它替代最终覆盖。

分别给出唯一化学连接数、同连接不同几何鞍点数、参照外 C2 数、每条首次命中成本、重复认证成本。一个已知连接的第十次观测不记新收益。C1 比例不是 C2 召回率。

错误接受率 = 独立复核判不满足 C2 的项 / 被报告为 C2 且完成复核的项；复核未决项另报，分母为零则不适用。未决率按已发起候选计，分类含认证未完、域门/身份未决、数值失败、预算/时间截断；未执行的提案另报覆盖截断，不混入候选失败。错误排除通过预先分层抽审估计，见发现设计 §6；不能用未升级者都没命中当零漏检。

选择比较用 §1.2 的保留率及逐参照首次保留成本，给相同精修预算上的差值。端到端比较另加发现投入，不从池内好结果推出自主发现优势。

### 4.2 重复单位与零号批

建议配对块 = 独立反应物构象/起点集合 + 姿态采样 seed + 搜索随机 seed；四臂共享同一块的 L0，但随机流按 arm/stage 分开。来源构象、姿态和搜索噪声分层报告；多个 trial、MD 帧或同一源的姿态不能当作独立分子重复。

**建议零号成本/噪声批：每个开发体系 6 个配对块；其中 2 个块按同 seed 冷启动重复一次，测数值/恢复噪声。** 开发使用解析台、b04、b05/N1 的指定开发批；这些数值供审阅，不是正式样本量。6 块只用于估算成本、离散度和可行性，不进入确认统计。调规则的数据与正式块/seed 表完全分开。

N3 保留为体系级留出，规则与效应阈值不在其发现结果上校准；其参照/数值资格由独立认证流程确认。若确需 N3 的成本校准，必须先锁定算法，仅测既定操作成本，并禁止据该批命中结果调策略；否则将它重标开发体系，另外选留出体系。

正式样本量由零号测得的配对差值分布、最小实际收益 δ 和预算共同决定。建议先预算 20 个独立配对块的资源，再按 pilot 做功效/区间精度设计；不足以识别 δ 时扩大独立块数或收窄结论，不把多跑同一几何充作独立重复。

数值门的噪声与算法效应噪声分开：梯度/Hessian/匹配容差依据独立认证的数值分辨率；收益阈值依据重复块的效果分布与最低值得投入的改善。δ 由用户审定，不能看到留出结果后挑“刚好显著”的数。

### 4.3 对比、区间与结论

建议确认问题为两个共同主对比：D2−D0 与 D2−DB 的 R(B*)；D2−D1 用于判断方案 A 相对对照 B 是否值得保留。按体系逐一给配对差值和区间；跨体系可另给等权均值，不用参照项多的体系支配总分。区间重采样以独立来源块为单位，保留块内四臂配对与嵌套重复；小样本或全零命中报告可识别范围，不声称“没有效应”。

正式批前冻结 δ、错误接受/漏失容忍、置信水平和主对比多重比较规则。建议仅当两项主对比的经校正区间下界超过 δ，且错误接受与漏失门通过，才声称主线有确认收益。D2−D1 未通过则不声称方案 A 优于 B；若仅胜 D0、不胜 DB，结论限为改进现有 PRRS。没有显著差异不等于等效，等效需另冻界限与设计。

确认批不依据中途召回提前停或调参；预算/时间硬上限、资源失败处理跑前写定。所有已发起块留在主表，未认证项零覆盖并注明失败，不以替换 seed 消掉坏结果。若发生外部故障，原记录保留，补跑按预定政策另列，不能择优。

### 5.2 三层结构身份与鞍点身份

保留 chemical state、构象 microstate、reaction event 三层；连接记录引用双端身份与事件；独立 saddle ID 再绑定驻点、负模和连接证据。姿态/意图/路径候选 ID 只是提案追踪，不当化学身份。端点对重复、事件键重复或管聚类相同，均不自动合并鞍点。

静态约束准备、强制 pulse、自由 MD、quench、PES 局部搜索、两侧下降、shoot 分别具名。没有自由 MD 的静态路径不伪装旧 DiscoveryTrace；如何接入 PARS 在发现设计 §8 单列契约。电荷、多重度和原子映射贯穿每个阶段，冲突在新的模型求值之前拒绝。
