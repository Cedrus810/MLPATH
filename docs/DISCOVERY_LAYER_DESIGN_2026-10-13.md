**主线：共享反应物姿态与通用意图，以有限约束松弛读取响应；先保证便宜覆盖，再把预算投到不同路线和未决候选，MD 留到后面。**

## 1. 目标、假设与模块边界

要解决的是有效提案与投入分配：只按原子对名称枚举方向，不能保证有限位移后出现不同接近姿态；每个候选立即跑 MD/淬火又可能把大部分成本花在重复返回。保留“扰动是探针、响应即信息”，将静态松弛与动力学明确拆开。

待检验假设：

1. 其余自由度在意图交付时松弛，可减少不相关形变代价、暴露协同响应；这不保证降低真实势垒或命中所有通道。
2. 便宜响应可帮助分配后续求值，前提是包含自身成本并保留低评分抽审；低成本、正曲率或回弹都不是路径存在性的答案。
3. 覆盖保底、路线新颖性和认证反馈结合，可减少反复发现同一入口；收益看 C2 召回，不优化表面反应率。

发现层输出候选和证据，不替代 PARS 选择、NEB/CI 精修、独立鞍点/连接认证、mature 射击或 QM。Dimer/ART 不作为方案 A 内的发现组件。对于已经成熟的鞍点初猜，L4 可调用项目已有局部精修原语；这属于共同认证后端，不能偷偷把 DB 的发现搜索搬入 D2。

新策略作为显式版本与旧 PRRS 并存，不原地重释历史 `coarse/refine`、`attempts` 或冻结条件。当前接口支持程度需施工计划逐一核对，本稿不声称命令已可用。

## 2. L0：来源构象与姿态库

### 2.1 来源构象

输入只有反应物组成、电子态、原子映射与模型域声明。先用冻结的通用构象规则和极小确认得到来源微态；不得从已知 TS 反向退火、参考产物插值或手工对准目标成键位点建立盲搜主起点。此类既有几何保留为诊断，来源明确。

多个来源构象分别保留 ID、生成 seed、确认成本与选择理由；不因同 chemical_key 就只留最低能构象。非等价扭转与环构象可改变可达入口；纯对称副本才按权威身份商掉。来源数上限与生成失败政策在 pilot 后冻结。

### 2.2 双分子相对姿态

建议按以下因素分层生成：来源构象组合、片段接近方向、相对朝向、初始分离壳层。方向覆盖整个球面，相对转动覆盖 SO(3)；用固定 seed 的球面/单位四元数采样或可核验的均匀设计，不把独立均匀 Euler 角宣称为均匀朝向。取样算法和候选上限属于需验证的设计选择。

先做刚体放置、非重叠检查和电子态检查；若为控制初始间距执行约束松弛，记录外部约束及准备成本。**原始姿态和完全无约束极小分别保存**：软复合物自由松弛可能全部塌成一个姿态，不能一开始就把完整姿态库淬火并据此声称朝向已覆盖。

保持分离的姿态可以是受控初态，不假装全部为极小；四臂获得同一份最终起点工件及其状态。D0/D1 的无约束响应与 DB 的局部搜索从冻结的相同坐标启动；需要另做极小预处理者在臂内付费并记该行为。最终连接端点必须通过独立极小确认，原始摆放姿态不充当已认证反应物盆地。

这里“从相同坐标启动”指输入：当前 D0 的 `search.py` 会先 `relax_source`，因此进入提案时可能已经换了姿态。首轮保留其原行为，记录姿态塌缩/来源变更与费用；不把差异隐藏在共享准备中。若比较同微态上的探针差异，另做共同已确认微态的消融。未确认来源盆地的姿态到端点只能标受控响应，不能自动标盆地 C1。

片段存在对称性时，用允许的自同构与刚体对齐判断严格重复；近似几何接近只降优先级，不作为化学等价证明。保存完整原子映射，不随 pose ID 改原子序号。单分子体系不造“片段姿态”，以内部构象与局部意图分层。

### 2.3 共享输入合同

每个 L0 项记录 `source_microstate / conformer / pose / atoms_map / electronic_state / generation_rule / seed / preparation / qualification / cost`。D0/D1/D2/DB 接收同一 L0 表；建库时付出的模型成本是共享 P，纯几何操作仍记时间。第一轮建议关闭运行中向其他臂共享新起点；臂内新微态探索有独立上限与完整上游成本。

“姿态库覆盖”只对冻结生成域成立，不等于所有反应接近姿态。未通过几何/模型/身份资格者、没被取样者与预算没轮到者分别记。

## 3. 通用意图生成

### 3.1 意图是干预说明，不是已知反应坐标

每个意图表达：从哪一来源/姿态出发，哪些内坐标或片段运动沿什么符号改变，允许其他坐标如何松弛，幅度/代价上限是什么。意图不宣告产物，不直接携带参考键差或鞍点方向。

| 族 | 生成规则建议 | 防止人为指定目标 |
| --- | --- | --- |
| 距离 | 现有键延伸/收缩；非键接近/分离；按碎片与距离层分组 | 不只保留已知成键对；远壳层保留有界样本 |
| 角/扭转 | 有定义且非奇异的内部角、真实可变扭转 | 对称 rotor 与非等价构象扭转分层，不能按“甲基”名字删除 |
| 片段运动 | 相对平移、转动与接近组合 | 同一姿态尝试不同交付方向，保留实际交付信息 |
| 少量协同坐标 | 上述原语的二元/少量组合，正负号及幅度比由通用表给出 | 局部/跨碎片组合均有配额；不专写 DA 两根成键或 E2 参考组合 |

**v1 只用距离原语和二元组合**；角/扭转/片段运动对照族留到 v2；不枚举高阶组合。pilot 前先用纯几何（不做模型求值）数出各体系的意图数 × 姿态数，据此定 L1 规模和预算。局部关系可依据反应物键图、片段、距离分层；即便合理的局部限定也可能漏长程协同，需保存排除规则、远层抽样与未覆盖数。适用于多体系的规则表一次冻结，不能给 N1/b09 另加参考位点例外。

### 3.2 定义域、尺度与实际交付

不同单位先用固定物理尺度无量纲化：`q_j = (c_j(x) − c_j(x0))/s_j`；s_j 按族与输入结构的冻结规则给定，不由当前候选池最大值/最小值重新缩放。距离、角、扭转与 pulse 的力/时间各自记录，不能把 Å、rad、eV 混成严重度。

意图可写为 `q(x) = λ v`，其中 v 为符号/比例固定的低维向量，λ 是逐级交付参数。保存申请坐标与实际达到坐标、非目标键变化、片段转动、质量加权位移和代价。坐标奇异/冗余、约束不可行或输入电荷冲突在求值前拒绝；有限位移中的附带变化靠实际工件审计，不凭名字说“纯压缩”。

实际交付相似可用于分层抽样与降优先级；小位移向量平行或局部 SVD 低秩不能证明有限幅度响应等价。权威对称关系以外不硬去重不同意图。

建议提案 ID 来自稳定的来源/姿态/族/坐标/符号/规则版本，执行次数放 attempt ID；文件排列与候选改名不能改变 tie break、聚类或抽样人口。随机流按来源、姿态、意图、阶段划分，追加候选不挪动已有任务的随机流。

## 4. 方案 A：有界约束松弛探针

### 4.1 正式定义与求解约束

对每个冻结 λ，求目标 PES 上的局部约束极小：

`x*(λ) ≈ local argmin_x E_PES(x), subject to q(x)=λv`。

只约束意图坐标，其余内部自由度松弛；整体平移/转动只作为数值规范固定，不把片段相对转动一并锁死。每级从前一级可核验结果 warm start，保存完整准备段。建议优先精确约束/投影求解，软惩罚势作实现备选；若用软约束，PES 能量、惩罚能、残差分开，不能把带罚项的总能当物理势垒。

geomeTRIC 支持约束扫描，可用于评估求解器候选，但其文档不证明本项目接口、预算门或并发恢复已经支持：[约束优化官方说明](https://geometric.readthedocs.io/en/latest/constraints.html)。约束扫描提供初猜，最终需无偏驻点认证；不能调用当前拒绝约束输入的 `prrs optimize` 并假定它已承担这项工作。

每级验收包括约束残差、切空间投影力、模型/几何域、有限值和计算上限。完整 PES 梯度仍保存，但约束极小不要求驱动方向受力为零。记录相应约束乘子/反力作为响应；多个坐标统一 λ 时可记录 `dE*/dλ = −μ·v`（约定拉格朗日量为 `E+μ·(q−λv)`），不把该量当认证负模。

若约束松弛跳到另一局部支路，记录跳跃前后几何、能量和约束残差；它可能说明新盆地可达，也可能是数值换支。缺少连续路径/连接时不伪装越垒轨迹，进入独立精修或未决。

### 4.2 粗扫、幅度与能量代价

L1 每意图先做固定的小幅试探和有限松弛，使用冻结的幅度格与每点上限。局部力/曲率只选初始步长，不能推算大幅区域。L2 才细化幅度、延长松弛或尝试少量相邻姿态；重试不改变原意图的历史状态。

截断依据是**真实无偏 E_PES 相对该意图起点的最大上升、实际交付位移与模型可信域**；每姿态起点能量和准备代价另报。低于自己高能姿态的能量，不等于从独立反应物出发低势垒。若各 λ 不连续，只有离散扫描能量包络，不能称全路径最大势垒。

最大 ΔE、最大位移、最大新增 forward、每级松弛步数和回退次数在 pilot 后冻结。触及上限记 `censored_energy / censored_amplitude / budget_exhausted`，不是“无通道”。几何与 OOD 门不能因想让候选通过而放宽；诊断疑似被误挡者另立有效域研究。

**先粗扫后细化：** 固定每来源/姿态分层的初始意图人口，在其已选集合的 L1 基础试探覆盖完成后才开放 L2。预算不足完成时标覆盖截断。为了不让第一个来源吃完全部成本，建议按冻结来源/姿态配额各完成基础覆盖，再全局分配余额；这是新分级合同，不宣称继承了旧 MD coarse 覆盖。

在线新微态可以进入后续探索轮，但不能插入当前人口抢走未粗扫项额度；每轮人口、增量成本与截断分别保存。旧 D0 响应策略继续按其原合同执行，不把 L1 数量当 D0 的 trial 覆盖。

### 4.3 “越脊”触发与释放

建议把用户所说“越脊点”在机器中先命名 **`ridge_suspected`**：连续合格的扫描点出现超过独立数值噪声的能量上升后下降，并有驱动反力变号/接近零的支持；保存峰前、峰附近、峰后几何。它只是释放/精修触发，不能宣称跨过真实 index-one 鞍点。分支跳跃、约束未收敛和只有一个高能点都不满足连续扫描触发。

松弛扫描越过 TS 后常不连续地跳到产物侧。出现跳支时做一次反向扫描（λ 递减）查滞回；跳支区间两侧被夹住的几何记 `branch_bracketed`，可与 `ridge_suspected` 同样触发释放或作 L4 初猜，仍需 C2 才进召回。

在疑似脊后选冻结规则指定的点，解除所有外部约束，重新计算无偏力，再 quench/确认端点。必要时从峰前一侧做对称释放核验，费用属于同一候选。释放返回、进入新构象、新化学态、碎裂、身份未决或未收敛分别记录；观测到新端点仍须 L4 找到 C2 才进入召回。

**不能把“没测到越脊”设为永久拒绝门。** 未见峰但变化新颖、换支或信息不足的候选可以升级继续扫描；预定抽查项可越过这一触发做释放/后续 MD，但必须标 `audit_release`，单报它的收益与成本。这样既保留主线“越脊后释放”，又能测出该启发式漏掉的路线。

释放时保存约束删除清单、坐标、重新求得的力、来源、seed、预算和准备段。后续若 MD 从此坐标启动，释放后初始化独立定义的动量；不能把静态扫描虚构为热采样，也不能沿用强制段缓存外力。

## 5. L0–L4 分级升级

| 层 | 进入与工作 | 出口和下一步 |
| --- | --- | --- |
| L0 | 通用来源/姿态/意图；严格重复审计及资格 | 进入 L1 或明确拒绝/未取样；不打“无反应”标签 |
| L1 | 固定小幅能量/力与有限约束松弛 | 有效响应、低优先、未决、数值失败或域截断；基础覆盖后才 L2 |
| L2 | 加深静态探针、幅度局部细化；冻结抽查救援 | 脊候选、新颖换支、继续未决；转 L3 或 L4 初猜 |
| L3 | 按触发释放与端点确认；对选定项做完整响应 MD | 端点/路径证据 C1，或未决；另行 L4 认证 |
| L4 | 共同精修、完整 Hessian、两侧下降、身份闭合 | C2 / duplicate_C2 / unresolved / rejected；动力学与 QM 另账 |

L1/L2 没有反应标签也有信息；归档原始响应，不用单一软模分数代替。L2 已形成足够好驻点初猜时可以直接 L4，不强制先跑 MD；精修失败再升级 MD只能按冻结救援政策与预算执行。

MD 的触发建议仅为：已选候选需要实际自由响应、静态释放/精修信息不足、预定低分抽查，以及 b09 的独立分支问题。第一版不替每个意图计算 committor。完整 MD 的温度、动量、时窗、终止和释放语义独立冻结；现有 P1 的具体 k/时窗不作为通用默认值。

候选状态与证据状态分开：`proposed → probed → deferred/promoted → attempted → completed/failed/censored` 是投入过程；`candidate/C1/C2` 是证据。预算没轮到的 deferred 不是 elastic，正曲率不是无反应，静态候选不是 MD 轨迹。

## 6. 升级规则、抽查与自适应分配

### 6.1 第一版采用可解释规则

建议先用分层优先级，不训练 Q、不拟合学习提案：

1. 资格合格，基础覆盖未完成者按冻结配额粗扫。
2. 基础覆盖结束后，在未重复的来源/姿态/意图层轮转；脊候选、明显耦合响应、不同换支和响应信息不足者优先升级。
3. 反复返回同盆/认证同一鞍点者减少后续重复额度；每层仍保留探索与抽查机会。
4. 同层同优先级用冻结随机键打破平手；不按文件名/输入顺序分配全部预算。

便宜响应用于排序的字段包括实际位移、目标坐标残差、能量包络、附带键/构象变化、换支、新颖性和成本；阈值来源是开发噪声测量。坐标族间不混原始单位；低能、高位移、软曲率都不能单独形成硬接受/排除。

### 6.2 四类预算账户（v2）

**v1 只分两个账户：搜索额与 C2 认证保留额**（认证保留额不被扫描吞掉，搜索额耗尽后完成已预留认证）。以下为 v2 设计。

在评估协议总 B_A 内建议分四个账户：基础覆盖、升级、抽查、C2 认证。各账户额度和允许转移方向 pilot 后冻结；认证保留额不能为了更多扫描被提前吞掉。初期没有成功也不挪走所有抽查额；搜索额耗尽后停新提案，完成已预留的认证任务。

基本分层为来源微态 × 姿态类 × 意图族；层太多时先按预定两级取样/上限冻结实际人口，不能承诺全部组合已覆盖。每层保存人口、取样数、L1 完成、升级概率/原因、未决、认证新项、重复与累计成本。预算不足完成保底时给缺口表，不能把配额当覆盖事实。

### 6.3 抽查如何估计漏失

**v1：** 暂缓候选按冻结比例、独立随机流均匀抽查，走正常升级流程，费用属 D2；只报告抽查发现了哪些新 C2/重复/失败，不做概率加权外推，也不据此声称零漏失。下面的分层 π_i 估计为 v2。

抽查人口是资格合格、已有 L1 响应却因低分/重复近似/容量而暂缓的候选；未生成、硬 OOD 拒绝和身份未知分别统计，不能用抽查推断这些域。按来源/族/暂缓原因分层，在每个冻结波次用独立随机流抽样，保存每项入样概率 π_i。

抽查项走与正常升级相同的后续流程与任务上限，费用属于 D2。按层报告抽查中新增 C2、重复 C2、失败和未决；可用 `Σ y_i/π_i` 估计被暂缓候选中可恢复 C2 的候选数，区间尊重分层/来源聚类。**该估计是候选机会数，不是未发现独立鞍点数**，多个候选可能落到同一个鞍点；独立路线漏失另靠实际去重证据报告。低分抽查仍未完成时不能推断零漏失。

若抽查成功，需要报告它发现的是哪个新项，以及正常排序为何暂缓。正式批内可按冻结反馈规则救援相同层，但不能读参考剩余项后定向放行。修改启发式阈值留到下一版本，旧批按旧规则评分。

### 6.4 自适应只在保底后启动（v2）

**v1 用固定分级分配，不做认证反馈自适应。** 以下为 v2 设计。

建议按波次更新预算分配，不在每次返回后无限加码一个幸运来源。统计层 h 中**臂内新 C2** 数、重复率、失败类型、认证等待数及真实消耗；初步收益率可定义为 `new_C2_h / total_cost_h`，成本包括该层无效/失败探针和认证。未完成认证不能直接当失败，候选潜力作为另一个信号。

将剩余升级额拆为固定探索份额与自适应份额；探索在冷区/未决层轮转，自适应按新 C2 成本收益排序并设置单层最大份额。所有比例、更新频率、最少证据量与先验都待 pilot 冻结；第一版不凭参考召回率在线调度。用同端点多鞍点身份判断 novelty，不能按化学节点重复把另一入口停掉。

首轮 D2 建议采用固定分级分配作为可归因起点；再将响应自适应作为单独干预做同预算消融。主线四臂评估完整策略，后续消融分别比较“无分级”“固定分级”“认证反馈自适应”，不能同时换姿态域、幅度和评分后归因于自适应。

## 7. 方案 B 与外部基线的公平接口

D1 用同一 L0。为保留“现有 pulse”语义，首轮建议只用现有 runner 能表达的方向原语和力/时长表；复杂多坐标 pulse 另作显式扩展，不暗称已实现。D1 不接入 D2 的约束松弛准备结果，D2 不免费复用 D1 的响应。双方可以用相同通用意图目录做覆盖审计，但有些意图 D1 无法交付时标 unsupported，不能伪造相同能力。

D1 的强制段做功、自由段能量、终止与端点确认全部入账；pulse 幅度与持续时间不能用方案 A 的离散 ΔE 直接等同。可按共同可信域/能量包络定义预算，实际注入与响应另报。比较结果是两种交付策略的全成本收益，不从“力更小”推导“更温和”。

DB 接收同一 L0；初始小位移和方向依据通用规则，不能用 D2 的脊候选或参考负模。重启和方向覆盖次数在 DB 内付费。Dimer/ART 找到的候选仍走共同 C2 接受门；失败和仅找到复合物软鞍点同样计成本。基线和 D2 在同一精修/认证后端接受相同任务上限与容差，搜索器自身参数分别冻结。

## 8. 输出与现有 PRRS/PARS/mature 的契约

建议新增逻辑记录，具体文件名/模块由施工计划确定：

| 记录 | 最少内容 |
| --- | --- |
| 来源/姿态表 | 构象与电子态、原始/准备后几何、资格、规则与准备成本 |
| 意图表 | 稳定 ID、坐标定义、符号/尺度、域、生成概率/排除原因 |
| probe 轨迹 | λ、真实 PES 能量/力、约束残差/乘子、实际几何、换支及调用账本 |
| upgrade 决策 | 人口/波次、规则版本、响应特征、正常/抽查概率、预算和暂缓理由 |
| release/response 记录 | 外部约束移除、动量、forced/free/quench 分段、端点与失败 |
| certification 记录 | 初猜来源、完整 Hessian、双侧下降、映射/身份、C2/重复/未决 |

路径帧分成 `pose_prepare / constrained_probe / release / free_response / quench / saddle_search / descent`，每帧保存电子态、来源及偏置状态。脊附近初猜、两个实际端点与它们之间有来源的几何段一并交付；不同 intent 的峰前/峰后不能随便拼成一条连续路径。

PARS 首轮可通过显式静态候选适配层消费：真实端点、准备段/释放段、鞍点初猜与 provenance。旧 PRRS 文件合同保持；静态轨迹不冒充 MD trace。NEB 初猜需保护事件附近图像、强制准备段与自由/释放段各自重采样，防止人工交付跳跃挤掉有效图像。聚类使用事件与几何路线表示，参考 saddle ID 永远只在评分端。

路径信息保真修订 ALG-02/11/15/16 是选择比较中的独立臂，不以“新发现层已经输出不同候选”自动视为修复完成。mature 只消费明确候选/释放几何，温度/盆区/seed/终止另冻；静态扫描本身不提供 committor 或动力学分支概率。

## 9. 预算、恢复与数值失败

所有 L0 求值、谱、松弛、释放、MD、Hessian、精修、认证都通过统一预算账本；方案 A 是否便宜由真实支出证明。每意图拥有基础上限、升级上限及 retry 上限，不因约束优化未收敛而无限续算。

断点需保存当前人口、λ/坐标目标、最后合格几何、约束状态、随机流、队列、抽查概率与预算结算。中断的求值已支出不回滚；重做用新 attempt。自适应更新按冻结波次提交，不能因 worker 完成顺序变化而悄悄换策略。旧 PRRS 的 resume 不自动证明新扫描状态能可靠恢复。

失败码至少区分：定义/电子态冲突、坐标奇异/约束不可行、投影优化不收敛、模型域拒绝、几何重叠、能量/位移截断、非连续换支、释放未决、非极小端点、C2 未通过、预算/时间停止、中断重算。失败保留工件和成本；不得全部压成 returned 或 nonreactive。

## 10. 可证伪的验收与停止规则

| 问题 | 应看到的证据 | 没通过时的处理 |
| --- | --- | --- |
| 意图是否真实交付 | 几何重标号/刚体变换下的等价行为；实际坐标与附带变化可审计 | 修交付定义，不靠提高幅度遮掩 |
| 约束松弛是否可信 | 残差与投影力门、无偏能量、释放外力清零、跳支具名 | 不输出已越脊或 C2 结论 |
| 分级是否省成本并保信息 | 全阶段计数闭合；抽查可揭露低分漏失；同预算 C2 曲线 | 保留无筛选/固定分配基线，修规则而非只增预算 |
| 自适应是否有收益 | 先粗扫、冷区保底、固定分级对照、独立块效果 | 无收益则沿用固定分级，不加学习控制器 |
| 独立多通道是否成立 | 不同端点与同连接几何鞍点分报；目标 PES 参照资格通过 | 不用解析成功替代分子验收 |
| 最终 b09 是否接近目标 | 参照、独立盲搜、入口认证、分支动力学与 QM 分门关闭 | 报具体缺口，不能以一个产物宣布完成 |

工程核验需要针对关键反例：同图不同鞍点、低幅回弹但高幅有连接、约束能量峰非鞍点、分支跳跃、原子重标号、近似方向被误合并、预算截断与 kill→resume。运行位置和资源由后续施工/执行协议指定；本稿没有执行这些检查。

若 D2 在独立参照上不胜 D0/DB，先依据工件区分姿态域、意图域、松弛、升级、认证或成本口径的失败源；回到设计，不叠 b09 特定坐标补丁。若 MD 无增量发现收益但有动力学诊断价值，保留后者，避免扩张加速叙事。

## 11. 建议审阅顺序与待定参数

先审评估协议的接受门、成本与参照；随后审本稿 L0/意图/约束探针，再审升级和反馈。可先接受结构设计、把数值作为 pilot 后的冻结项；结构未定时不写具体施工文件清单。

| 待审决定 | 本稿建议 |
| --- | --- |
| L0 原始姿态 vs 淬火极小 | 两种工件都保留；同坐标输入各臂，不先把姿态全压成单一极小 |
| 意图规模 | v1 只用距离与二元组合；其他族 v2；不写体系专属 TS 坐标 |

| 各类上限 | pilot 测量后冻姿态/意图数、幅度格、ΔE、松弛与认证上限、抽查和预算比例 |
