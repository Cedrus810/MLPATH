## 1. 研究问题与分期

AFIR 给出候选极小、鞍点和路径窗口。去掉 AFIR 推力后，从指定几何和动量分布发射短轨迹。对 b09，先量每个起点到反应物、`(2+1)`、`(4+1)` 的竞争首次进入。回返、在开链区停留和超时都留下时序与坐标，可用于判断分支发生在哪里，以及下一批应当在哪些构型播种。

| 阶段 | 要回答的问题 | 所需数据 |
| --- | --- | --- |
| 1. 直接射击 | 已找到的另一进攻面和 POLAR-1 TS-2OMe 各自能否直接进入两个产物盆？ | 固定几何、独立热动量、无偏惯性短轨迹和多盆首次进入 |
| 2. 播种对照 | 复用回返和超时轨迹，能否用同样 E/F 预算更早找到或复现少见路径？ | 固定候选池、同预算对照、原轨迹之外的独立确认 |
| 3. 动力学网络 | 能否从有覆盖的轨迹估计速率、布居或反应通量？ | 明确的动力学系综、反应物侧供应、盆间或界面采样和独立检验 |

阶段 1 是固定种子射击。TPS 是在预先定义的路径系综中做 Monte Carlo，射击提案和接受规则共同确定采样分布。阶段 2 可以独立验证 AFIR 提供起点和保存非反应轨迹的收益。若将来实现正式 TPS，路径系综、提案概率和接受或重权规则需一起登记。搜索和动力学载荷沿用 [E/F 约束](NONHESSIAN_AFIR_DESIGN_2026-11-14.md)，已有 Hessian 数据只用于说明参考点身份。 [Falkner 等，2025](https://doi.org/10.1063/5.0261744)

## 3. 第一阶段协议

### 3.1 动力学和首次进入

对每个固定几何按 384 K 的 Maxwell–Boltzmann 分布抽取独立动量，沿用 `thermal_momenta` 去除总平移和转动。温度参数指定初始动量分布，每条轨迹各自做 velocity-Verlet NVE。记录坐标和原子映射哈希、charge、multiplicity、模型权重哈希、精度、时间步和随机种子。

用已优化的反应物和产物建立盆核模板，复用 b09 判别器的关键原子定义。沿用带滞回的键图，进判别器前把模板和射击坐标都映射到同一原子顺序。用一次原子换序重放检查映射。 [现有 b09 判别器](../benchmarks/afir_mc/b09_saddle_check.py)

| 盆或区域 | 拟议在线规则 |
| --- | --- |
| 反应物 A | 反应物键图保持，三条关键新键均未出现，且卡宾碳到 Cb 的距离 ≥2.9 Å。用 3.0 Å 重判作为敏感性检验，另报进入 A 后仍未达到 3.0 Å 的轨迹 |
| 产物 P2 | 卡宾碳同时键连 Ca、Cb，且完整映射键图匹配 `(2+1)` 模板 |
| 产物 P4 | 卡宾碳同时键连 Cb、醛氧，且完整映射键图匹配 `(4+1)` 模板 |
| 过渡区或其他结构 | 只形成卡宾碳–Cb 的开链区、混合键图和其他结构按原标签记录。保留可能的新产物几何，另行复核其身份 |

已对现有几何做静态核对。两个鞍点的卡宾碳–Cb 距离约为 1.98 Å，自动鞍点的反应物侧连接端为 2.97 Å，分离的反应物输入为 6.61 Å。采用 2.9 Å 的拟议下限可以把接触复合物纳入 A，3.0 Å 可用于检查结论是否依赖这一区分。现有 P2、P4 模板的关键键与上表一致。

起点需位于三个盆核之外。每一步记录盆核标签，连续保持 **10 fs** 才确认首次进入，保存连续段开始及确认时刻。分类发生在惯性轨迹上，事后弛豫只作身份诊断。Pilot 的有效轨迹积分到 500 fs，保留首次进入之后的片段，便于同一批数据重判 5/10/20 fs 持续时间和反应物距离阈值，也可区分 `P4 first` 与 `P2 → P4`。已确认的首入标签保持到轨迹结束。首次进入前的数值异常单列。首次进入后的异常保留已确认标签，并标记后续轨迹截断。

### 3.2 估计量

给定几何 $x$、动量分布 $\mu_T$ 和时限 $t_*$，记 $F_j(t_* \mid x)$ 为在 $t_*$ 内先确认进入 $j$ 的概率，$j$ 为 A、P2、P4。输出经验累计首次进入比例 $n_j(t)/N$，以及 500 fs 时的计数和区间。每个起点的 $N$ 为预定的独立射击数。物理超时保留在分母。若有 $n_{\mathrm{fail}}$ 条在首次判归前数值失效，则同时给出缺失数据范围 $[n_j/N,(n_j+n_{\mathrm{fail}})/N]$。按同一分母报先入 A、P2、P4、到时限未判定和首入前失效，五类数目之和等于 $N$。

另外报产物条件比例 $n_{\mathrm{P4}}/(n_{\mathrm{P2}}+n_{\mathrm{P4}})$，附有效分母和 95% Wilson 区间。该比例仅描述在时限内已经到达两个目标产物之一的轨迹。单条轨迹是一份样本。配对步长试验用于数值对照，帧和同一条轨迹的续段沿用原样本身份。零次观察到 P4 时，给单侧 95% 精确上界 $1-0.05^{1/m}$，其中 $m$ 取可判定该事件的独立样本数，并同时报告失效情况和缺失范围。若产物条件分母为零，则该条件比例未定义。无限时 committor 需要另做时限收敛或经验证的模型。

### 3.3 预算、验收和停止

| 批次 | 拟议设置 | 产物 |
| --- | --- | --- |
| 判归检查 | 反应物、P2、P4、开链单键、短暂越界和原子换序的静态或构造轨迹；确认两个实际鞍点均从过渡区起步 | 盆核映射，事件时序，数值异常与超时的统计测试 |
| Pilot | 两个几何各 32 条、0.5 fs、500 fs；每个几何预取 8 个同动量种子用 0.25 fs 重放 | 最多 96,000 积分步。报漂移分布、步长和持续时间敏感性、到达时间、全成本和各类轨迹 |
| 条件延长 | 若未判定数足以改变两个产物的排序，或少见分支只出现在时限附近，按预定随机规则从 0.5 fs 主批每个起点选最多 8 条超时轨迹，由原相空间和判归状态延长至 1,000 fs | 最多追加 16,000 步。以原分母保留 500 fs 主结果，另报被抽中的超时轨迹后来去哪 |
| 独立确认 | Pilot 判归和数值检查通过后，按目标分支比例的区间宽度预定每起点的样本数，使用独立种子 | 起步量级可取每起点 400 条。在有效样本量为 400 且概率约 0.5 时，95% 区间半宽约 5 个百分点，产物条件分母通常更小 |

Pilot 通过条件是输入可溯源、三个盆核可区分、类别守恒、记录可重放。用配对步长检查能量误差和首入标签。若步长或 5/10/20 fs 选择改变分支是否出现，或有集中在某条支路的数值失败，先查积分、映射和盆核，记录原因后再定确认批。用独立确认批检验两个直接产物能否复现，并报告实际计数。任一起点只有单产品或看不到少见产物时，保留这项结果和置信上界。两个起点均进入 P4 也不能单独说明从反应物进攻时各个鞍点的贡献。

预算表按积分步计。实测另外记录模型 E/F 调用、批大小、初始化、可选弛豫和 I/O，以及墙钟和硬件。先测串行复用路径，吞吐确实限制确认批时再做批量积分。

## 4. 第二阶段｜回返与超时轨迹怎样改善下一批

先固定两套比较。第一套比较「仅鞍点播种」与「鞍点加 AFIR 成键窗口播种」，检验 AFIR 路径几何有没有带来额外覆盖。第二套从同一个固定短轨迹探索批出发，比较「只从已进入产物的轨迹选后续播种点」与「允许从所有有效轨迹选点」，两臂共用分箱和选点规则。按三条关键距离、相关二面角及关键距离速度分层，选代表构型。优先覆盖通向两个产物的轨迹共享、或大量轨迹久留的区段，保留每个候选的来源及选择规则。

两套对照都冻结同一 E/F 预算和轨迹时限，记录公共探索批与新增播种成本。b09 预先以首次进入 P4 为少见路径的指标。评价每个独立重复中首次发现 P4 的 E/F、复现率和未发现次数。若公共探索批没有产物轨迹，则第二套比较缺少对照臂，记为覆盖不足。用独立热动量从预定几何确认结局。各播种几何的分支概率单报，平均值只对预先定义的初始分布和权重计算。固定鞍点的分支比继续从独立射击估计。

过阻尼 Langevin 是可选播种对照，离散积分可只用 E/F，设定温度、迁移率和随机步长。对常数扩散的连续时间 Onsager–Machlup 小管概率，漂移散度项在梯度漂移下涉及势能的 Hessian 迹。Freidlin–Wentzell 的 E/F 目标适合低噪声路径提议。Doob 条件化是另一个候选，近似控制路径若用于物理统计，需要对应路径权重和独立验证。过阻尼候选最终交给同一套惯性射击复算 b09 分支。 [Du 等，2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/78fa1d5646bc285940281cfc1386efae-Abstract-Conference.html) · [Onsager–Machlup 与 Freidlin–Wentzell 的关系](https://alea.impa.br/articles/v21/21-35.pdf) · [Häupl 等，2026](https://arxiv.org/abs/2602.13130)

## 5. 第三阶段｜网络动力学的入口条件

1. **先选物理量和系综。** 分清从预形成的反应物复合物出发的首达或速率，与从分离反应物出发的双分子反应速率。后者另需遭遇通量及浓度、体积或标准态约定。气相 NVE 混合总能量的短射击、固定能量系综和固定温度的恒温动力学分别定义。草稿早期的微秒猜测缺少与实际初始条件一致的速率证据，暂以测得的覆盖和通量评估可行性。
2. **构建有数据支持的态。** MIN 表用作盆核标签。对短时传播，在盆外按成键距离、二面角等增加过渡微态，对惯性明显的区段检验加入速度符号或最近访问盆的必要性。用固定时间间隔、不含 AFIR 推力的轨迹帧估计滞后转移。首入后终止的轨迹只支持相应吸收边界下的估计。未知图、失联子图和未采边单列。
3. **用独立轨迹验证再算 TPT。** 先量反应物侧、产物侧和连接区的采样支持。对候选滞后时间，检查 implied timescales、Chapman–Kolmogorov 预测，以及跨播种来源的条件转移和首次进入概率是否与直接射击相容。以独立轨迹或独立批次重采样。细致平衡是对物理上适用的模型施加的约束，不能凭空校准从反应物侧到界面的供应。通过验证后才从该模型算布居、速率和通量。 [Noé 等，2009](https://doi.org/10.1073/pnas.0905466106) · [Nüske 等，2017](https://doi.org/10.1063/1.4976518) · [Prinz 等，2011](https://doi.org/10.1063/1.3565032)
4. **反应物侧短轨迹覆盖不足时，优先考虑 weighted ensemble。** 用 AFIR 几何定分箱，用目标反应物系综初始化，按权重拆分/合并并保持目标动力学。指定源、汇和回注规则后，以独立重复检验源汇稳态通量。若改走 milestoning，要检查界面首次命中分布和通量迭代。TRAM 需要定义好的采样系综、偏置能和局部平衡条件。现存 AFIR 优化路径用来找构型与界面。 [Zhang 等，2010](https://doi.org/10.1063/1.3306345) · [Bello-Rivas 与 Elber，2015](https://doi.org/10.1063/1.4913399) · [Wu 等，2016](https://doi.org/10.1073/pnas.1525092113)

## 6. 与 AFIR 网络和已有方法的关系

AFIR 第二阶段网络建设的交付物是可续跑的 MIN/TS 连通和展开记录，包含 b09 的 `(2+1) → (4+1)` 重排搜索。该表可为第三阶段提供状态参照，第一阶段用现有两个鞍点和映射后的终点模板即可验证。RCMC 的数学输入是速率矩阵，常见 AFIR 应用通过 TST 供给速率。若后续动力学得到可信的边速率，两者可串接。短 MD/MSM、正式 TPS、过阻尼条件化及 RCMC 都已有先例。此侧线的待验证贡献是 AFIR 实际找到的几何能否以有限 E/F 开销揭示动力学分支，以及把回返和超时轨迹用于再播种能否进一步节省开销。 [AFIR 网络计划](PLAN_AFIR_NETWORK_2026-11-18.md) · [Sumiya 等，2015](https://doi.org/10.1021/acs.jpca.5b09447) · [Sumiya 与 Maeda，2020](https://academic.oup.com/chemlett/article/49/5/553/7339616)
