## 3. committor 规划器草稿（离线、多帧）

草稿不在仓库里，贴来的部分在 `plan()` 构造 `rows` 处截断；bracket 定位与单调性检验未见。

- **N = 16 下永远判不出边**。「其他」门要求 Wilson 上界 ≤ 0.25；0 发「其他」时上界 = (z²/n)/(1+z²/n)，
  要 ≤ 0.25 需 n ≥ 3z²。10 帧 Bonferroni（20 次检验）z ≈ 3.02 ⇒ n ≥ 28；16 发全干净时上界 0.363。
  而 `P1_COMMITTOR_PROTOCOL.md` 对 >25% 的处理是「按实际分母报告」，不是拒判。
- **序贯使用 vs 固定样本区间**：看 → 补打 → 再看，名义覆盖率不再成立。PRRS-2 的「探索批选帧、固定批给区间」正是解法（§4）。
- 帧数变 ⇒ Bonferroni z 变 ⇒ 已判的帧可退回 unresolved；输出应带 `z` 与 `tests`。
- `wilson` 与 `runner.wilson_interval` 重复且少输入校验；若为避免 import ase 而独立，写明并钉一个数值一致测试。
- 喂不饱：现行代码每个 bracket 只从一帧打，规划器需要的多帧数据还不存在。

## 4½. 轨迹终止规则：固定长度 NVE + quench vs TIS 式「首次进入即停」

**比的不是 NVE 与 TIS** —— TIS 同样积分 NVE（或随机）动力学；比的是**轨迹什么时候停、归属由谁判**。

**现行**（`runner.run_trial`，射击同）：固定 `response_steps` 步 NVE（默认 200 × 0.25 fs = 50 fs；**P1 committor 那批用的是 160 步 = 40 fs**）→
动量清零 → quench → 按 quench 落点判盆地。

- 50 fs 是**进结果的超参数**：到 50 fs 还没定下来的轨迹由最速下降判归，即「t = 50 fs 时刻的
  几何吸引盆」，不是动力学去向。现测 p_B 是动力学 committor 与这个量的混合；换 `response_steps`
  p_B 可能就变。~~**未实测**，是推论。~~ **已实测，成立**，见下方「实测」。
- 「其他」混了三件事：拓扑没撑过自由段尾部（`transient_topology`）、quench 不收敛、落点在
  registry 里认不出来。

**TIS 式**：从帧出发，**首次进入 A 或 B 即停**，另设上限 L_max。

- 无 t_free 超参，判归直接来自动力学，不经 quench；
- 「其他」有精确含义：**到 L_max 仍未进入 A 或 B** = 真未定；
- 代价自适应：很快定下来的轨迹很短，卡在中间的才跑长。

**path-sampling MC 里的 L_old/α 技巧**（据记忆出自 van Erp & Bolhuis, *Elaborating transition
interface sampling methods*, J. Comput. Phys. 2005；**引用前核原文**）：射击点在旧路径的帧上均匀选，
细致平衡要求按 min(1, L_old/L_new) 接受；**先**抽 α ~ U(0,1)、定 L_max = L_old/α，积分中一超出就
立即拒绝 —— 与事后按概率接受在分布上等价，但被拒的长路径不用跑完。同理先积反向那一半，
到 B 而不是 A 就立刻拒绝。

**对 PRRS 的含义**

1. committor 射击只需「首次进入即停 + L_max」。L_old/α **用不上**：各发独立、不是马尔可夫链，
   没有接受率。只有将来走 TIS / RETIS 算速率时才需要。
2. 要一个**便宜的「已进入 A / B」判据**（不能每步 quench）。现成材料：带滞回的键图
   （`bond_hysteresis`）+ `tail_persistence` 的持续 k 步思路。每 k 步查一次，判进入后**做一次**
   quench 核对落点是否就是 registry 里那个微态 —— A / B 的定义仍归 registry，只把「何时停」交给动力学。
3. NVE 漂移门要随之改：长度可变后漂移大致随长度累积，每原子 0.1 eV 对长路径更松。按**整条路径
   实测漂移相对势垒**报告（§2 已给 committor 记录加了 `max_nve_drift_eV_atom`，与此配套）。
4. 终止规则是协议的一部分，按规矩**跑前冻**。
