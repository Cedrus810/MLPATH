## 1. 第一版交付与工程边界

第一版交付 `prrs mature prepare|shoot|report`：

```text
PRRS run + PARS selection
    → 已有代表路径上的候选几何
    → 独立热动量射击、首次进入式判归
    → 过渡区域兼容 / A侧 / B侧 / 未决诊断
    → 路径与候选的可追溯精化交接清单
    → 现有 PARS NEB + 独立鞍点/QM 验证
```

实施选择：

- 在 `src/prrs/` 增加平铺模块，复用 `runner.shoot` 与只读 `Registry.identify`。
  新命令独立运行，未调用它时现有搜索行为保持原样。
- PARS 仍只经文件对接，继续禁止 `import prrs`。成熟层读取 PARS 文件，不要求它反向依赖成熟层。
- 首版范围为有限非周期、单一标量势能面、映射一致的全原子体系；同图构象盆地先显式拒绝。
  退化自环保留：若映射后的两侧键集合不同，可以使用现有首次进入规则。
- 第一版复用 NVE 自由响应及 Maxwell–Boltzmann 初动量；不把位置 q 模型当成相空间 Doob 桥的 h。
- 新增数据写入新的运行目录，不向源 `network.json` admit 射击端点，不修改旧 run。

首版完成后才能进入学习层；生成模型列为独立后续工程。FEL、速率与扰动策略反馈另立计划。

### M0 的具体检查

输入优先：`runs/p1_committor2`、`runs/p1_first_entry_confirm`、
`runs/p1_path_committor_explore`、`runs/pars_ground_truth`。逐文件检查来源，确认批和探索批分开使用。
PARS selection 缺失或来自修复前实现时，在新输出目录重新 select；保留原目录。

识别 A/B 用映射后的微态与键集合，不能用被对称商掉的 `chemical_key` 判断 P1 两侧。
如果现有 PARS 文件只有 chemical node ID，成熟层回读其来源 PRRS attempt 的微态身份；
来源不足则拒绝该候选并报缺失，不根据几何近似猜身份。

### M2 候选规则

首轮每通道最多选择 2 条路径，优先来自不同反应管；每路径先放 5 个内部候选。
在已经裁剪与适当对齐的父路径上取弧长位置 1/6、2/6、3/6、4/6、5/6，来源原帧或线性
插值均明确记录。刚体对齐只用于能量具有刚体不变性的孤立体系。

超过预算的反应管记 `not_sampled_budget`，不称为不存在或不重要。
不假设 q 沿路径单调，首版不做基于单调性的二分；两端/中间出现回越就报告并保留。
候选检查数值、原子重叠与适用域；不要求整数价键图合法，也不重判通道。

### M3 统计与分类

- 射击起点的几何固定，热动量由生产实现按 seed 初始化；不继承 proposal 的动量。
- 首版首次进入判据必须让 A/B 区域不重叠；图相同明确报 `unsupported_same_graph`。
- `p_B_given_AB=B/(A+B)`、区间和所有 excluded 计数同时报告。A+B=0 时是 null。
- 未吸收或第三盆较多时只提供有限时窗统计，诊断为未决，不能把条件比例当精确 q。
  入口 quench 不一致保留原始进入侧计数，但使动力学诊断失效，不改判以求得到好看的比例。
- 无穷长到达概率与有限 cap 有区别：通过独立终止规则校验后才能解释为其近似。
- 建议诊断带为 [0.4,0.6]：区间与该带重叠只叫 `transition_region_compatible`；
  区间全部低于/高于该带才分别记 A侧/B侧；不等于确认 q 落在带内。
- 候选未定、漂移未达协议要求、other 超阈值或预算耗尽，均保留 `unresolved`。
  默认只是诊断与优先级建议，不删除源路径、不把候选计为已验证 TS。

第一版建议 `other_fraction≤0.10`、入口核对不一致数为 0；具体漂移容差由零号测量
与现行科学协议确定，不能把现有可靠性硬门的最大容差直接当精度保证。

### M4 续跑与成本

任务 ID 由 proposal+shot 固定，seed 由已写任务表给定，不依赖执行顺序或 Python 的随机 hash。
同 seed 并不保证不同几何的射击统计独立；正式训练/验证采用不同 seed 组与来源路径分组。

完整 `ShotRecord` 写入提交标记后才计为完成；聚合结果从提交标记重建。
半写目录隔离到本输出的 interrupted 区，重新执行同任务；不删除源文件、不重算已提交发。
缺预算/缺信息写状态，不能静默降级成固定 t_free 判归。

预算包含发起数、动力学步数、quench、力/能评估和耗时。实现计数 wrapper 时必须避免
改变 ASE calculator 缓存行为；测试计数对结果与力评估调用的影响。
累计预算在每个可计量调用前检查；耗尽写显式状态，不允许最后一发无上限超支。
硬时间截止是运行限制，跨组科学比较优先用总力评估预算，并记录能评估与硬件时间。

### M5 P1 首批预算建议

| 批次 | 建议规模 | 用途 |
|---|---|---|
| 零号测量 | 1 个候选 × 8 发，新 seed | 测每发力评估/时间、记录频率与漂移；只用于确定正式协议，不进入确认统计 |
| 探索 | 最多 2 路径 × 5 内点 × 16 发 = 160 发 | 找兼容区域与两侧；检查诊断/来源/预算闭环 |
| 独立确认 | 最多 2 候选 × 100 新发 = 200 发 | 候选按跑前固定的规则从探索批选择；固定样本量重新估计 |
| 侧区抽查 | 最多 1 候选 × 50 新发 = 50 发 | 检查被诊断为侧区的几何，避免只验证模型/筛选器喜爱的候选 |

正式首批最多 410 发，另有独立零号 8 发。P1 提议沿用 T=300 K、k=160 步、cap=1280
自由步，但这些值连同步长、采样间隔、quench 设置、独立 seed 表都写入新协议。
探索 160 发的动力学步数上限是 204800；正式 410 发上限是 524800，不含 quench 的成本。
零号测量后固定总力评估硬上限与最长运行时间；预算不够时下调整批规模并在开跑前冻结。
不根据正式结果选择性加发、换 seed 或改 gate。

确认候选规则建议：先满足可解释性检查，再优先覆盖不同父路径/反应管；按点估计离 0.5
的距离排序，稳定 ID 破平局。探索批没有兼容候选时记录未定位，不强行挑点称过渡区域。
侧区抽查从其余候选按冻结 seed 抽取；若没有侧区候选，则抽未决候选并显式标记。
本批用于工程与定位验证，不把有限样本兼容判定升级为 TSE 精确重建。

### M6 的参考体系与比较臂

先用已有解析势（双井、质子接力/绕路测试台）检查两个可达通道、第三盆、回越与预算。
不能把测试台里尚未枚举/验证的鞍点当标准答案。随后选择有独立多鞍点清单的真实体系；
b05 可作候选，前提是竞争通道已确认。b04 用于带电、两碎片与映射边界。

比较臂单独命名：

- **A0**：当前 PARS 选择 + 已有精化。
- **A1**：同样候选来源与选择 + 直接射击诊断 + 精化。
- **A2**：学习 q 的候选优先级 + 独立射击核对 + 精化（Q 阶段后）。
- **A3**：增加生成桥；其余与 A2 一致（B 阶段后）。

参照集上的全量精化/独立确认是单列的参考构建成本，各臂共用；不能重复计入某一臂。
PRRS 发现成本是共用前置成本，同时给出增量成熟成本与包含发现的完整成本。
训练、端态新采样、射击、失败尝试、精化、验证均算入各臂新增预算。

建议用至少 5 个实际进入热动量/提议过程的独立 seed 组；输出按配对组的覆盖与成本，
不要把 T=0 时完全相同的运行当独立重复。冻结参考身份匹配、抽查规则、总预算与失效口径。
验证鞍点必须独立核验驻点/一负模与双侧连通性；NEB 收敛不自动等于鞍点已验证。

## 5. 学习层 Q：先学射击标签

| 任务 | 内容 | 进入/完成条件 |
|---|---|---|
| **Q0 数据集** | 收集全原子连续特征、A/B计数与实际分母，按通道/条件分组，按父路径和独立批次拆 train/validation/test | M3 统计正确；有过渡区域与两侧覆盖，不能只有两个端态；第三盆/未吸收保留 |
| **Q1 轻量模型** | 距离/内坐标 + 通道条件的小网络；以射击计数的二项似然学习条件 q | lazy import，可选训练依赖；基础 ASE/NumPy 安装可 prepare/shoot/report；变换不变性与来源防泄漏测试通过 |
| **Q2 校准与主动选点** | 用预测与不确定性选择新点；固定一部分预算抽查侧区/稀少反应管 | 独立射击评估 Brier/log-loss、校准、错误排除；未覆盖域明确弃权；按 A1/A2 同预算比较 |

第三盆占比大的数据不直接用两分类模型解释为无条件 committor；先限定解释范围，
需要时升级多盆竞争模型。Q1 是射击监督模型，不宣称实现了作者的变分 committor 算法。
初版用可验证的通道内特征，不预设跨体系泛化；小样本不能支持跨化学空间的结论。

进入 Q 的条件是标签与校准流程成立，并且直接射击的成本值得用模型分配；
若 A1 没有成本收益仍可作为动力学分析能力交付，但不能宣传搜索加速。

| **B1 条件生成桥** | 从已发现 A/B、反应原子/键差与已采样过渡附近数据学习残差/条件 diffusion | Q2 有域内校准；复杂通道存在简单提议覆盖不足；训练数据与验证分离 |
| **B2 物理闭环** | 生成候选 → 可靠性检查 → 独立射击/必要的释放采样 → 精化/验证 → 追加训练数据 | 生成频率不当平衡权重；不重建/替换反应 H；偏置段单独记录 |
| **B3 同预算比较** | A2/A3 消融，记录有效候选、罕见反应管、可信鞍点与完整成本 | 同预算提高可信覆盖或同覆盖降低成本；无效生成与训练成本全部计入 |

如果需要定向牵引，在 B2 单独测方向、步长、损伤、外部做功与释放行为，再制定协议。
不照搬蛋白 TMD 参数，也不把定向 MD 自动当正确的条件路径采样。
联合图 diffusion、相空间桥、RiteWeight/FEL、扰动策略学习均是独立后续问题。

## 7. 验收门与验证方式

| 门 | 必须证明的事情 | 对应验证 |
|---|---|---|
| **E1 身份门** | P1 自环不会合并两侧；全 H 与映射不丢；同图端态显式拒绝 | 实际 P1 fixture + 错映射/同图/缺身份反例 |
| **E2 动力学门** | 没有二次施力；seed 对应热动量；首次进入与离线逐步判定一致 | 现有 committor 测试 + 新流程端到端；删 deliver=False、改进入步比较必须使测试失败 |
| **E3 统计门** | 未定/崩溃不落入 A/B；条件分母公开；区间兼容不自动等于 TS | 注入第三盆、无吸收、入口核对不一致；检查记录与诊断 |
| **E4 溯源/恢复门** | 同任务恢复不重计数；换模型/几何/协议拒绝；半写不当成功 | kill 于轨迹/原提交/本层提交/汇总多个边界；含 checkpoint 改内容的反例 |
| **E5 隔离门** | 原 run 不变；PARS 可独立运行；默认搜索行为不变 | 源文件前后哈希、PARS boundary、PRRS digest 零差异 |
| **E6 物理门** | 成熟诊断与鞍点证据分开，精化交接保留两端与完整路径 | 独立驻点/负模/双侧连接检查；q≈0.5 但非鞍点的反例 |
| **E7 收益门** | 同预算/同覆盖的成本与机理覆盖都有可比较结果 | A0–A3、独立组与侧区抽查；P1 不用于多机理收益结论 |

改 PRRS 核心/新增模块后跑根目录 `make check`；改 PARS 时再跑 `make -C pars check`。
使用 Makefile 指定的 `openmm_dev` 科学环境与独立 ruff 环境，不因系统 Python 缺依赖而临时装包。
每个行为修复附有能失败的反例/必要变异检验；不以测试数量代替科学证据。
真实 MLP 长计算按仓库既有约定安排 kasuga02；本机做只读检查和解析势/工程验证。
