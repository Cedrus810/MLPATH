## 4. 已识别的差距（给下一个对话做分析的起点；都已实测，没有排优先级）

1. **推的方式。** 分子间压缩是两个分子沿原子对轴的刚体平移，带不出成键需要的接近姿态，比如卡宾的朝向和烯碳的锥化。证据：1.2 Å 推到 1.92 Å 仍然弹回。kick 只把动能给两个原子，能量很快散进分子内部。
2. **振幅范围。** `geometry_amplitudes_A` 最大 1.0 Å；从起点到 TS-2OMe，C:–Cb 要缩短 1.15 Å。细化只在已有振幅之间插值，不会往外扩。
3. **候选截断。** 起点的 C:–O_ald 是 4.123 Å，超过 `pair_cutoff_A = 4.0`，所以卡宾 C → 醛氧这个方向不在候选里。单凭这一点不足以解释没有 (4+1)。
4. **淬火上限。** `quench_steps = 500`；本批实测需要 527–1102 步，p001 的产物因此被漏收。
5. **起点有偏且不是最低构象。** 起点是从 TS-2OMe 退出来的；run 找到了比它低 0.21–0.22 eV 的构象。
6. **双分子体系的成键排序先验。** 软模先验分不出哪对原子会成键（见 10-09 排序诊断）；目前没有替代先验。
7. **没覆盖的族。** kick（672 个 trial）、stretch（112）、bend（288）没有做全候选扫描；kick 冒烟只试了两个方向。
