### 为什么停：一句判据逻辑不成立

现行问法（`benchmarks/README.md` 规矩 5 与 `TAXONOMY.md` 的写法）是：

> 该通道上存在确认极小 ⇒ 记为分步；**不存在 ⇒ 记为协同**。两者都是 pass。

**后半句无效。** 有限抽样只能给出"未观测到"，不能给出"不存在"。
而覆盖是被实测证明截断的（下节），所以"不存在"这个结论**在任何一次运行里都没有依据**。
这不是覆盖率低的程度问题，是推理形式的问题：把 null 当成正结论。

### 换了什么

```
旧：颜色类内排列的笛卡尔积，每个完整候选再比一次整条边集
新：逐点回溯 —— 每映射一个原子立即对所有已映射点检查 edge 与 non-edge 一致性；
    下一个待映射原子取候选最少者，同数按索引定序（确定性，且不依赖搜索顺序）
```

单例颜色类的原子候选数为 1，所以最先被固定；甲基碳一旦定下，它的三个氢就被邻接关系
约束到 3 个候选 —— 九氢轨道的 9! 分支自然裂成三个 3!。

quench_nonconverged       3        3      ← 原样
completed                68       72
realization                       rigid_bend 12 · rigid_translation 36
                                  · continuation 20 · impulse 18
```

**新增完成的是 4 个幅度样本，不是 4 个新增方向** —— 那 4 个方向此前就在选中集里，
只是它们的某些幅度被门拒了。H···H 那 11 次与 quench 那 3 次一字未变，
这是本次对照要验的第二件事，比"拒绝减少"更重要：**干预范围确实只有 bend。**

`nodes 1 · ts 0`，四个新跑通的样本也是弹性返回，**两条通道仍 `unanswered`**。

两处解释留限定，不当结论：
- `quench_nonconverged` 本身不证明"还在下降"，要由轨迹确认（下节做了，结论与初稿相反）。
- 55 → 45 s/trial 是实测；归因于"少了重试路径"缺分阶段计时支持，暂不归因。

### quench 续算：这一格唯一的反应性结局，此前被当成失败丢掉了

只把 `quench_steps` 提到 2 倍，其余一律不动，从每个样本自己的淬火起点重跑，三份分别保留
（`docs/experiments/b05_quench_continuation.py` · `runs/b05_quench_continuation/`）。

```
三个样本 59–63 步内收敛
终点  ['C4H8', 'Cl', 'H2O'] · C=C 1.3340 Å · r(C–Cl) 3.8828 Å · ΔE −1.277 eV · key 与源不同
不是极小：saddle_order 1，虚频 −75…−77 cm⁻¹，该模 99.4% 是水的天平动（实测位移权重）
```

**先前那句"残余力 224–259 倍、在下降但没走完"是错的**：那量在 `raw_endpoint.extxyz` 上，
而它是**未淬火**的 MD 端点。真实截断处 fmax 是 0.0113–0.0135，门槛的 1.1–1.4 倍。
与 build.py 那次同形的教训：**按名字挑产物，没先确认那个名字指什么。**

**三条后果，严重性递减：**

1. **`quench_steps` 是这一格的发现瓶颈，不是方向预算。** 原运行报 0 channels，
   而一条 MD 轨迹其实已经走到消除产物；淬火差 59 步，结局被记成 `quench_failed` 丢弃。
2. **软模打磨覆盖不到碎片间的天平动。** 它只处理图上的可旋转扭转，
   而水与烯之间没有扭转边，所以没有任何东西打磨它 —— 三碎片产物因此停在 −76 cm⁻¹ 的鞍点。
3. 按判据这既不是 `observed_stepwise` 也**还不是** `observed_direct`
   （那个鞍点的模是水的转动，两侧下降只会给出同一产物集的两个取向）。
   它是**续算的发现**，不回写 probe4，不算原搜索已发现的通道。

### ② 两侧下降的结果（同日，接上节）

三个 order-1 驻点各做两侧下降，六条全部**停在同一组成**（`C4H8 + Cl + H2O`）、
只有水的取向差约 9°，能量彼此 13 meV 内，**无一到达确认极小**。
负模分解（质量加权，约定见脚本）：水碎片占 99.3–99.4%，其中 **rotation 99.9–100%**、
translation ≤0.1%、internal 0.0% —— **是水的刚体转动**，此前"99.4% 在水上"不足以推出这一点。

停止原因两种，**都是预算**：三侧 `fmax_not_reached`（下降中的淬火用完 500 步 ——
本实验自己引入的混淆，续算刚证明这里差约 59 步），
三侧 `order 1 / relays 4`（淬火已收敛到 fmax 0.0085–0.0096，落点仍是一阶鞍点，中继上限用尽）。

**这一步该记的三句话，逐字如下：**

> **quench 预算曾阻止三个样本得到完整结局；补算得到一致的消除产物型 order-1 驻点。**
> 这是重要正证据，但**两条通道的正式判定仍是 `unanswered`**。
>
> 瓶颈的正确说法：**对这三个已执行样本，首先暴露的是淬火收敛预算，随后是产物驻点的极小确认；
> 未选 155 个方向的覆盖限制仍然存在。**
>
> **③（给碎片软模加打磨机制）现在没有依据**：六条下降是被两道从未放开过的预算挡住的，
> 不是被证明处理不了。先放开预算重跑，再谈是否要新机制。

## 4b 幅度阶梯与 bracket —— 未决

```
0.1 completed → m0000 返回 · 0.3 completed → m0000 返回
0.6 rejected ← collateral_bond   ← 空洞

幅度上限没扩展，`refinement_steps` 没动。

能量上限（4a）与此是不同的控制路径：第二次探针 `ts` 从 0 变 1 而 `brackets` 仍全 0，
证实放宽上限不会让阶梯长出 bracket。**但 bracket 与 collateral 不是独立问题** ——
probe3 证实了后半句：修的是 collateral 那一侧，长出来的是 bracket。
