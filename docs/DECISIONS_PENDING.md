### 附带修掉的一个真实缺陷：负 seed


**原因已更正（2026-09-05，用户核查）。** 初稿写的是"只有最高一级反应，没有下一级可比"——
落盘数据不支持：

```
0.1 completed → m0000 返回 · 0.3 completed → m0000 返回
0.6 rejected ← collateral_bond   ← 空洞
1.0 completed → m0001 离开
```

细化只比相邻样本（`search.py:1361`），(0.3,0.6) 与 (0.6,1.0) 都因为 0.6 是拒绝点而不成对。
**是 collateral 拒绝隔断了唯一有效的"返回→离开"对 (0.3, 1.0)。**
若 0.6 有效返回，现有实现就能成 bracket——不用加档、不用改阶梯。

**所以这不是独立于 collateral 的问题**，次序是先修扰动交付再评估扫描策略。

**待决的问题**：

**修完扰动交付之后再判**：同一阶梯能不能形成有效 bracket。
若仍有缺测区间，扫描要显式区分**返回 / 离开 / 被阻断 / 未知** ——
不得把拒绝当返回，也不得无记录跳过。幅度上限扩展是**另一项干预**，
需预先定义预算与停止条件。

能量上限（4a）与此是不同的控制路径：第二次探针 `ts` 从 0 变 1 而 `brackets` 仍全 0，
证实放宽上限不会让阶梯长出 bracket。**但 bracket 与 collateral 不是独立问题。**

## 4c collateral —— 诊断完成，三选一未决

**是位移实现，不是必要耦合**（实测见 `benchmarks/b04_sn2_chloride/PROBE_2026-09-04.md`）。
契约已钉成测试：被驱动的键豁免、其余键的损伤仍拒绝。

三条路各自要保住那两半：改位移实现（让 bond 也走刚体片段，torsion 已有先例）
/ 引入通用复合驱动支持 / 修订阈值。
