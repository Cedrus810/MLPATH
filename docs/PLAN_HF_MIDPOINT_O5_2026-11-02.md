## 1. 要回答的问题

在同一 q 上、从同一起始几何出发、同一阈值（1e-3 eV/Å）和同一步数上限（200），换一种只用力的优化器，能不能让 BFGS 停不下来的中点松弛收敛？收敛到的反力与正常中点相比是否一致？

只回答"能不能收敛、代价多少"。不改 `ts_ef.py`，不改阈值、界线和门。要不要把哪种优化器接进代码，看结果后由用户定。

## 6. 结果（2026-11-02 跑完，11-04 汇总）

同帧冷启动、同阈值 1e-3、同 200 步：FIRE 在近根卡点收敛 33 / 38（BFGS 0.05 Å 3 / 38，BFGS 0.01 Å 5 / 38），远根失败帧 54 / 71（3 / 71、4 / 71），对照 28 / 30（23 / 30、24 / 30），forward 都更少。收敛反力在重复之间、与 BFGS 之间都相差 ≤ 0.004（σ_c 以内）。仍有 3 个近根帧和 17 个远根帧 FIRE 未收敛。接入代码后的整条 HS 效果未测。

## 未确认（Claude 推断）

- FIRE 的默认参数（`dt`、`maxstep` 等）未针对约束松弛调过；若 A2 表现差，不能说明 FIRE 本身不适用。
- 冷启动与实际运行带入曲率不同（11-01 冷启动对照显示带入曲率略有帮助），各臂都用冷启动是为了可比。
- N 组的起始帧要靠重跑 v4 得到，fp32 不可复现可能使重跑的卡点与验收时不完全相同。
