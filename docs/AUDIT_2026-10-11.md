## 1. [P2] PARS 代表路径不核验逐帧元素序列

位置：`pars/src/pars/cli.py:355–375`，`_candidate_from_seed`。

读取时只对每帧 charge/spin 做比较，`numbers` 则只取首帧。
同样原子数的后续帧即使换了元素，也会被用首帧元素重建后送入 NEB。
上游 `PrrsRun.load_trace` 的映射检查没有覆盖独立精修读取代表文件的入口；
`seed_sha256` 记录文件内容也不验证该内容是否符合路径契约。

反例：七帧文件的中间一帧为 He，其余为 H。读取不报错，整个链被重建为 H，
解析势后端返回 `ci_neb_converged`、`connectivity=matched`、势垒 1.0 eV。
这里认证的是重建后的 H 链，不能认证输入文件所记载的物种序列。

修复出口：在任何精修计算之前检查每帧原子数与元素序列一致；同时核对
candidate/channel/provenance/image 的一致性及文件所代表的选中 ID。
不同元素序列、拼错代表文件或乱序帧应拒绝，正确的 select→refine 链应保持可用。
同元素原子的置换仍须由生产者保留映射，元素比较本身不能识别它。

## 2. [P2] 重复 attempt ID 绕过账本逐行核验

位置：`pars/src/pars/adapters/prrs_run.py:79–80,96–104`。

`_attempts_by_id` 用字典覆盖同 ID 的前一条记录；`checked_attempts` 再按 ID 查该字典，
因此看起来逐行核验，实际重复核验的是最后一条。
一次失败/非反应的重复记录，可以被后面的 completed/reactive 记录遮住。

反例：在 `t000001` 的 reactive 行前插入同 ID 的 failed/elastic 行。
读取与 ingest 不拒绝；两条经过核验后都变成 reactive，`t000001` 被导入两次。
后续按 candidate ID 建字典的 archive 又会折叠重复候选，导致计数口径不一致。

修复出口：构造索引前拒绝任何重复 attempt ID，并让 result 的比较绑定当前账本行。
重复相同行也不能静默扩充样本；重复冲突行必须在过滤前拒绝。

## 3. [P2] mature 接受与批次条件不一致的射击记录

位置：`mature/src/mature/io.py:330–364,376–382`。

`ShotRecord` 检查字段形态，但 `OutputStore.commit` 没有核对当前 protocol、
任务分配 seed、角色和实现来源。汇总只按 proposal ID 分组。
外批记录既可以占用本批任务，又可以混进条件统计。

反例：当前任务 seed 为 100000，提交 seed=999、另一 protocol hash 和另一
implementation hash 的 A 记录。提交成功，`p1#s0000` 被记为 done，pending 从
16 降为 15，估计中计入 1 发。

修复出口：提交和恢复读取都绑定本批 protocol、角色、已分配 task/seed，以及
明确冻结的执行实现；未知任务、外批协议、错误 seed 在写 marker 前拒绝。
确需比较不同条件时另立批次或显式分组，不能混成一个估计。
本项影响当前 M1 库的契约；M3 射击/正式 CLI 尚未实现，不是已经完成的科学批次出错证明。

## 4. [P2] mature 读取 commit marker 不重验内容哈希

位置：`mature/src/mature/io.py:301–310,346–349,367–371`。

写入 marker 时保存了 `record_sha256`，但完成清单与统计不重算；幂等重提也仅比较
存储哈希，没有比较它与当前 marker payload 的一致性。
因此结构合法但内容已变化的 marker 可以继续被当成提交凭据。

反例：先正确提交 A，再仅把 marker 的 `record.outcome/entry_side` 改为 B，保留旧 hash。
`shots/.../result.json` 仍为 A。恢复成功、重提原 A 返回成功，汇总却得到
`p_B_given_AB=1.0`。脚本确认存储 hash 与 marker 内容重算 hash 不一致。

修复出口：完成/恢复/重提/汇总共用一个校验入口，核对内容 hash、marker 的
task/proposal/shot ID 与路径/内嵌记录一致，并明确 result.json 与 marker 的权威关系。
任何不一致应在跳过任务或汇总之前拒绝；幂等重提不能吞掉损坏凭据。

## 5. [P2] b09 的 TS 来源起点不足以推出“最有利”或“差距下界”

位置：`docs/B09_GAP_ANALYSIS_2026-10-10.md:15`。

该句从“起点由 TS-2OMe 退向反应物后极小化”直接推出“对 PRRS 最有利”和
“差距是下界”。TS 来源能证明构造上的通道偏向，不能证明它比其它接近姿态、
反应物构象或热系综起点更有利；后续极小化也不保证保留最易交付扰动的几何。

### ALG-01 · [P2] 原始 Å / rad / eV 不能混成一个触发严重度

**已确认问题。** `pars/src/pars/frontier/objectives.py::trigger_severity` 直接返回
`perturbation_amplitude`，忽略 family/unit。`normalize.py::fit_normalization` 在通道内对
该列统一做 median/IQR，只能统一不同目标列的尺度，不能让同一列里的长度、角度和能量可比。
PARS 原设计 §8.2 的限定是“under the specified perturbation family”。

新探针显示：只比较该目标时，0.2 eV kick 支配 0.5 Å stretch；把同一长度表示成
0.05 nm 后，支配方向反转。0.2 Å 与 0.2 eV 也被当作相等。
**nm 只是量纲思想实验，当前 PRRS 固定输出单位，不是已发现生产者会换成 nm；**
探针没有经过 ingest，也没有证明某条真实路径已被删除。
但当前混合族的严重度排序本身缺乏共同含义。

**改进方向。** 先冻结比较规则：同族、同单位内比较；跨族保留不同维度／比较分组，
或者使用经过独立校准的无量纲干预成本。简单 `a/a_ref` 可以定义搜索策略尺度，
仍不能自动解释为相同物理难度；几何位移的势能变化也不能直接当作 kick 动能的等价物。
记录原始 family/amplitude/unit、转换尺度和可比性政策；没有校准时保守保留跨族候选。

**验收。** 同一物理输入经过正确单位转换后选择不变；未校准的 Å/rad/eV 不产生
凭数值大小决定的跨族支配；同族正确排序保持。再以实际混合族候选池比较精修覆盖和成本。

### ALG-02 · 反应管需要保留同键事件中的几何路线

**结构性限制已确认。** `pars/src/pars/paths/fingerprint.py` 只用逐帧键集合的
Jaccard/Frechet 距离；`cluster.py::build_tubes` 不读取坐标。
两个共享端点、中间映射原子距离分别为 1.118 与 2.062 Å 的合成路径，
给定同一键序列后距离为 0，被放进一个 tube。
这证明描述符无法区分它们，**没有证明它们是真实的两个鞍点，也没有执行 archive 删除反例**。

现有 archive 已先建管、再在管内压缩，`test_mechanism_pruning.py` 也保护不同键事件顺序，
不能把这些说成未实现。限制在于“几何上不同但键事件相同”可被归为同管；
只按目标空间覆盖的代表选择未必保留这些区别。
项目已有 [解析双鞍点夹具](../benchmarks/pars_two_saddles/README.md)，
仍需专门检验同 A/B、同键事件的几何分辨以及真实分子多鞍点覆盖。

**改进方向。** 在权威映射和键事件之外增加连续路径描述符：反应区域映射距离、
角／扭转、碎片相对姿态或局部路径形状。保持整体平移／正旋转不变性，
明确原子置换与手性处理，不能靠反射对齐抹掉立体路线。
联合几何覆盖与目标覆盖保留代表、备选和冷区救援；检查 leader 聚类对 ID 重命名的敏感性，
“排序确定”不等于“分组不受命名影响”。

**验收。** 先建立独立认证的同连接多鞍点参照池，标签只用于事后评分。
分别测输入池覆盖、选中代表覆盖、认证成功覆盖及错误合并，不能把发现层没找到的鞍点
算成选择层漏掉。小型两鞍点参照要求保留并认证 2/2；真实体系在同求值预算下比较
原算法、几何保留算法和预先冻结的基线选择规则，并报告重复精修成本。

### ALG-03 · 一般接近姿态与协同扰动，需要回到表示设计

**目标能力缺口。** `src/prrs/perturbations.py::FAMILIES/propose` 是单 bond/angle/dihedral
的 displace/kick/pulse。已有 `fragment_rotations` 服务软坐标 polish，
不是独立的广覆盖发现提案；也不能把现有 fragment translation 辅助函数误写成不存在。
原设计 [§3.4/§19.1](../mlp_native_perturbation_response_reaction_search.md) 的多坐标表示
尚未形成一般发现族。

既有 b09 文档记载 compress 84×4 全执行仍无反应、刚体压缩到 C–Cb 1.92 Å 后弹回；
人工强推 +6.16 eV 到产物只说明可达性，未证明鞍点或期望机制。
这些支持检查姿态／协同表示，不能证明某个新方案必然有效。

**改进方向。** 独立采样碎片相对平移、朝向／旋转，再结合低维内部协同变形；
也可比较已有 pulse 的动态响应与新多坐标提案。记录实际交付运动、附带变形、
注入能量和相对姿态覆盖，保留碰撞、共价几何与模型可信门。
谱排序应评分实际交付方向，10-09 的 `delivered_direction` 修复沿用。

**验收。** 先在简单的双分子／协同多通道参照上比较 pulse、单坐标、姿态与协同提案，
固定总求值预算、多 seed／独立反应物构象，并分报新连接、认证鞍点与门拒。
discover 不使用已知 TS 或 b09 特定成键原子对作提案先验；之后才盲测 b09。

### ALG-04 · 排序需要覆盖保底，并利用非反应响应

**源码范围。** `propose` 有族间 round-robin、谱排序与种子随机排序，
没有按历史 trial 响应更新一般方向效用；搜索已有网络扩展和振幅细化，
不能概括成“完全不自适应”。同碎片间压缩的谱重叠主要区分平移轴，
源码已有这项局限说明，不能依它声称化学成键优先级可靠。

**改进方向。** 在族配额之外加入原子对／位点、运动类型、碎片姿态的覆盖保底；
对 `pair_cutoff_A`、对称归并、活性域造成的候选域排除单独记账，
完整执行候选表不等于完整覆盖一般反应空间。
先完成已选方向的粗扫，再用 return/departure、重排、新颖性、可信度、失败原因和成本
分配剩余预算；不必先引入学习模型，更不能因为没有 reactive 标签而丢掉全部响应信息。
网络层增加源节点／微态间的探索保底，避免先处理源的细化耗尽全局预算；
这是要比较的策略，不是本轮已复现的调度错误。

**验收。** 同求值预算比较谱排序、族内均匀、位点／运动分层，以及增加响应反馈的策略；
冻结最低覆盖和探索份额，报告 selected/executed/excluded/censored、每源花费、
可信新连接和多通道覆盖。connect 的目标优先队列也须保留探索退路并做消融，
不能把一个绕路反例直接解释为队列算法失败。

### ALG-05 · 振幅探索与响应时窗应有独立资格

**源码限制。** `search.py::finish_scan` 在既有相邻 coarse 的 return/departure 间细化，
不会自行探索表外振幅。它已经声明局部窗口、没有假设全局单调性；
`window_semantics` 与 `audit-windows` 也已存在，不是要从头补建。

**改进方向。** 在预先冻结的安全域和成本内，按响应类型增加振幅覆盖或有限外扩；
保留多窗口与非单调响应，gate/failure/unresolved 不能强制二分到 return/departure。
先试可逆参数域，再决定是否更换表示；无限加力度不是一般优化方案。
另对响应时长、时间步、温度和判归滞后做资格比较；强迫段、自由段、淬火证据分开。
普通响应从反应物出发，不能直接套用射击内点的“初始即首次进入 A”停机规则。

**验收。** 在冻定位移／能量域内比较产物与未决率、窗口漂移、门拒和实际成本。
时窗未稳定时明确报告条件依赖；仍标 finite-horizon response，
局部临界振幅不是静态盆地边界、自由能垒或反应速率。

### ALG-06 · 淬火应按收敛证据恢复，优化器收益要过完整链

**已有依据。** `runner.py::quench` 使用 FIRE 与交替 soft polish；`quench_steps`
约束每次 minimize，不是包括 polish、曲率和重启的总求值上限。
既有 b09 完整重放在较大上限下收敛了 25/26 个失败端点，余下 `t000327` 仍未决；
p001 的 FIRE/BFGS 步数对照不等于整体搜索收益，也不能直接接受原失败端点为产物。

**改进方向。** 依据力残差下降、polish 收缩、几何门与总成本作有界 continuation／恢复；
允许不同优化器或信赖域预条件方案，但对所有符合条件的失败端点采用同一规则，
不能只救看起来成键的端点。对软坐标交替不收缩，比较耦合优化而不是无限加轮数。
负曲率仍交给极小／鞍点判别；既有 B′ 策略是未启用的独立决定，不能顺手打开，
也不能放松全局力与曲率门来提高表面收敛率。

**验收。** 固定真实势能求值预算，对完整 `quench→polish→confirm_minimum` 链
比较 FIRE 与备选：收敛率、最终映射盆地、极小阶数、可信度、失败／未决和墙钟。
测试包含无键变化、成键、软复合物和碎裂，不能用一个已知产物或优化步数比作全局结论。

### ALG-07 · 局部软模鞍点不应吞掉全部精修预算

**已有风险。** b09 文档中的 37 个软复合物 `ts_candidate` 不是反应鞍点覆盖。
PRRS 局部候选与 PARS 的 CI、曲率、两侧下降／端点匹配已有独立门，继续保留。
要区分“种子重复、局部非反应软鞍点”与“同连接的不同真鞍点”，后者由 ALG-02 保留。

**改进方向。** 以已认证的局部结果和连续几何描述符去重种子；按反应区域交付响应、
路径质量和不确定性分配精修预算，低优先候选保留抽审／救援，不能按低能量软模
启发式硬删。测出需要后再比较不同 NEB 图像分配／重参数化与 dimer 种子策略；
改变图像数会同时改变当前曲率目标，必须重新冻结比较口径，不能当作纯加速。

**验收。** 同成本比较可信 index-one 且两侧匹配的独立鞍点数、假接受、
真鞍点错误排除、重复种子耗费与分辨率稳定性。端点、全路径及 Hessian 采样的
不确定性检查保留；cheap screen 的收益不能代替最终认证。

### ALG-08 · 先有完整求值成本账本，才能说算法更好

**必要前置。** 现有 `max_trials`、方向账本和局部 `force_evaluations` 并不提供
全链统一实际成本。同一 trial 的 MD、polish、Hessian、爬鞍点或精修花费差别很大。
只固定 trial 数可能让一条算法多烧大量势能求值，看起来更有效。

**改进方向。** 在实际 calculator/model 调用层记录：MD、quench、polish、谱排序、
极小确认、爬鞍点、两侧下降／relay、shoot、NEB；包含失败、重试、恢复重算。
区分 ASE 缓存命中与真实模型 forward，记录 committee 成员调用及 CPU/GPU／I/O 墙钟。
保留原 trial 硬上限，再单独冻结共同实际求值／墙钟预算，不能静默改旧预算定义。

**验收。** 小型解析势的调用计数与外部计数器一致；缓存、门拒、Hessian、
kill/resume 等分支不漏计。随后用认证新连接／鞍点覆盖对总成本作比较，
重复 seed 的分布和预算截断同时报告；先定义改善判据，后看留出体系结果。

### ALG-09 · 长粗扫需要更细的可靠续跑，性能项逐一测量

**源码确认。** `search.py` 在出队微态前保存 resume point，粗扫和细化共享微态事务；
中断会重放两轮。它已有一致性回归，不能称为结果错误，但长微态扫描恢复成本大。
`publish()` 仍在每个 trial 全量构造／发布网络，反应边重扫 TS 支持；
`soft_internal_modes` 有本次进程内的微态缓存，极小确认阶段的谱尚未直接复用到提案。

**必要能力与测量候选分开。**

- 长扫描续跑：考虑 coarse batch／scan 的确定性原子提交；同时保存方向账本、
  队列与 admission 状态、RNG、预算计数、待细化列表。每 trial 落盘并不等于已能
  安全从该 trial 续跑；不能只提前移动 resume point。
- I/O：测 `publish`、schema 校验、轨迹读取与 NFS 写放大；有效后才考虑增量事件／
  分区快照和 TS 端点索引。必须保留恢复所需的完整状态及既有读者契约。
- 曲率／身份复用：只有几何、物种映射、电子态、质量、模型和相关配置均一致才复用。
  全 Hessian/密集谱在大体系的成本需要测；HVP/解析 Hessian 可用于排序候选方案，
  不能以少数低模或局部活性 Hessian自动代替完整极小／鞍点阶数认证。
- 独立 trial／shoot 的并行或批量 model forward：先测 GPU 利用率、内存及批量收益；
  隔离可变 calculator/Atoms，冻结 seed 与结果提交顺序，避免并发改变网络搜索轨迹。
  SIMD 几何、对称映射、图缓存等同样先 profile，身份未认证时不能启发式归并。

**验收。** coarse、refine 和辅助候选阶段分别 kill→resume，与不中断运行比较
所有最终身份、账本、RNG、提交次序及预算；统计真实重算成本是否下降。
性能优化按 [09-28 的协议](REVIEW_2026-09-28.md) 测量→冻结判据→单项干预→digest／回归／变异检验。
旧 PERF-01…28 是静态候选，不能全写成当前必须落地；PERF-02 的 basin calculator 复用
和 PERF-11 的 watcher 文件缓存当前已有实现，本轮从源码确认，不重复列为待修。
未测出瓶颈的批量、缓存或向量化留在候选区，不承诺加速倍数。

### ALG-10 · 多机制覆盖之后，射击诊断与模型资格仍要单独完成

**当前边界。** mature 的 M0/M1 已有记录与 53 项回归；M2 候选提取、M3 射击和 M4
正式 CLI 编排尚未交付，旧 `mature/README.md` 状态早于 M0/M1，不能照抄其“全未开始”。
PRRS 现有 shoot/first-entry 可复用，不能重写一套动力学然后混入旧统计。

**改进方向。** 按 [现有成熟层计划](PLAN_GEN_COMPAS_MATURATION_2026-10-03.md) 完成
代表管内点提议、独立热动量射击、只读首次进入判归、未吸收／第三盆／门拒的独立计数，
以及内容绑定的提交／恢复与精修交接。固定候选几何、盆区、温度、时窗、seed 和预算；
不把扰动轨迹或错误协议混成热射击。分支采样位置和条件必须事先定义，
`p(B|A或B)` 与含未决／第三盆的总体去向分布分别报告，ambimodal 分支比需要相应参照。

是科学接受前置，不能靠“更优化的搜索”补出模型正确性。

**验收。** 单发同几何／seed 对照既有 shoot；第三盆、未吸收、失败不挤入 A/B；

### 甲基、普通扭转与软转动如何节流（讨论稿，未冻结）

本节回应“如何不在甲基／扭转等运动上浪费时间，方案还没想好”。
建议首先控制重复工作和预算升级，而不是按基团名删除自由度；具体额度、筛选阈值和
构象选择规则仍待比较，没有自动转成生产规则。

**当前源码确认的边界。**

- `rotatable_torsions` 已区分 genuine 与对称 rotor，位移幅度已有基本周期及近对称零位移过滤。
  这不等于甲基任意角度都等价：甲基势垒、与环境／反应的耦合仍可能存在。
- `_dihedral_directions` 给 genuine/rotor 的排序值分别为 0/1；`propose` 有谱时会将
  这个字段整体替换成 `-spectral_overlap`。因此“对称 rotor 永远靠后”没有独立策略保证。
  这是本次源码检查，尚未跑真实谱反例，不能声称它已经导致某个历史预算浪费。
- `Registry.note_trial` 对所有 trial 都增加 node/state 的花费；现有化学节点容量与构象容量
  已分开，但转子、构象和一般化学试探并没有独立、可审计的求值成本份额。
- polish 已检查梯度和曲率；仅低曲率不足以视作 free。旧 3-oxobutanal 甲基“低曲率但
  有梯度”的误判已有修复，不能通过重新忽略梯度来省时间。
- `finish_scan` 的局部鞍点搜索会考虑 `ts_candidate`，仅出现软转子边界也可能获得后续分析；
  需要限制重复升级，而不是把所有此类候选当作已知无反应。

**推荐先比较“分账、限额、去重”的方案。**

| 运动／工作 | 建议处理 | 保留的出口 |
| --- | --- | --- |
| 已认证的对称副本 | 只保留基本周期与一个等价代表，身份不变 | 认证不足时不合并；不将所有甲基角度视作副本 |
| 重复、已认证的局部转子鞍点／同盆返回 | 缓存证据；限制再次细化、爬鞍点、IRC／shoot 的投入 | 小额抽审；不同局部环境、模型／配置变化时失效 |
| 非等价的甲基与普通构象扭转 | 单列有上限的构象探索成本；保留少量姿态有区别的极小 | 对新可达方向／非重复响应保留再次分配预算的机会 |
| 分子间相对朝向／与反应耦合的扭转 | 作为接近姿态／协同提案候选保留 | 不因其低频或未改键而永久降为无关运动 |
| 端点打磨中的软转子 | 按残差与收缩证据选择有界优化；将反复往返记为未决 | 接受端点前仍过完整力、曲率、映射与模型门 |

构象保留不能只按最低能量，也不能拿全分子 RMSD 中的甲基 H 转动当作充分新颖性；
需要同时看可靠的对称映射、非等价骨架／局部接触和实际交付方向的覆盖。
这些是排序／分配依据，不是“反应相关性已证明”的标签；不能依赖已知目标键或 TS。
片段相对转向尤其不能当作整个体系的无意义刚体转动删除。

实现时把策略优先级与谱分数分成独立字段，谱只在已定义的策略层内排序；
分别记录 rotor/conformer/general-probe 及下游分析的实际求值成本，
保留 `max_trials` 等原硬限，再冻结各层额度、保底与升级规则。
源微态内仍先完成**已选粗扫集合**，后细化。未选／限额略过的方向继续记为覆盖受限；
不能把压低转子份额后的 sampled 运行称为整个原候选基 exhaustive。

**暂不推荐的两种捷径。** 全关 torsion 会丢失构象入口；在自由响应中冻结全部甲基／
扭转会改变动力学和可达性。若研究局部预松弛或受限准备，它必须作为另一个明示的
干预保存输入／源状态与释放约束后的核验，不夹进旧协议；不放宽全体系接受条件。

**最小决策实验。** 不先猜 5%／10% 等比例，先在明确的现有样本中分解上述各项成本，
随后冻结同总求值预算的原策略与节流策略。测试同时包含纯对称副本、真实扭转极小、
甲基低曲率但梯度不小、扭转准备后才能发生的反应，以及双分子朝向入口。
验收同时要求重复花费下降、真实构象／认证反应覆盖保持、门限不放松，
并报告对新入口的错误压制和预算截断；未测出收益就不将策略设为默认。
本次只补了讨论与源码依据，没有运行该决策实验，也没有改算法。

### 7.3 最容易混淆的科学缺口

1. **有四个一阶驻点，不等于连接／分岔已成立。** 先用已知参照做两侧核验与
   受控轨迹资格测试，给搜索提供可评分的参照；已知 TS 只用于这条参照线和事后评分，
   不喂给 discover。如果目标 PES／协议下的参照分支尚未建立，不能把分支未复现全归因于搜索。
2. **MLP／论文的动力学条件不同。** 仓库预检使用气相 POLAR-1；提供的 SI
   [Computational methods](../benchmarks/carbene_ambimodal/si/ja5c13906_si.txt) 记载
   SMD 溶剂 DFT、Progdyn 准经典 TS 起始轨迹，二甲氧基卡宾使用 384 K、1 fs，最长 500 fs。
   当前 PRRS 探针是 0 K 的强迫响应后淬火；`runner::shoot` 是固定几何加经典 Maxwell 动量。
   更改温度或启动 shoot 不自动得到论文的同一初始系综；振动／坐标抽样等细节需另外核对冻结。
   先验证 POLAR-1 上定义明确的经典动力学结果，再决定如何和论文参照逐层比较。
3. **(4+1) 的短时分岔与 (2+1) 后重排是不同问题。** 入口 ambimodal 去向、竞争入口 TS、
   TS-2OMe-2 重排以及最终实验产物需要分别归因；不能用单一射击窗口同时声称全部复现，
   也不能把经典条件下的短时比例直接拿来拟合最终实验产物比例。
4. **省掉甲基工作不等于补上反应运动。** 预算去重／分账能减少浪费，
   接近姿态与协同内部变形仍须主动探索。相对碎片朝向尤其不能归入整体刚体无关运动。

### 7.4 修复与研究的依赖顺序

- **A：可信入口。** 关闭四个新数据契约缺口；混合族选择前修 ALG-01。
  已有延后 fingerprint 事项保持用户裁决，只在实际使用受影响 factory 的新证据链中明确限制。
- **B：可以比较。** 冻结 b09 分层判据和独立起点协议；建立已知参照的连接／动力学资格，
  补全实际成本账本。此处需要新实验的步骤本次没有执行。
- **C：发现能力。** 在简单多通道体系固定预算比较姿态／协同／已有 pulse、响应反馈、
  有界振幅／时窗与完整淬火恢复；同时比较甲基／软转子节流，保留探索底线。
- **D：保留与精修。** 用独立认证候选池比较同键事件的几何反应管、代表覆盖与局部鞍点去重；
  按实测推进续跑粒度／I/O／安全复用，接 mature M2→M4。
- **E：b09 盲测与科学门。** 独立构象／姿态起点，不用参考 TS 作方向提示；依次报告
  连接发现、三个入口 TS 覆盖、重排连接、条件化分支及独立 QM 证据。

e3nn 类网络是 C 的**候选提案模型**：可先学候选评分，再比较等变协同位移生成。
它不能替代 A/B、PARS 几何保留或分支系综资格；先有覆盖明确的响应数据与留出体系，
再以同成本的可信新连接／鞍点覆盖决定是否需要学习层。
不启动旧全族 1408-trial 计划，也不因本节排序擅自修改任何设计承诺或实验配置。

## 8. 拉伸试探、自动探索与“每次都付 MD 成本”的结构问题（讨论稿）

用户指出：“自动探索要么像瞎探索，要么探索不够，每次还需要 MD”。
这是提案信息效率与验证成本的设计问题，不能靠换一个排序网络或全面增加预算直接解决。
本节比较可能的流程，不改变原 PRRS 的有限时窗响应合同，也未实施或测出收益。

### 8.1 当前到底如何试

- `perturbations.py::_bond_directions` 对已有键枚举 stretch，对满足候选域的非键对枚举
  compress，再由配额／谱／优先级选择。它是结构化探索基，尚不能解释为已经学会选择反应入口。
- stretch 和 compress 共用 `geometry_amplitudes_A`。相同绝对位移并不是不同键长、
  刚度或环境中的相同激发尺度。交付主要按几何实现；刚体分割存在时平移两侧，
  环内等情形恢复非目标共价键长，没有用目标 PES 自动寻找协同低代价的交付路径。
- `runner.py::run_trial` 已有 MD 前的几何、能量／力等可信门，不是完全没有筛选。
  通过这些门的已执行普通候选进入自由 MD，然后 quench/classify；在 b09 主批即
  每次最多 200 步自由响应，后续还付 polish、极小确认及可能的鞍点分析成本。
  未选候选和前置拒绝并不会全部跑 MD。现有前置门主要回答“能否可信执行”，
  尚没有统一的“该候选下一层值得投入多少成本”的机制。
- 只统计 MD 步数也不够；quench／Hessian／软模等可能很贵，完整成本要用 ALG-08 实测。

### 8.2 可以先比较分级投入，而不是全量候选立即进完整流程

| 层级 | 工作 | 信息与用途 | 不能据此声称什么 |
| --- | --- | --- | --- |
| L0 | 对称／实际交付运动审计、几何域与接近姿态生成 | 识别已认证重复与不同提案，保留探索分层 | 所有相近运动都化学等价、所有方向已覆盖 |
| L1 | 有界的小位移能量／力响应；可选有限约束松弛或可复用局部曲率 | 比较注入代价、耦合变形、有效交付、可信域及新颖性 | 一次回弹或能量升高证明没有反应路径 |
| L2 | 按冻结策略分配进一步局部搜索或短响应探测 | 将信息不足／新颖／不同方向的候选保留并升级，记录未决和成本 | 未升级候选就是 elastic 或无反应 |
| L3 | 对选定候选跑定义明确的完整响应／端点确认 | 获得原 PRRS 响应证据，或另定义的证据类型 | 完成响应等于鞍点或速率认证 |
| L4 | 精修、index-one 与两侧连接核验；独立动力学／分支统计 | 分别关闭驻点、网络连接和动力学门 | 静态连接直接决定动态分支比 |

L1 可比较按局部刚度与有界实际能量代价自适应幅度，而不是所有键套同一 Å 表；
小扰动的局部模型只用于初始尺度／排序，非线性区域必须重新评估。
约束松弛会改变提案准备方式，保存真实准备段、释放点和来源；它不是自由 MD。
Hessian/HVP 和局部优化也要付模型调用成本，不能只因为不叫 MD 就默认便宜。

低幅度下的恢复力、正曲率或能量上升都可能出现在真实跨垒方向上，不能用作
硬排除反应的单一判据。筛选政策需保留分层探索配额、低评分抽审与未决候选的救援，
测错误排除和遗漏机制，保留候选→便宜试探→升级／暂缓的账本。
不得把 L0/L1 的“粗扫”重命名成旧协议的 MD coarse 覆盖；原有“先全部粗扫后细化”
规则继续约束选中的原协议响应集合，新筛选层另立合同。

### 8.3 若目标是找连接／鞍点，另一条路线不必先经过完整 MD

可以独立比较“多样化局部种子→势能面激活／最低模跟随→鞍点→两侧下降”的发现支路。
[dimer 的官方描述](https://docs.ase-lib.org/ase/dimer.html) 是由单点出发找鞍点，
使用一阶导数；[activation-relaxation 原始方法](https://arxiv.org/abs/cond-mat/9710023)
以极小→邻近鞍点→新极小组织事件。它们支持探索静态连接，不要求每个种子先产生
完整物理 MD 轨迹，但仍需合适种子、多方向覆盖、模型求值及最终认证。
不能承诺它们在本项目更快，也不能以最低模为唯一方向而再次只找到甲基／复合物软鞍点。

PRRS 已有局部爬鞍点原语；将其移到 MD 之前作为独立发现支路，是方法范围的改变，
不是修改一个 `response_steps` 参数。路径证据要标为 PES 搜索，并单独定义接入 PARS
的契约；没有实际 MD 的结果不能伪造 DiscoveryTrace、有限时窗响应或热采样证据。
这条静态支路也不能单独回答 b09 的 ambimodal 分支，后者仍需规定条件下的动力学。

### 8.4 先定目的，再选方法

两个比较臂分别是：**保留 PRRS 响应发现、增加便宜筛选与分级投入**；
**增加独立 PES 连接／鞍点发现支路，再作动态核验**。
它们可以比较或互补，但不混用验收含义。e3nn 类学习模型可负责评分或协同提案，
是否使用它应晚于输入／输出／响应标签及成本定义。

最小比较先采用较简单的独立多通道参照，固定真实模型调用预算；报告输入方向／
姿态覆盖、经过各层的数量、筛选错误排除、可信新连接／独立鞍点、总花费及未决率。
成本节约只有在未以漏掉真实机制换取时才有意义；对有限搜索的 null 保持范围限定。
本次没有开启拉伸／MD 对照、修改已有配置或将上述任一支路设为默认。
