## 1. 为什么转向适用性

- 定位层已过关：成键窗口定位器在与 PBS 29729 同设置的回归里，b04 / b05 首次命中提前 1.8–6 倍、b05 三个参照全中、总花费约降到 1/3；N1 召回不变；b09 自动定位到"反应物 → (2+1)"一阶鞍点（DONE_LOG 11-26）。

## 2. 冻结前要定的规则（待用户定）

### 2.1 双对层（证据：`benchmarks/afir_mc/double_layer_census.py`，`results/2026-11-26/double_layer_census/census.json`，只读）

双对组合按两对原子是否跨片段分三类：II 两对都跨片段；IX 一对跨、一对片段内；XX 两对都在片段内。

| 运行 | II：条目 / 路径 forward / 新事件 / 一阶参照匹配 | IX | XX |
| --- | --- | --- | --- |
| N1 sA（29729） | 182 / 72 345 / 1 / 2 | 1 348 / 476 608 / 0 / 0 | 1 734 / 146 689 / 0 / 0 |
| N1 sB（29729） | 716 / 71 931 / 1 / 2 | 5 481 / 534 636 / 0 / 0 | 7 161 / 164 655 / 0 / 0 |
| b05 sA（29729） | — | 164 / 29 220 / 1 / 4 | 231 / 25 659 / 0 / 0 |
| b05 sB（29729） | — | 254 / 51 898 / 2 / 15 | 330 / 37 342 / 0 / 0 |
| b09 sB（第一阶段） | 349 / 8 756 / 0 / 0 | 9 979 / 244 019 / 1 / 0 | 41 349 / 372 539 / 0 / 0 |
| b09 sB（window 回归） | 349 / 12 117 / 0 / 0 | 9 979 / 309 051 / 1 / 0 | 41 349 / 475 414 / 0 / 0 |

（"条目"含预算用尽未跑的；"路径 forward"只计 AFIR 路径本身，不含两端极小化与定位。）

- XX：六次运行 0 个新事件、0 个参照，却是 b09 双对层的最大花费。
- II：N1 的 DA 参照全部来自这里，花费最小。
- IX：b05 的消除参照全部来自这里（OH⁻ 夺 H 同时片段内 C–H / C–Cl 变化），不能删；N1、b09 上 IX 花费大、产出 0 或 1。

选项：

| 选项 | 内容 | 依据 / 风险 |
| --- | --- | --- |
| D0 | 不改 | — |
| **D1（建议）** | 复合物（片段数 ≥ 2）上 XX 组合只在第一个节点推（与单对层规则 A 同一逻辑）；II、IX 照旧 | 上表 XX 0 产出；保留在第一个节点上一次，单分子化学仍有机会 |
| D2 | D1 + 双对层内按 II → IX → XX 的顺序推（同类内仍按种子打乱） | 不删任何条目，只让最可能产出的先付费；N1 的首次命中会提前（推断） |
| D3 | 双对层放开共用原子（全体系统一） | 针对卡宾这类单原子成两键；b09 TS-2OMe 是不同步的，单对层已推出 (2+1) 通道，现无证据需要 |

建议 D1 + D2，D3 不做。

### 2.2 朝向数（E）

- b09 第一阶段 sA 的 32 个朝向里 0 次推到卡宾碳–Ca / Cb，sB 推到 2 次（DONE_LOG 11-23）；离线几何估算单个朝向命中约 11.5%。
- 单对层规则 A 之后，每个朝向的片段间单对约 8 条（b09）/ 8 条（N1），每条约 200 forward 加端点极小化，加一个朝向约 2–3k forward（按冒烟均值推算，未测）。
- 选项：E0 保持 32；**E1（建议）64**；E2 96。按单个朝向 11.5% 命中估算，64 个起点全不中的概率约 0.04%（32 个时约 2%）；这是几何估算，sA 的实际 0 命中说明节点去重等因素会让真实命中率更低（未查）。

### 2.3 构象回流（B，只回流一层）

单对层在复合物第一个节点上推片段内原子对时，末端极小若键图不变、但片段构象与输入不同（对称 RMSD 超出 `basin_rmsd_A`），把这个片段构象加进构象库，用同一随机朝向生成器与另一片段摆成新节点（数量 = 原朝向数的一半，待定），只推片段间单对与 II / IX 双对。只回流一层，不递归。
- 依据：N1 s-cis 丙烯醛已由单对层推出（DONE_LOG 11-18），b09 -cis 需要另一种醛构象（11-20 更正）。
- 待用户定：做不做；回流节点数。

上面定完后，把全部开关写成一个规则版本（暂名 AFIR-W1），记进项目 `CLAUDE.md` 与本文；之后对所有体系不再按体系改参数。

## 3. 冻结后的验证（适用性）

### 3.0 前置：单分子输入（不涉及规则选择，先施工）

横向验证设计的留出槽位 H1–H3 全是**单分子反应**（RGD1），而现行 `run_mc_afir_batch.py` 的准备步骤要求恰好两个片段（`run_mc_afir.prepare`："MC-AFIR phase 1 needs 2 fragments"）。施工：片段数 = 1 时不摆朝向，节点只有输入结构（之后由构象回流 / 网络扩展补），单对 / 双对候选全部是分子内原子对，规则 A / D1 对单分子不生效。解析台测试 + 一次冒烟（用开发集里的单分子体系，如 b02 或 b03，待查哪个有 POLAR-1 可用的输入）。

### 3.1 留出体系

按横向验证设计 §3：RGD1 2023-04-24 更新记录，H2（重原子成断键 / 开闭环）、H3（同一反应物至少两个事件）两个槽位做端到端，H1 本期不做。选取、参照认证与搜索端隔离照该文执行；搜索端只读反应物与 AFIR-W1 规则。参照认证需要 MLP 面上的 TS（事后、可用 Hessian 与 QM）。
