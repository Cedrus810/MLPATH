# Gen-COMPAS 思路接入 MLPATH 的可行性评估

日期：2026-10-03。性质：研究与实施建议；不是冻结协议，不改变已有实验判据。

## 判断

可以做。近期最合理的目标是：在已发现的反应通道上，增加可复核的动力学过渡区域定位，
再检验它能否改善现有路径精化的效率或覆盖率。生成模型作为后续的候选提议器。

工程基础已经存在：PRRS 负责发现、身份与网络；PARS 负责路径分组、选择和 NEB 精化；
PRRS 的首次进入式射击可提供动力学标签。无需为了接入论文思路重排整个核心目录。

“生成桥 + committor + 物理验证”可以实现，但是否省算力、是否保持罕见机理、是否具有
论文层面的新增价值，都还没有证据。不能把框架拼接当成已证实的方法改进。

## 外部资料的核对范围

- [Nature 正式论文](https://www.nature.com/articles/s41586-026-11025-1)：检索可读摘要支持从已知端态恢复构象转变的定位；正文与 PDF 在本次浏览中被 Nature 身份跳转阻挡。
- [作者预印本全文，v1](https://arxiv.org/html/2510.24979v1)：明确介绍端态附近短无偏 MD → diffusion → TMD → 无偏采样 → committor 与迭代。它是早期版本，不能据此断言正式版所有实验或数字。
- [作者当前 README](https://github.com/Tangcyu/Gen-COMPAS/blob/main/README.md)：启动前需要独立从 A、B 采样并合并训练轨迹；原子数和顺序必须匹配。后续迭代包含 committor 筛选与 RiteWeight。
- [作者当前配置](https://github.com/Tangcyu/Gen-COMPAS/blob/main/config.yaml)：`q_variance=0.1` 对应模型预测值 0.4–0.6；有显式的 A/B basin 定义；默认特征与模板面向蛋白体系。

作者当前代码的 main 分支与论文发表时版本不一定相同；若做复现须记录具体版本。
“不预定义反应坐标”不意味着可以省去 A/B 吸收区域的定义。

并不说明这些扫描窗口都在过渡区域。

`runs/p1_path_committor_explore/summary.json` 还有鞍点附近的射击探索：N=16，

## 贴文中需要修正的判断

1. **断键/成键不要求必须先做联合图 diffusion。** 在保留所有原子的反应中，原子数与
   元素可以不变，连接关系在连续坐标空间里改变。坐标生成器仍然可以提出候选；端态
   键差和反应原子可作为条件。联合图生成是研究选项，不是可行性的前提。
2. **“两根半键”不能当成化学错误。** SN2、质子转移的过渡结构本来就可能含部分
   断裂/形成的键。硬门应检查重叠、数值异常、势适用域等；不能要求每个中间帧有
   合法的整数价键图。反应身份由稳定端态与验证确定。
3. **q≈0.5 不是一阶鞍点证明。** 它依赖温度、动量系综、环境与吸收区域，也可能
   对应有后续分叉的中间态。鞍点仍需驻点、负曲率及两侧连通性/QM 验证。
4. **16–64 发不足以硬判 0.4≤q≤0.6。** 当 B 恰占一半时，N=16 的 Wilson 95%
   区间约 [0.28,0.72]，N=64 约 [0.38,0.62]。模型预测切片与射击确认的统计含义
   不同。可先粗筛再独立追加确认，追加规则须跑前写明。
5. **第三盆与未吸收不能隐去。** 现有 `p_B_given_AB=B/(A+B)` 是条件比例。
   未定发较多时不能把它直接解释为无条件的 q；竞争通道较多时还需明确第三盆的
   处理，必要时做多盆首次到达统计。
6. **省算力需要端到端计账。** 全部候选都射击几十发可能更贵，尤其对已有便宜 NEB
   基线的小分子。必须把端态采样、候选构建、射击、训练、精化和验证成本都计入。
7. **自由能不能从生成频率或 PRRS 路径频率直接读。** proposal 和扰动改变起始
   分布；只有短轨迹无偏，不等于集合具有平衡权重。第一版不给 FEL/速率承诺。
8. **“没有撞车”需要限定。** 未知产物发现与已知端态构象采样的问题不同；本仓库
   已有 connect 模式，已知 A/B 的问题存在交集。新的科学贡献应落在反应拓扑变化、
   多通道覆盖和预算下的表现，不能只靠 exploration/exploitation 命名。

## 最小落地路线

```text
PRRS run：已发现通道、端态与响应轨迹
    → PARS：按通道/反应管选择少量代表
    → bridge proposal：从已有路径提出候选帧
    → shooting：固定几何、独立热动量、首次进入与不确定区间
    → 保留过渡区域候选及未决候选
    → 已有 NEB/dimer 等精化
    → 驻点/负曲率、双侧连通性、QM/IRC
```

### 第一步：不训练生成器，接通代表路径的动力学诊断

- 复用已有路径文件；施力段和淬火迭代不作为无偏动力学训练片段。分别记录候选
  从何而来与是否经过物理采样。
- 保留全原子，特别是反应 H；端态原子顺序、总电荷、电子态与 calculator 条件一致。
- 先沿少量代表路径抽帧，粗射击找两侧之间的区域；对少量未决候选再做独立确认。
  初期作为旁路诊断，不据单次 q 点估计硬删除候选或修改冻结搜索判据。
- P1 的 k=160/cap=1280 只在该体系已有确认；移到 b04/b05 要重新测吸收判据。
  同键图构象、退化自环不能只靠 `chemical_key` 区分 A/B，需要映射后的区域定义。

建议新增独立实验脚本与旁路结果文件；沿用现有 `shoot`，不要复制动力学实现。
新增记录至少含 channel/event、A/B 区域版本、帧与模型哈希、来源路径、T、系综、
积分设置、seed、A/B/other/失败细分、进入时刻、Wilson 区间、漂移与核对结果。

### 第二步：标签足够后再学习 committor

先训练轻量的射击监督模型；输入可用连续原子距离/内坐标加通道条件。
使用每个几何的 A/B 计数与实际样本量，而不是把一次射击结果当成精确 q。
这是射击监督估计，与作者的变分 committor 实现不是同一个算法。

训练/验证按来源路径或独立批次分组，避免邻近 MD 帧泄漏。独立射击验证校准，
也抽查模型判为远离 0.5 的候选，评估错误排除率。未吸收与第三盆须单独建模或标记。

### 第三步：基线仍不足时再增加生成桥

先比较现有响应路径和端态插值/IDPP 等简单提议器。只有在复杂通道上确有覆盖或
精化瓶颈时，再尝试受端态、键差、反应原子条件约束的残差 diffusion。

生成样本只是候选：可靠性检查 → 物理采样/独立射击 → 精化验证。
若采用定向牵引，需单独验证工作量、损伤、释放后的行为；不能直接拿蛋白 TMD
的力常数与氢重建模板用于小分子反应。阶段之间保留原子映射与来源记录。

## 能证明价值的实验

P1 用于接线检查；b04 可检查带电、两碎片与退化原子映射。真正的效率与覆盖检验
需要已有多鞍点/多机理参照的体系；b05 是候选，但竞争通道未确认前不能预设它已满足。
也可先使用已有解析势测试台验证机制。

比较臂建议：已有 PARS+精化；增加直接射击；增加学习的 q；最后才增加生成桥。
每项干预独立命名，固定总预算与参考势，不把 MLP 误差混成搜索误差。

跑前冻结总力评估/时间预算、通道与鞍点匹配规则、失效/未决统计、独立射击验证
和抽查比例。至少报告：已验证鞍点/机理覆盖、假接受与错误排除、精化成功率、总成本。
训练和候选准备成本也计入；失败和未完成保留。正式定量速率/FEL 另立采样与重权协议。

是否继续生成模型阶段，应由“同预算增加可信覆盖，或同覆盖降低总成本”的结果决定。
这一轮工作仅评估可行性并核对已有文件，没有新跑 MD、训练模型或改变核心代码。
