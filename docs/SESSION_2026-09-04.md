### 修掉的四个真实缺陷

1. **电荷传不到势能。** 配置声明 −1、模型按 0 算，两边都不报错。
   实测同一结构：标 −1 时 Σqᵢ = −1.000000、亲核 Cl 带 −0.9729、偶极 2.96；
   不标时偶极 0.37 —— **两个不同的物理对象**。
2. **负 seed。** `seed + 7919 * sign` 在 `sign = -1` 且基础 seed < 7919 时为负，
   `default_rng` 抛错。只在 `minimum_check="probe"` 下可达，三个冻结 run 全用 `"hessian"`，
   所以没打到任何已记录结果。修成 `side_seed`（用 `SeedSequence` 而非 `abs()`——
   abs() 在 seed=0 处碰撞）。
3. **身份是算力的函数。** `bond_order_limit` 1000 → 100 让同一分子的 key
   从 `8710064d12ce6a5a` 变成 `38584b6ee5c4eca2`。预算类失败现在抛 `IdentityUnavailable`。
4. **digest 的分类调用参数传错**（用户核查发现）。
   `classify_transition(A, B, 1.2, None)` 让 `1.2` 落进 `broken` 槽，
   把"什么都没变"判成 `degenerate_reaction`。字段**退休**（留在基线里作缺陷记录，
   比对时跳过），新增正确计算的 `transition_class`。

## 四、身份层的三项分离（`chemical_key` 保持模型无关）

1. **共同的构型身份协议保留。** Lewis 枚举是**有明确适用范围**的解析器，
   范围记在 `_CONFIGURATION_PROTOCOL = "lewis-neutral-closed-shell/2026-09-04"`，
   随每个 key 记录（哈希之外）。
2. **判不出记"未知"** —— 不当"没有立体差异"（`locked_bond_parity` 现在是 `None` 不是 `[]`），
   **也不把失败原因哈希成新物质**（哈希只带是否解析成功）。
3. **物理测量单独记账。** 转动势垒、自由转动带模型与测量条件，用于构象去重与动力学，
   **不静默改写共同的化学身份**。

**准入否决已解除耦合**：`admit` 的分支现在按名声明属于哪一层
（`refused_by = "model_domain_declaration"`、`declaration = "closed_shell_only"`），
并写明禁止的反向读法 —— 未解析不是域外的证据，已解析也不是域内的证据。

**候选不再丢失**：量了既有语料，`evicted = 0`（储层上限从未触及）、
`out_of_domain` 拒绝 3 次。那 3 次都是**先通过 `confirm_minimum` 再被标签拒**的，
结构在盘上但只能逐条读记录才找得到。新增 `network["withheld_candidates"]`
给 QM 复核一份清单。**准入行为一字未改。**

一条用户纠正的：**模型无关的定义 ≠ 不同模型必须给出相同身份。**
P3 三模型一致是**观测结果**，不是定义要求 ——
写进定义反而会让模型真的预测出不同产物时看不见。
