## 0. 为什么绕开 Hessian：MLP 特化

前提（用户 11-14）：MLP 给的能量和力可靠，Hessian 不可靠，所以只能绕开。这是本方法的出发点，不在本项目里另作论证：MLP 的 Hessian 若可靠，把 MLP 接进 GRRM 早已有人做成；训练 Hessian 本身就很困难（用户另一个项目的经验）。"便宜"是附带的好处，不是理由。

本项目里已经遇到的表现（fp32 POLAR-1，数字见所引文档）：
- 解析 Hessian 与有限差分的交叉核验偏差贴着 1% 门限：b05 中位 0.0065–0.012、20–60% 超限；回退的 fd Hessian 在 fp32 下更差，被刚体模门拦下；b04 的 6 个事件有 3 个因此阶数未决（`docs/TODO.md` 第 12 条）。
- "内部模复核不一致"使阶数在重算之间摆动：HF-6 第一阶段 N1 的 Dimer 一阶数 20 → 28（fp32 求值不逐位重复；`docs/HF6_SUMMARY_2026-11-12.md` §5）。
- 11-12 冒烟：`descend_saddle` 在 N1 一个鞍点上两侧都停在 Hessian 相关的门（`internal_mode_recheck_disagrees`、`fmax_not_reached_after_polish`），给不出端点（DONE_LOG 11-12）。
- 10-24 F1：旧精修器 `follow_min_mode` 在完整谱不可用时直接失败（HF 设计记录 §4 F1）。

对设计的约束：
1. **搜索里的任何决定都不依赖曲率**，包括隐式的曲率：用力差分沿某方向估曲率（Dimer 旋转、Hessian–向量积）也不用。TS 只用反力的**符号**（一阶量）括区与收敛（§4.2）。由 E/F 历史得到的 BFGS 近似可以作为优化器内部的步长工具（HF 设计 §2），但不作判据；fp32 下它不稳时改用 FIRE（现有 HF 精阶段的做法）。
2. **极小与 TS 的确认只用 E/F**：极小 = 扰动后重新下降回到同一盆；TS = 约束分支上反力变号 + 完整力收敛 + 两侧 E/F 下降到不同的盆。
3. **事后的 Hessian 阶数检验本身也不可靠**：只作参考，单独记账；"未决"照记，不覆盖搜索结果，也不能拿它否掉搜索得到的 TS。
4. **E/F 只在模型适用域内可靠**：AFIR 力会把原子推到高能、近距离的构型。每一步检查最小原子间距（相对共价半径和）、单步能量突变与力的量级，越界记 `domain_exit` 并停止该路径，不当成反应（现有扫描已有定义域与能量截断，沿用其判据）。
5. **利用便宜**：多条 AFIR 路径、多个横向松弛并行，用常驻模型批量求值（`parallel`）。

## 2. AFIR 函数（照搬；SC 的偏置坐标见 §2.1，用户 11-15 改）

```text
F(Q) = E(Q) + ρ α · Σ_{i∈A} Σ_{j∈B} ω_ij r_ij / Σ_{i∈A} Σ_{j∈B} ω_ij           (Chem. Rec. 式 1)
ω_ij = [(R_i + R_j) / r_ij]^p ,  p = 6                                       (式 2)
α = γ / { [2^(−1/6) − (1 + √(1 + γ/ε))^(−1/6)] · R0 }                         (式 3)
R0 = 3.8164 Å, ε = 1.0061 kJ/mol（Ar–Ar LJ）
γ = −RT ln(h / (t · k_B T))                                                   (式 5)
```

- ρ = 1：把 A、B 推近；ρ = −1：拉开（Chem. Rec. 原文："ρ is either 1 to push fragments together or −1 to pull them apart"）。
- R_i：共价半径（原文 "the sum of covalent radii"；用 `ase.data.covalent_radii`）。
- α 是 Ar–Ar LJ 势上碰撞能为 γ 时的平均力（原文）。γ 是"力项能消去的势垒高度的近似上限"。
- 式 (3) 在两份来源的文本提取中都是乱码；上式是按原文文字定义（LJ 势、碰撞能 γ、平均力）推出、并与提取片段一致的形式。**实现前用原文 PDF 核对**（§12）。量级：γ = 100 kJ/mol 时 α ≈ 119 kJ/mol/Å ≈ 1.23 eV/Å。
- 单位：MLP 给 eV；α 按 1 eV = 96.485 kJ/mol 换算成 eV/Å。
- γ 的取法（原文）：按式 (5) 由温度 T 与反应时间 t 定，t 取得比实际长（原文例子全部用 t = 10 天）。298.15 K 时 γ = 93.3（1 小时）/ 101.2（1 天）/ 106.9（10 天）kJ/mol。我按式 (5) 复算这三个数一致；但原文例子"T = 403.15 K、t = 10 天 → γ = 153.0 kJ/mol"复算得 145.6，对不上（原因未查，§12）。

### 2.1 SC-AFIR 的偏置坐标：权重冻结在路径起点（用户 2026-11-15 决定，改动原版）

用户原话（2026-11-15，逐字）：

> 可以把偏置坐标改成：
> c_ij = [(R_i+R_j)/r_ij(x_0)]^6 / Σ_ab [(R_a+R_b)/r_ab(x_0)]^6，  q(x) = Σ_ij c_ij r_ij(x)
>
> 其中 x_0 是这条 SC 路径的扰动起点。路径中不更新 c_ij，下一条路径根据自己的起点重新确定。
>
> 这样：∂q/∂r_ij = c_ij > 0

### 2.2 SC-AFIR 只推被选中的原子对；TS 定位坐标与推力解耦（用户 2026-11-15 决定，取代 §2.1 作默认）

### 2.3 双对协同探索层（用户 2026-11-15 决定）

用户原话（2026-11-15，逐字）："保留单对作为基础，再加双对协同探索；γ 继续固定 106.9。"；"不一定 啊 超过 只是热力学不稳定  但是 七++++  不是 你这套周环逻辑"（否决按新环大小筛选）；最终方案：

> 1. 推力、枚举和起点照你的方案。
> - 双对使用四个不同原子，偏置为 α(r_kl+r_mn)/√2，γ 保持 106.9。
> - 不限制环大小，直接对完整双对组合做对称去重，再按固定种子打乱。
> - 两对同时缩短 20%，在同一次最小二乘拟合中处理，避免顺序影响起点。
> - 单对基础层保留，双对单独记账。

>    P = canon(A_kl×B_kl) ∪ canon(A_mn×B_mn)，q(x) = Σ_{(i,j)∈P} c_ij r_ij(x)

## 3. AFIR 路径（照搬；优化器只用 E/F）

### 3.1 定义

AFIR 路径是从起始结构出发、极小化 F 的那条轨迹（原文："Such a path obtained by minimization of the AFIR function is called AFIR path"）。α 在一条路径内固定。力项只在这一步加（原文 flow 第 1 步）。

### 3.2 优化器

GRRM 用 RFO 并每 50 步算一次精确 Hessian；本设计用只需 E/F 的优化器（ASE BFGS 或 FIRE，最大步长限制同现有 `_MAX_STEP_A`）。轨迹的每一步都记录：几何、E（无偏）、∇E、ρ 项的值与梯度、键图。

这一步只是换优化器，路径的定义不变。注意：轨迹的形状依赖优化器，所以同一起点、同一 α，BFGS 轨迹与 RFO 轨迹不同；这不影响 §4 的 TS 与极小，因为它们都在无偏 PES 上重新求，只把路径当初猜。

### 3.3 终止、早弃与路径身份（GRRM17）

- 终止（先到者）：F 的局部极小已达到；轨迹上已经过两个能量极大；体系解离。
- 早弃：每步比较力项（式 1 第二项）与它在起始（扰动）结构的值；10 步后仍更大，判为该 γ 下"不反应"，丢弃。
- 路径身份 = (起始 MIN i, 原子对 / 片段对 j, ρ)；同一身份不算两次。

## 4. 本项目自己的部分：MIN、TS、连接（只用 E/F）

### 4.1 路径上的极小 → MIN

取轨迹上无偏能量 E 的局部极小（以及轨迹终点），去掉力项后做 E/F 极小化到 fmax ≤ τ_min。确认：n_p 次随机扰动（幅度为实测几何噪声的若干倍）后重新下降，全部回到同一盆（键图相同，对齐 RMSD 与 ΔE 在判重容差内）。身份与判重：键图 + 对称 RMSD + 能量（现有规则，对称群取结构自身图群与反应物图群的并；镜像是否算同一个待定，见 §12）。

### 4.2 路径最高点 → TS（HF 反力零点内核）

AFIR 路径是在固定 α 下得到的：沿片段距离 ρ_AB 的约束分支上，E*(ρ) 的二阶导为负的一段在恒力下不稳定，所以轨迹会跳过 TS，最高点只是近似。GRRM 在这里用 LUP 加 Hessian TS 优化；本设计改为在同一坐标上**位移控制**，重建一段连续分支：

1. 坐标：取该路径的片段加权距离 ρ_AB(x) = Σω r / Σω（式 1 第二项去掉 ρα）。
2. 在轨迹上 E 最高点的前后各取若干点；每个点固定其 ρ_AB 值，其余坐标在无偏 PES 上只用 E/F 做横向松弛，读出反力 λ = −(F·g)/(g·g)（g = ∇ρ_AB，F = −∇E）。
3. 找到相邻两点之间 λ 由正变负、且两点在同一连续分支上（对齐位移在实测几何噪声与分支连续判据内）→ 得到括区。
4. 在括区内用现有的 HF 反力零点内核（`refine_ts_ef`：二分 / 割线、两阶段中点、FIRE 精阶段）定位；收敛判据不变：完整无偏力 ≤ 0.01 eV/Å、横向力、约束残差同时满足，按实测反力分辨率终止。
5. 坐标接口：现有约束（`ts_ef._Constraint`）只调用坐标的 `value` / `gradient`；ρ_AB 实现同样两个方法即可接入。

理论依据（推导，待解析台验证）：TS 处 ∇E = 0，所以它是自己那个 ρ 等值面上的驻点、λ = 0；它在等值面上是极小（分支经过它）当且仅当 g·H⁻¹·g < 0，即 ∇ρ 与不稳定模有足够重叠。搜索不检查这个条件，只看分支是否连续、λ 是否变号。

跳支（分支在 ρ 上不连续）：两侧缩步复扫确认；确认后以跳变前后结构的位移 d 定义线性坐标 q_d(x) = (x − x_before)·d̂（先刚体对齐），在 q_d 上用同一内核定位；仍无连续括区则记 `branch_unresolved`，不计为 TS。

**2026-11-15 状态（用户原话："暂停 q_d，不加“近邻 ≤ 3.0”的裁剪"）**：上面的 q_d 已实现为 `afir.DisplacementCoordinate`（先笛卡尔线性、后改距离空间）与 `afir_local.rebracket_jump`，**未接入运行器**。解析台上两种形式都在"可分离 fold"上失败：固定 q_d 的松弛分别经由整体转动、经由软的分子间距离绕开约束（DONE_LOG 2026-11-15）。暂停，跳支照记 `unresolved:hysteresis`。

## 5. 起点与分组（照搬）

### 5.1 MC-AFIR（多分子）

- 片段 A、B（以及 C……）固定为各反应物分子。三个反应物时，A–C、B–C 各加一个力项（原文）。
- 起始结构：随机生成相对朝向与接近位置（原文）。本项目已有的 L0 片段构象与姿态生成器（`poses`）可作这个随机生成器；与原文的差别是它先做构象资格与壳层摆放，记录在案。
- 循环：生成随机结构 → 极小化 F 得 AFIR 路径 → 重复；**最近 n 条路径没有新产物即停止**（原文）。n、以及"新产物"的判法（键图 + 判重）待定（§12）。
- γ：可固定，也可每条路径在 [γ, γ_max] 内随机取（原文 Chem. Rec. 的一个例子取 106.9–1069 kJ/mol）。

### 5.2 SC-AFIR（单分子，以及多分子的片段内反应）

对每个原子对 (k, l)：

1. 生成扰动结构：k–l 距离缩短 / 拉长 x%（x = 20），其余原子用最小二乘拟合使距离矩阵与原结构的 RMS 误差最小（不需要量子化学计算；原文强调这对局部对称的结构很重要）。
2. 分组：k 入 A、l 入 B；把与 A（B）相连的原子加入 A（B），r_ij/(R_i+R_j) < 1.5 视为相连；做两遍（第一、二层）；若 r_ij/(R_i+R_j) < r_kl/(R_k+R_l)，把 i 从 A、j 从 B 中去掉。
3. 在扰动结构上极小化 F 得 AFIR 路径。
4. 跳过很远的原子对：r_kl/(R_k+R_l) > 3.0（用户 11-14 定；原文 Chem. Rec. 为 5.0、GRRM17 为 8.0，超出 MLP 自身截断的原子对模型看不到）；对称等价的原子对只算一次。
5. 偶尔（N 原子体系每 N 条路径一次）也算被跳过的远距原子对，以诱导大变形（原文）。

## 6. 网络扩展、导航与停止（照搬）

- 从初始 MIN 开始对它做 SC-AFIR（多分子先做 MC-AFIR）；新 MIN 入表。
- 选下一个要展开的 MIN（Chem. Rec. 式 6）：μ_i = ξ_i · exp(−ΔE_i/RT_R) / Σ_j exp(−ΔE_j/RT_R)，ξ_i ∈ (0, 1) 随机，取 μ 最大者；T_R 远高于实验温度（GRRM17 默认 2981.5 K）。原文："In the without-Hessian search, electronic energy ΔE_i is adopted instead of ΔG_i"——不算 Hessian 时用 ΔE 正是原文的做法。
