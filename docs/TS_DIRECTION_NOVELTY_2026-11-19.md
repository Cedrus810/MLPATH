## 1. 建议押注的科学问题

**在搜索决策不使用 Hessian、模态或力差分曲率的条件下，如何判断一条尚未收敛的反应路径已经提供了足够可靠的爬坡方向，并只为缺失的方向信息继续付费？**

拟发展的主张是：通过几何方向之间的动作差异、实际 E/F 定位进展和有限尺度通道检查，控制粗路径优化与局部爬坡的交替；在保持连接成功率的同时减少整条路径求值。

这是研究假设。最接近的现有工作是 SPM 与 OCI-NEB；是否形成独立方法贡献，取决于新判据是否比它们以及简单截短 String 更有效。名称、少量节点、批量计算均不单独承担新颖性。

## 4. 最值得发展的候选贡献

### A. 用爬坡动作的一致性控制方向优化精度（主线）

在同一个刚体参考系、同一局部路径段，取不同弧长跨度的单位切向 `t_j`。取向相反视为同一方向，使用秩一投影 `P_j = t_j t_j^T`。

同一个候选位置的力为 `F`，相应爬坡动作为：

\[
G_j=(I-2P_j)F.
\]

建议研究两个廉价诊断量：

\[
D_{\rm geom}=\max_{i,j}\|P_i-P_j\|_2,
\qquad
D_{\rm act}=2\max_{i,j}\|(P_i-P_j)F\|_2.
\]

第一个量看几何方向的分歧；第二个量直接看这些分歧对当前爬坡动作的影响。它们只需路径几何与当前力；可用向量点积计算，无须显式构造大矩阵，也不计算力差分曲率。

实际控制研究：方向动作在目标精度上已一致、短段爬坡有进展时，停止整条路径松弛；分歧较大时仅重建峰区路径；方向一致但定位停滞时，单独检查步长和通道，防止把所有失败都归因于切向。

两个局限必须进入设计：多种切向可以一致地指错；`F` 接近零时，`D_act` 对任何方向都会变小。因此它们是方向敏感性的可观测指标，绝对方向误差及鞍点资格仍需额外证据。候选方法必须结合短段实际定位反馈和末端连接检查。

与 SPM 的差别应通过实验建立：SPM 的既有漂移阈值与固定构型间距，对比按爬坡动作差异分配方向精度的控制。与 OCI-NEB 的差别是方向判定不使用 Dimer 模态；双方最终比较同一定位与连接任务。

### B. 有限力误差下的方向需求分析（支撑主线）

设评估力 `F_tilde = F + e`，`||e|| <= epsilon_F`；参考方向为 `t_*`，实际方向为 `t`，两者夹角按正负等价取锐角 `theta`。两种理想化爬坡动作之间有初等界：

\[
\|(I-2tt^T)\widetilde F-(I-2t_*t_*^T)F\|_2
\le \epsilon_F+2\|F\|_2\sin\theta.
\]

推导：反射矩阵的谱范数为 1；两个单位秩一投影之差的谱范数为 `sin(theta)`；再用三角不等式。

这条界是分析起点，不单独主张新颖性。它把力误差与方向误差分开，支持研究“当前残差水平需要多准的方向”。方向的真实误差未知，`D_geom`/`D_act` 与它的关系需条件或实验校准。

特别要注意：动作扰动界没有给出全局收敛保证。不同方向共享 `F=0` 的零点，局部稳定性会不同；小力残差、两侧下降和一阶性质分别报告。算法不读取 Hessian；理论分析仍可用理想光滑势的 Hessian表述局部条件。

还有一个直接恒等式：`||(I-2tt^T)F||_2 = ||F||_2`。因此同一点上比较不同方向的爬坡力范数，得不到方向优劣；需要比较动作差异及试走后的进展。OCI-NEB 已讨论反射方向对齐及 45° 稳定性角度，简单重述该角度也不作为本项目的新贡献。

对比有限差分 `H v` 时，若两次力误差分别有界于 `epsilon_F`，差分噪声最坏为 `2 epsilon_F/h`。这里的反射动作直接使用一次力，没有这个差分除距项。SPM 同样具备不求该差分的特点，因此这属于方法类别的优势，独立贡献仍要由方向控制体现。

### C. 保留发现路径的通道信息（辅助线）

AFIR 给出的路径带有起点、末端盆及局部几何走向。局部修方向时保留这些信息，记录候选最终连接哪个盆对；遇到第三盆或不同通道时显式报告。

这可以减少“驻点收敛了但连接错了”的费用。但 CSM 和稳定边界方法已有盆关联思想，单独将其命名为通道保持算法，贡献力度较弱。有限两侧下降也不能确保保留某个路径同伦类。

**排序：A 为主要候选，B 为理论与 MLP 数值适用性的支撑，C 为任务正确性和失败分类。**

## 5. 一条可实现、可否证的研究路线

这是开发方向，阈值与生产调度尚未冻结。

1. 输入搜索自己产生的 AFIR 路径和两端 E/F 极小，保留多峰信息；先在一个共同刚体参考系提取无偏能量峰及多尺度几何切向。局部对齐需保持候选、力与所有方向坐标系一致。
2. 先试直接爬坡；没有进展时才局部修链。已有五条是开发集，不把参照几何、成键对或命中身份送入控制器。
3. 在短段试走前后记录完整力范数、最佳残差、能量、位移、方向分歧及花费。允许块内非单调变化，避免把一两步反弹当作方向失败。
4. 按动作分歧与实际进展决定继续爬坡、修方向或扩大峰区。更新方向后重置不再适用的优化器历史。全部失败试走和方向重建付费。
5. 候选过完整力门后，执行相同的两侧 E/F 下降、端点极小稳定性检查与盆身份判定。独立阶数检查留在评价端，未决单列。

不先引入 Hessian 拟合、模态预测网络或额外训练。先回答几何方向和当前 E/F 是否已经够用。

## 6. 最小实验与贡献去留

### 6.1 先做能决定是否继续的消融

保留当前五条 N1 开发路径及全部结果。用同一缓存 AFIR 轨迹，在以下 String 更新数后启动同一爬坡器：`0 / 20 / 100 / 1000`。这些是测量档位，不是生产默认值。

每档同时保存：候选位置、几何切向、共同固定位置上的方向对照、整条链残差、定位成功与连接成本。粗链更新同时改变位置和方向，必须安排“固定候选位置只换方向”与“固定方向只换位置”的对照，区分两者贡献。

结果解释：

- 直接爬坡与 1000 步同样完成全部连接：优先采用简单方案，方向自适应控制在这批数据上没有必要。
- 固定的短 String 已覆盖全部成功且更省：保留实用改进，继续用困难与留出输入判断是否需要更复杂方法。
- 不同路径需要显著不同的方向精度，且动作分歧/实际反馈能预测这种需求：支持发展 A。
- `D_geom`/`D_act` 没有预测价值：放弃这组指标，避免事后为每条路径设阈值。

本阶段不追求每条都“调成功”，保留失败及转向别的通道的结果。

### 6.3 数值扰动实验须保持物理解释

区分三类：同一几何重复求值的非确定性；fp32/fp64 数值差；模型与 QM 势的系统差。重复求值量不到最后一类，也不直接测得空间导数误差。

先用解析势做有控制的、保守的扰动：

\[
E_{\ell}(x)=E_0(x)+a\ell\sin(u^Tx/\ell),\qquad\|u\|=1.
\]

其能量扰动幅度为 `a ell`，力扰动范数不超过 `a`，Hessian 扰动范数不超过 `a/ell`。这可以构造 E/F 变化小而曲率变化大的测试。使用预设一组 `a, ell`，与方向尺度、完成连接的成本联合报告。

该实验检验求解器的数值行为。不能将它描述为已经建立真实 POLAR-1 的误差模型；扰动本身也可能生成额外驻点，需要同时报告当前势的驻点与有限尺度端点行为。

### 6.4 统一成功量尺与成本

主量尺：在同一总预算内得到完整力收敛、完成指定两侧 E/F 连接及端点稳定性检查的候选比例；参照匹配与独立阶数另列。

成本包含路径准备、全部试走、方向重建、端点下降和失败；结构求值、批量模型调用、墙钟分别报告。局部对照共用 AFIR 路径并将其费用单列；端到端比较再纳入发现花费。沿用同一模型、硬件、精度与共同评价流程。

开发期与运行期阈值、方向跨度政策、重试和预算政策必须分开。共同准备可以缓存，但报告首次执行费用；不把多个消融档位的合计费用误记为单一生产方法的费用。

## 7. 可写进后续论文的主张草案

只有后续实验支持时，才采用如下范围的主张：

## 8. 本轮结论与下一步产物

最值得继续挖的是 **“无模态的方向充分性控制”**。其具体新意候选是从爬坡动作差异和实际残差进展决定需要多少路径信息，替代固定迭代数或模态对齐门。

下一份有决定力的产物是 0/20/100/1000 档位加位置/方向分离的开发测量表；根据表中证据决定是否实现 A。本文不预设速度倍数，不将普通早停、少节点或粗路径后接爬坡作为首创。
