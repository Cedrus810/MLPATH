# 03 曲率、响应算子与鞍点认证

对应源码：`src/prrs/runner.py`（`hessian_vector_product` 到 `descend_saddle` 一段）。
对应理论文档：`docs/PRRS_CURVATURE_ROUTES.md`（路线 A / B / C 与架构结论 §E）。

一句口号先放这儿：

> **不要"避免 Hessian 物理"，而要"避免 Hessian 矩阵"。**

## 3.1 观测量的重新定义

虚频不是判据，它是判据的一种**报告形式**。虚频来自质量加权 Hessian 的负本征值：

$$H_m v_i = \lambda_i v_i, \qquad \lambda_i < 0 \Rightarrow \omega_i \ \text{为虚}$$

PRRS 不需要知道 $-290.1\ \mathrm{cm^{-1}}$ 这个数。它需要的是

$$\boxed{\lambda_1 < 0, \qquad \lambda_2 > 0}$$

即"**只有一个**不稳定方向"。$-250$ 还是 $-300\ \mathrm{cm^{-1}}$ 对 TS pool 的裁决没有影响。

## 3.2 原语：Hessian-vector product

`hessian_vector_product`。在参考几何处展开 $F(R + \delta R) = F(R) - H\,\delta R + O(\delta R^2)$，
所以

$$\boxed{Hv \approx -\frac{F(R + hv) - F(R - hv)}{2h}}$$

**每个 $Hv$ 恰好 2 次力评估，与 $3N$ 无关。** 完整 Hessian 是 $3N$ 个这样的乘积；
迭代最低本征值求解器不管体系多大都只要几十个；单独一个就给出一个方向的刚度。

这是同一个测量在不同幅度下的两端：**Hessian 是扰动响应的无穷小极限，不是另一个对象。**

代码细节：$\pm h$ 两次评估之间必须 `try/finally` 复原坐标。门控在位移点上拒绝是它的
本职而不是异常路径——没有 finally 的话结构会停在 $R \pm hv$ 上，之后每一次测量都在
一个没人要求的几何上进行。

## 3.3 质量加权与投影

质量加权坐标 $q = M^{1/2} x$，所以

$$H_m = M^{-1/2} H M^{-1/2}$$

一个笛卡尔位移 $d$ 映射为 $M^{1/2} d$，**不是** $M^{-1/2}d$。这个方向搞反了在同核对上
只是重标度、完全看不出来，masses 一不同就选到了完全错误的方向（`_mass_weighted_direction`
的 docstring 专门钉这一点）。

方向曲率（`_curvature_along`，输入 $v$ 已是质量加权单位向量）：

$$\kappa(v) = v^\top H_m v
= \Bigl\langle v,\ M^{-1/2}\,\bigl[H\,(M^{-1/2} v)\bigr]\Bigr\rangle$$

代码里就是：对 $M^{-1/2}v$ 取 HVP，再把结果除以 $\sqrt m$ 与 $v$ 内积。2 次力评估，
与体系大小无关，**符号就是全部内容**：$\kappa(v) < 0$ 说明参考点沿这个方向不是极小。

### 刚体子空间必须两侧投影

`_trivial_modes` 给出质量加权下的 3 平移 + 3 转动的正交归一基 $B$（$6 \times 3N$）：

$$\text{translation}_\alpha = \sqrt{m}\, e_\alpha, \qquad
\text{rotation}_\alpha = \sqrt{m}\,\bigl(e_\alpha \times (x - x_{\rm com})\bigr)$$

投影子

$$P = I - B^\top B$$

**必须作用在输入和输出两侧**：$H_{\rm proj} = P H_m P$。只投一侧的话求解器会收敛到
刚体零模而不是化学模式。

投影是"最低本征值能直接和 0 比较"的前提——否则那个阈值必须去吸收刚体噪声。

### 刚体模上的 Rayleigh 商不是零，而且这件事有解析式

整体转动下能量不变：$E(R(s)x) = E(x)$ 对所有 $s$。对 $s$ 求两次导：

$$\dot x^\top H \dot x + g \cdot \ddot x = 0, \qquad \ddot x = -\omega^2 x_\perp$$

$$\Longrightarrow \boxed{\dot x^\top H \dot x = \omega^2\,(g \cdot x_\perp)}$$

也就是说：**转动方向的曲率正比于残余梯度**，只在驻点才严格为零。
平移则完全没有这一项——恒等式在任何几何处都精确，因为能量只依赖坐标之差。

这解释了一件否则会被误读的事：一个收敛到搜索自身力容差的结构，转动 Rayleigh 商是
$O(|g|/r)$ 量级，在乙醇上是 $10^{-3}$——**恰好等于本征值容差本身**。生读这个数会
以为计算很糟。

`trivial_mode_floor` 因此上报的是**残差**：

$$\text{residual}_r = \underbrace{u_r^\top H_m u_r}_{\text{实测}} - \underbrace{\omega^2 (g\cdot x_\perp)/\lVert u_r\rVert^2}_{\text{梯度能解释的部分}}$$

这是**唯一不需要外部参考数据**的质量度量，而且除梯度外不花任何额外力评估
（调用者刚淬火完，梯度是缓存的）。残差如果没有远低于本征值容差，那个尺度上的每个判断都是噪声。

**它是什么，不是什么**（`confirm_minimum` 的 `floor_gate` 字段）：这是一个**必要条件**，
只检查了六个曲率事先已知的方向。通过它**不构成**关于内部子空间的证据——一个形如
$P_{\rm int} A P_{\rm int}$ 的误差在每个刚体模上残差**恰好为零**，内部本征值可以任意错。
所以：失败 $\Rightarrow$ Hessian 不可用；通过 $\Rightarrow$ 只说明"破坏不变性的那一类错误"
（单位因子错、块转置或错序、非对称差分噪声、质量错）低于容差。

## 3.4 有限幅度响应算子（路线 B）

把上面的东西提为定义。在对称约化的位形流形

$$\mathcal X = \mathcal C \big/ \bigl(SE(3) \times \Gamma\bigr)$$

上（$\Gamma$ 是原子置换/分子对称群），定义 **finite-amplitude response operator**：

$$\boxed{\mathcal L_a(x)\,v = \frac{\operatorname{PT}_+ \nabla E\bigl(\mathscr R_x(av)\bigr) - \operatorname{PT}_- \nabla E\bigl(\mathscr R_x(-av)\bigr)}{2a}}$$

$\operatorname{PT}_\pm$ 把两个扰动点的梯度输运回 $T_x\mathcal X$；在当前笛卡尔实现里就是投影 $P$。

关键性质：

$$\boxed{\lim_{a\to 0}\mathcal L_a(x)\,v = \operatorname{Hess}E(x)\,v}
\qquad\Longleftrightarrow\qquad \boxed{H = \mathcal L_0}$$

标量形式（能量式）：

$$\boxed{\kappa_a(x; v) = \langle v, \mathcal L_a(x) v\rangle
\approx \frac{E(\mathscr R_x(av)) + E(\mathscr R_x(-av)) - 2E(x)}{a^2}}$$

于是整个 PRRS 统一到**一个尺度参数** $a$ 上：

$$a: 0 \longrightarrow \text{finite} \longrightarrow \text{basin crossing}$$
$$\text{local curvature} \longrightarrow \text{anharmonic response} \longrightarrow \text{reaction}$$

`direction_stiffness`（$a$ 小）和幅度细化（$a$ 大）不是两个模块，是同一个测量的两端。

**统一对象**：$\mathcal R_x(v, a, t)$——在状态 $x$、沿方向 $v$、幅度 $a$、经时间 $t$ 后的响应。

| 极限 | 内容 |
| --- | --- |
| $a \to 0,\ t \to 0$ | linear response / Hessian |
| 有限 $a$，短 $t$ | anharmonic susceptibility |
| 更大 $a, t$ | basin escape |
| 最终 | reaction |

$$\boxed{\text{Hessian} \subset \text{PRRS response theory}}$$

而不是 PRRS + Hessian 模块。位移版探针是 $t \to 0$ 的 $\mathcal R$，动量版是 $t > 0$ 的。

## 3.5 $\kappa_a$ 是对 PES 的 $\operatorname{sinc}^2$ 低通滤波（路线 C）

这不是类比，是能写出传递函数并被实测确认的。

沿方向 $v$ 取 PES 的一个空间傅里叶分量 $E \sim e^{ikx}$。

**能量形式**（对称二阶差分）：

$$\frac{e^{ika} + e^{-ika} - 2}{a^2} = -\frac{4}{a^2}\sin^2\frac{ka}{2}
= -k^2\left[\frac{\sin(ka/2)}{ka/2}\right]^2$$

精确二阶导给 $-k^2$，所以

$$\boxed{T_a^E(k) = \operatorname{sinc}^2\!\left(\frac{ka}{2}\right)}$$

**力形式**（对称一阶差分的投影）：

$$\frac{ik e^{ika} - ik e^{-ika}}{2a} = -k^2\frac{\sin(ka)}{ka}
\qquad\Longrightarrow\qquad \boxed{T_a^F(k) = \operatorname{sinc}(ka)}$$

两者都是低通，截断波数约 $2/a$：**幅度 $a$ 就是分辨率**，不是待消除的误差参数。

### 为什么估计量用能量形式

$$T_a^E = \operatorname{sinc}^2 \ge 0, \qquad T_a^F = \operatorname{sinc}\ \text{会变号}$$

$T_a^F(k) < 0$ 当 $ka \in (\pi, 2\pi)$——**力形式会把波长在 $a$ 与 $2a$ 之间的分量反号**。
能量形式永远不会。所以多尺度估计量用能量形式；力形式留给单点快筛和 Lanczos 的 $Hv$
（那里要的是 $H$ 本身，不是滤波）。

领头阶给出一个可直接检验的预言：

$$T_a^E = 1 - \frac{(ka)^2}{12} + \cdots,\qquad T_a^F = 1 - \frac{(ka)^2}{6}+\cdots
\qquad\Longrightarrow\qquad \boxed{\frac{\kappa_a^F - \kappa_0}{\kappa_a^E - \kappa_0} \to 2}$$

**实测确认**：乙醇 syn 鞍点，三个模式、跨一个半数量级的幅度，比值全部是 $2.00$
（$1.983$–$2.012$），大 $a$ 端随高阶项缓慢偏离。滤波图像是被数据定量确认的。

### 这个滤波扣掉什么、扣不掉什么

**能扣掉**：PES 的高空间频率成分。若 MLP 误差是高频涟漪，$\operatorname{sinc}^2$ 按 $1/(ka)^2$ 压制它。

**扣不掉**：

1. **平滑偏差**。一个曲率整体偏硬 10% 的模型，过任何低通还是偏硬 10%。滤波作用在频率上，
   偏差在幅度上。**这是真正剩下的风险，对所有无参考诊断都不可见。**
2. **真实的高频物理**。滤波不区分"模型涟漪"和"真实非谐结构"。所以它不是去噪器，
   **它是带宽选择**。诚实的报告是"在分辨率 $a$ 下的曲率"，不是"曲率"。

## 3.6 带内回归：`response_curvature`

既然 $a$ 是分辨率，**单个小 $a$ 就是一次悄悄做出的带宽选择**。所以采一个幅度带并拟合

$$\boxed{\kappa(a) = \kappa_0 + c\,a^2 + O(a^4)}$$

实现（`response_curvature`）：

- 幅度 $a$ 在 `response_band_A` $= (0.01, 0.1)\ \mathrm{\AA\sqrt{amu}}$ 上取
  `response_samples` $= 5$ 个 `geomspace` 点；
- 每个 $a$ 花 2 次评估，共 $2K$；只用能量，但每次都顺带拿到力，因为可靠性门需要它们
  判断这个探针是否物理；
- 设计矩阵 $X = [\mathbf 1,\ a^2]$，OLS：$\hat\beta = (X^\top X)^{-1}X^\top \kappa$，
  $\hat\kappa_0 = \hat\beta_0$，$\hat c = \hat\beta_1$；
- $\hat\sigma^2 = \lVert r\rVert^2 / (K - 2)$，$\sigma_{\kappa_0} = \sqrt{\hat\sigma^2 (X^\top X)^{-1}_{00}}$。

输出的三个量各有各的意义：$\hat\kappa_0$ 外推曲率，$\hat c$ 谐振近似丢掉的领头非谐性，
$\sigma$ 误差棒——**误差棒才是重点**，一个模长没有几倍于自身不确定度的曲率什么也分类不了。

$\sigma$ 的诚实限定（字段 `sigma_meaning`）：它是一个**确定性拟合的 OLS 残差尺度**，
量的是 $\kappa_0 + ca^2$ 描述样本有多好，**不是**标定过的统计不确定度，而且**看不见系统误差**
——比如探了错误的方向。在丙二醛上实测到 $\sigma = 3.7\times10^{-6}$ 而值本身错了 $0.18$。
所以字段叫 `exceeds_residual_scale`（$|\kappa| > $ `response_significance` $\cdot\,\sigma$），
**不叫 significant**。

### retraction 的账：为什么这里用弦

`response_curvature` 的探针端点是**笛卡尔弦** $R \pm a v$，不是内坐标的弧。这是一个
有后果的选择，写下来而不是默认：

一般 retraction 展开为 $\mathscr R(av) = R + av + \tfrac12 a^2 c_v + \cdots$，代入得

$$\boxed{\kappa_0 = v^\top H v + g \cdot c_v}$$

**弦有 $c_v = 0$**，所以它的 $\kappa_0$ 在**任何**几何（驻点与否）都精确等于 $v^\top Hv$。
弦是"$a\to0$ 极限精确重现 Hessian 商"的那个映射，所以它是曲率的正确映射。
一条弯曲的 retraction（比如扭转的弧）带着 $c_v \ne 0$，在梯度不为零处它的 $\kappa_0$
与 $v^\top Hv$ 差 $g\cdot c_v$。

一阶项的相消要求二阶项对 $+a$ 和 $-a$ 相同。弦平凡满足（根本没有二阶项）；
以后要放进来的任何弯曲映射都必须检查这一条，因为一个奇分量会在分子里留下 $a\,g\cdot v$，
使 $\kappa_a$ 按 $1/a$ 发散而不是收敛。

但**弦不是搜索行走的路径**（见 02 章 §2.3）。在默认带的顶端，探针在氢上的位移约
$0.1\ \mathrm{\AA}$，已经是 `internal` 单步上限的两倍，两个映射在那里明显分家了。
$\kappa$ 不受影响（$c_v = 0$ 与键怎么样无关），但 `anharmonicity` 和 `sign_stable`
是从有限幅度样本读的，**一个键已经被拉开的样本不是在报告它名义上的那个运动**。
所以每个幅度都测 `bond_strain`（分数键长变化，纯几何、零评估成本）并上报。

## 3.7 在球面上把方向转下去：无矩阵的 dimer

对能量形式关于方向 $v$ 求导：

$$\frac{\partial}{\partial v}\left[\frac{E(x+av) + E(x-av) - 2E(x)}{a^2}\right]
= \frac{g(x+av) - g(x-av)}{a} = 2 D_a(v)$$

而 guard 每次给能量时**顺带**返回力。所以**目标函数和它的梯度出自同一对评估**：

$$\boxed{v_{\min} = \arg\min_{\lVert v\rVert = 1} \kappa_a(x; v)}$$

的一步下降只花 2 次力评估——一个 Hessian-vector product 的价钱——**没有矩阵，也不需要
一个在有限幅度下根本不存在的谱**。$a \to 0$ 时它退化为极小化 Rayleigh 商，也就是 dimer。

工程注意：旋转必须在投影子空间内进行（$v \leftarrow Pv$ 再归一），否则 dimer 会滑向刚体模。

这就是 `lowest_response_direction`，以及 `_independent_response_reading` 的基础。
后者的价值在于**它不被告知答案**：`response_curvature` 拿的是 Hessian 自己的本征向量，
所以它是在**精化**那个答案而不是**检验**它；从一个 seed 化的随机方向出发收敛到同一个方向，
才叫互证，因为 seed 不知道答案。它**只上报，从不门控**。

## 3.8 有限 $a$ 下没有算子，所以也没有本征值

这是架构结论 §E 的核心，也是"Hessian 是 validation limit"这句话的真正理由——
比"小体系便宜"强得多。

设 $g(x + d) = g_0 + Hd + \tfrac12 T[d,d] + \tfrac16 F[d,d,d] + O(d^4)$
（$T = \nabla^3 E$，$F = \nabla^4 E$，全对称）。力形式的有限响应

$$D_a(v) := \frac{g(x + av) - g(x - av)}{2a} = Hv + \frac{a^2}{6}F[v,v,v] + O(a^4)$$

它**既非线性**——$D_a(\alpha v) = \alpha D_{\alpha a}(v) \ne \alpha D_a(v)$——**也非对称**：

$$\boxed{\langle v_1, D_a v_2\rangle - \langle v_2, D_a v_1\rangle
= \frac{a^2}{6}\Bigl(F[v_1,v_2,v_2,v_2] - F[v_2,v_1,v_1,v_1]\Bigr) \ne 0}$$

（$v_1\cdot Hv_2 = v_2\cdot Hv_1$ 抵消，剩下的是 $F$ 的两个**不同**收缩。）

能量形式没有对称性问题（从标量导出），但

$$\boxed{\kappa_a^E(v) = \langle v, Hv\rangle + \frac{a^2}{12}F[v,v,v,v] + O(a^4)}$$

是球面上的**四次型**，不是二次型。

**实测（MACE 乙醇鞍点）**：取 $v_1, v_2$ 为 Hessian 本征向量，于是 $v_1 \cdot Hv_2 = 0$
精确成立，测到的整个数值就是 $a^2$ 项：

| $a$ | $\langle v_1, D_a v_2\rangle$ | $\langle v_2, D_a v_1\rangle$ | 非对称量 $/a^2$ |
| --- | --- | --- | --- |
| $10^{-2}$ | $1.982\times10^{-5}$ | $1.278\times10^{-4}$ | $-1.0796$ |
| $2\times10^{-2}$ | $7.93\times10^{-5}$ | $5.11\times10^{-4}$ | $-1.0786$ |
| $5\times10^{-2}$ | $4.95\times10^{-4}$ | $3.17\times10^{-3}$ | $-1.0716$ |
| $10^{-1}$ | $1.97\times10^{-3}$ | $1.24\times10^{-2}$ | $-1.0469$ |

在**最小**的测试幅度上两者已经差 6.4 倍。反推
$F[v_1,v_2,v_2,v_2] = 1.19$、$F[v_2,v_1,v_1,v_1] = 7.67$，
$(1.19 - 7.67)/6 = -1.0796$——与实测逐位吻合。

**结论**：$a \to 0$ 是**唯一有谱定理**的地方。有限 $a$ 下的 $\kappa_a$ 连"本征值"都不是。
所以代码里 `_LOWEST_RESPONSE_DIRECTION_MEANING` 明写着
"variational bottom response direction at one amplitude; **NOT an eigenvector** and its
value is **NOT an eigenvalue**"，而 `hessian_spectrum` 的 docstring 写着
"This is the only regime in which the numbers are genuinely eigenvalues"。

## 3.9 Morse 指标与 Morse–Bott

驻点 $\nabla E(x^\ddagger) = 0$。传统条件是"Hessian 有一个负本征值"，数学上的名字是
**Morse 指标**：

$$\nu(x) = \#\{\lambda_i < 0\}$$

$$\nu = 0 \Rightarrow \text{极小}, \qquad \boxed{\nu = 1 \Rightarrow \text{一阶鞍点}}, \qquad \nu > 1 \Rightarrow \text{高阶鞍点}$$

虚频只是为了跟量化软件交流才转换出来的 reporting quantity。

**为什么必须是 Morse–Bott 而不是纯 Morse**：普通 Morse 理论假设临界点孤立，即 $\ker H = 0$。
真实分子有近似自由转子。若某个扭转真自由（$k \to 0$），只在该坐标上不同的结构由零势垒
路径相连、本应属同一盆地，而普通 RMSD 会判为不同 microstate——**自由转子生成无穷多假构象**。

Morse–Bott 分解：

$$T_x\mathcal X = \mathcal N \oplus \mathcal U \oplus \mathcal S$$

$\mathcal N$ 中性/自由，$\mathcal U$ 不稳定，$\mathcal S$ 稳定。**不要求** $\dim \mathcal N = 0$。
TS 只要求

$$\boxed{\nabla E(x^\ddagger) \approx 0, \qquad \dim\mathcal U = 1}, \qquad \dim\mathcal N \ge 0$$

这比人为规定"$|k| < 0.01 \Rightarrow$ free"有理论出处：**free 这一级不是容差 hack，它就是 $\mathcal N$**。

落地：`polish_soft_modes` 的四级判据 + `network.free_bonds_of` +
`chemistry.free_aligned_symmetric_rmsd`——microstate 去重前先沿 $\mathcal N$ 取商
（RMSD 比较前沿自由坐标对齐）。

### `polish_soft_modes` 的四级

先测一个扭转的广义力与刚度（`torsion_response`，沿该坐标**自己的精确路径**差分，
所以没有链式法则、也没有"其它坐标怎么固定"的歧义；桥键上是刚体旋转，别的什么都不动）：

$$g_q = \frac{E(+\delta) - E(-\delta)}{2\delta}, \qquad
k_q = \frac{E(+\delta) - 2E(0) + E(-\delta)}{\delta^2}$$

单位 eV/rad 与 eV/rad²。四级：

| tier | 条件 | 处理 |
| --- | --- | --- |
| `stiff` | $k_q > $ `soft_mode_curvature_max` $=50$ | 全局力容差已经钉住了它 |
| `negative_curvature` | $k_q < 0$ 且 $\lvert k_q\rvert \ge$ floor | 不动；这是极小检验该做的判断 |
| `free` | $\lvert k_q \rvert <$ floor $=0.01$ **且** $\lvert g_q\rvert \le$ floor $\cdot$ tol | 平坦坐标，值不携带信息，记录而不要求 |
| `flat_biased` | $\lvert k_q\rvert <$ floor **但** $\lvert g_q\rvert$ 超界 | 曲率太小不能当 Newton 尺度，但坐标不驻定 |
| （其余） | soft, 正曲率 | 要求 $\lvert g_q/k_q\rvert <$ tol，并做 Newton 步 |

第四级是被实测逼出来的：3-氧代丁醛的产物极小被报成比紧容差下的同一极小高 $9.97\ \mathrm{meV}$，
差额全在一个被标为 "free" 的甲基扭转上——曲率 $0.0041 < 0.01$，但梯度 $-0.014\ \mathrm{eV/rad}$，
且坐标离极小 $0.71\ \mathrm{rad}$。**平坦坐标没有梯度；小的局部曲率只意味着 Newton 尺度
在转子势垒的拐点附近不可用。** 而且 "free" 这个判决还喂给 `free_bonds_of`，
于是那个坐标被从 microstate 比较里错误地商掉了。

梯度界是**推导出来**而不是选出来的：在这个函数愿意信任的最小曲率处，
小于 `floor * tolerance` 的梯度不可能把坐标推出容差。

### 淬火的收敛判据

`quench` = FIRE 到 `quench_fmax_eV_A`，然后最多 `soft_polish_rounds` 轮
"抛光 $\to$ 若动过则重新 FIRE"。收敛 **= 抛光满意 AND 抛光没有移动几何**。
只看"满意"会在抛光刚刚位移过的结构上报告收敛——实测在 3-氧代丁醛产物上，
一个 $0.35\ \mathrm{rad}$ 的甲基扫描步返回 `converged=True` 而 $f_{\max} = 0.179$
对着 $0.02$ 的容差。

## 3.10 极小检验：`confirm_minimum`

梯度消失只说明是**驻点**，极大和鞍点一样满足。不检验的话势垒顶会被记成产物盆地。

两条路线，且**用了哪条被记录下来**：

**`hessian`**：对角化质量加权 Hessian（刚体模投掉），要求剩下的每个本征值 $\ge -$`tol`。

$$H_m = \frac{H}{\sqrt{m}\,\sqrt{m}^\top}, \qquad
\text{spectrum} = \operatorname{eigh}\bigl(P H_m P\bigr), \qquad P = I - B^\top B$$

矩阵有两个来源：

- `analytic`：后端自己的二阶导（MACE 的力本来就是 autograd，所以二阶导是免费的）。
  **不被信任，而是被执行证明**：单位因子（$E$ 与 $F$ 的换算因子未必被施加到 Hessian 上，
  而当因子恰为 1 时错误是静默的）和数组布局都没有保证。所以做
  `analytic_hessian_check_directions` $=3$ 个**seed 化随机方向**的 HVP 对账，
  相对偏差必须 $<$ `analytic_hessian_check` $=10^{-2}$。用随机方向而非固定图案，
  是因为结构化的探针会对结构化的错误失明（一个置换或分块的布局可能恰好不改变那个向量的乘积）。
  另外**在对称化之前**测不对称度并记录——二阶导本该对称，一个不对称的原始矩阵说明
  布局或单位错了，先对称化会把这个信号抹成一个更小、更像样的、摊到全矩阵的误差。
- `fd`：$6N$ 次力评估的中心差分，截断误差 $O(h^2)$，之后 $\tfrac12(H + H^\top)$ 对称化。

`auto` 优先解析，失败则回退并记录原因。

**`probe`**：seed 化的质量加权位移 + 测 $v^\top Hv$，便宜但只采样若干方向。
在乙醇扭转势垒顶实测**两个等价鞍点只抓到一个**，所以它是给大体系的 fallback，不是默认。
它的 `meaning` 写着："负值是鞍点的决定性证据；全正**不是**极小的证明。"

### 三道闸门，全部 fail-closed

1. **刚体地板**：`worst_floor > trivial_floor_fraction * tol` $\Rightarrow$
   符号结构不可读，拒绝，`saddle_order = None`。
2. **`internal_mode_recheck`**：地板做不到的那件事——**把计数本身用第二种方法再测一遍**，
   拿组装出来的矩阵去对一个截断外推的直接乘积。阻塞或不一致都拒绝。
   （它的 `fits_h2_law` 字段有一条重要限定：阶梯是 $h$ 的二次式**只说明外推有意义**，
   **不是**曲面光滑的证据——一个比探针还窄的高斯在 25 倍跨度上同样能拟合到半个百分点。）
3. **门控拒绝**：任何一次力评估被 `GuardedCalculator` 拒绝，整个检验返回未确认。

**"未测量"永远不等于"已确认"**，这是全仓库统一的方向。

### 恰好一个负模不是废料

`len(negative) == 1` 是**一阶鞍点**——一个 TS 候选，它的本征向量就是反应坐标，
正是 dimer 或 NEB 精化本来还要重新发现一遍的东西。所以它进入自己的 TS pool，
不进 reservoir 也不进垃圾桶。

虚频按下式上报（且**只在** `saddle_order == 1` 时上报）：

$$\tilde\nu\ [\mathrm{cm^{-1}}] = -\frac{\hbar \times 10^{10}}{\sqrt{e \cdot u}} \cdot \frac{\sqrt{-\lambda}}{\text{invcm}}$$

## 3.11 从盆地边界走到鞍点：`follow_min_mode`

**找到不稳定方向不等于找到鞍点。** `lowest_response_direction` 回答"负曲率指向哪"，
到达那里还需要中心移动。

Min-mode following 的经典形式是把沿最低模的力反号：

$$\boxed{F_{\rm TS} = F - 2\,(F \cdot v)\,v}$$

于是行走在除 $v$ 外的每个方向下降、在脊上上升。这里实现成**该表达式所近似的那个 Newton 步**，
在解析 Hessian 的本征基里取：Newton 步收敛到最近的驻点**不论其指标**，这就是同一个反号，
但精确、并且以曲率为尺度。这个选择之所以可用，是因为解析 Hessian 实测干净到 $10^{-15}$
且在这些尺寸上比有限差分更便宜。

要点：

- **刚体方向是排除，不是反号**；
- 步长有**信赖域**上限 `min_mode_step_A`，因为 Newton 步只在二次模型好用的范围内好用；
- 谱每 `min_mode_refresh` 步刷新一次；
- **爬哪个模**是分情况的（这是实测逼出来的关键分支）：
  - **给了 `direction`**（要跟的坐标）：选与该方向**质量加权重叠最大**的本征向量，
    并带符号地向前传递，使行走留在被问的那个坐标上；
  - **没给**：问题真的是"最软的鞍点在哪"，答案就是最低**非平凡**模。

  为什么必须分：在 3-氧代丁醛上，甲基和羟基转子是分子里最软的东西，每次取最低本征值
  返回了 8 个 $-65$ 到 $-80\ \mathrm{cm^{-1}}$ 的转子势垒，而质子转移在 $-3186$。
- **能量天花板** `saddle_search_max_rise_eV`：爬升否则是无界的，会开心地到达一个和
  引发它的反应毫无关系的鞍点——从丙二醛探针帧出发它到过 $2.34\ \mathrm{eV}$ 高处的
  O–H 均裂，端点是一对自由基，完全在模型域外。**越界的一步是回溯而不是致命**
  （把步长问题误当域问题曾经拒掉了一个已经到达质子转移鞍点的种子）；
  **起点就在天花板之上是另一种判决**，跳过让下一个种子来。

**种子比优化器重要。** 淬火停在鞍点上是一个软坐标的巧合，不是算法：在丙二醛上实测，
60 个探针找到产物 2 次、鞍点 0 次，而那个鞍点在 $\lambda_1 = -37.3$——比乙醇上真发生过
巧合的那些势垒陡 120 倍。PRRS 原生的部分是**种子**：一个靠近分界面的幅度，
现在由瞬态穿越帧保留下来。

`follow_min_mode` 返回的是**候选**。是最后在收敛几何上运行的 `confirm_minimum`
才被允许对指标做出声明——这两个角色的标准不同，值得点名。

## 3.12 TS 认证的最终形式

不再是

$$\text{optimize} \to \text{Hessian} \to \text{frequency} \to \text{数虚频}$$

而是三个数学属性：

$$\boxed{\text{stationarity} + \text{index} + \text{connectivity}}$$

$$\nabla E(x^\ddagger) = 0, \qquad \dim\mathcal U = 1, \qquad
\Phi(+v_u) = A,\quad \Phi(-v_u) = B$$

其中 $v_u = \arg\min_v \kappa_0(x^\ddagger; v)$，$\Phi$ 是 quench / basin map
（代码里的 `descend_saddle`）。

**$\Phi$ 给出的是 $\mathcal X$ 上的无向关联。** 有向反应边需要另外的证据——
所以记录里 `_CONNECT_SADDLE_MEANING` 写着 "undirected, and no barrier is implied"。

一个负方向**不能**证明只有一个：

$$\kappa(v_1) < 0 \Rightarrow n_- \ge 1$$

要认证 $n_- = 1$ 必须看第二低模。Ritz 值满足 Cauchy 交错 $\theta_k \ge \lambda_k$，
**这个方向只帮一半的忙**：每个负 Ritz 值都**严格证明**存在一个负本征值（下界严格），
但"没有第二个负 Ritz 值"**不能**证明没有第二个负本征值（上界不严格）。

### $\nu_a$ 对 $a$ 是非单调的

一个曾经写在纸上的猜测——"局部干净的一阶鞍点，走远出现第二个非线性逃逸通道，
所以 $\nu_a$ 随 $a$ 增加"——**被实测证否**。在乙醇 syn 鞍点上，$\nu_a$ 随 $a$ **减小**：
$a \lesssim 0.05$ 时 $\nu_a = 1$，$a \gtrsim 0.1$ 时 $\nu_a = 0$，因为那个不稳定模是
有界周期坐标，走远会翻过邻近极小再爬升。

**两个方向都可能，不能假设。** 这条留在这里作为一个方法论样本：这个仓库里被实测推翻的
猜测是标注保留而不是删除的。
