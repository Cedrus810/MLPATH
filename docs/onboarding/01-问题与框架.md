# 01 问题与框架

## 1.1 要解决的问题

给定一个稳定结构 $A$ 和一个可靠的势能模型，**在不知道产物的前提下**，找出
$A$ 能发生哪些反应。

$$\boxed{\text{从稳定结构 } A \text{ 出发，主动扰动系统，观察响应，自动发现反应通道 } A \to B_i}$$

明确**不需要**：

- 完整 Hessian；
- 预先给定的产物；
- 预先给定的反应坐标；
- 预先给定的最小能量路径。

第一目标不是过渡态，而是**盆地连通性** $A \leftrightarrow B$。势垒和 TS 精化是之后的事。
这条分工在文档里反复出现，值得记住：

$$\boxed{\text{reaction discovery} \ \ne\ \text{reaction characterization}}$$

## 1.2 为什么不是"NEB 的又一个小改动"

NEB / string / dimer 这些方法的共同前提是**你已经知道要连接什么**（NEB 需要两端）
或者**你已经在鞍点附近**（dimer 需要好的初猜）。它们是**局部精化工具**，不是发现引擎。

更深一层的理由是计算结构的改变：

| | 传统量化 | MLP |
| --- | --- | --- |
| 单次力评估 | 昂贵 | 极便宜 |
| 并行度 | 低 | 高 |
| 算法应当优化 | **最小化力评估次数** | **用大量廉价动力学实验换信息** |

所以 PRRS 的立场是：不要把 MLP 塞进为昂贵 ab initio 设计的算法里，而是围绕现代 MLP
的实际计算结构设计算法：

$$\boxed{\text{大规模并行扰动} + \text{短轨迹响应} + \text{自适应反应发现}}$$

在这个框架里，NEB / dimer / eigenvector following 仍然存在，但降级为
$\boxed{\text{局部精化工具}}$，在连通性已经建立之后才被引入。

## 1.3 核心循环

$$\boxed{\text{State} \to \text{Perturb} \to \text{Respond} \to \text{Classify} \to \text{Refine}}$$

写开：

$$R_0 \to \{P_k\} \to \{\tau_k(t)\} \to \{B_1, B_2, \ldots\} \to \text{reaction channels}$$

- $R_0$：当前局部极小；
- $P_k$：第 $k$ 个扰动；
- $\tau_k(t)$：一条短 MLP 轨迹；
- $B_i$：新发现的盆地。

一次 trial 在代码里就是 `runner.run_trial`，具体是这样一条流水线：

```
source (已淬火, p = 0)
   │  probe.mode == "displace" 时施加几何扰动，并做二维交付验收（目标坐标 + 附带损伤）
   ▼
perturbed
   │  按 temperature_K 赋予热动量（默认 0 K）
   │  probe.mode == "kick" 时注入精确的 ΔK
   ▼
[可选] forced 段：pulse 家族在 pulse_steps 步内加一个保守偏置力，然后撤掉
   ▼
free 段：response_steps 步 **无偏置** NVE（Velocity Verlet, timestep_fs）
   │  每步都检查 NVE 能量漂移、力上限、原子重叠、模型不确定度
   ▼
raw_endpoint
   │  清零动量，FIRE 淬火 + mode-resolved 软模抛光
   ▼
endpoint  →  classify  →  confirm_minimum  →  admit 到网络
```

两个阶段的分离是关键：**forced 响应**期间扰动在作用，**free relaxation**期间扰动已撤掉。
第二段才是有信息的那一段——如果系统回到原盆地，响应是弹性/构象的；如果落到别处，
才发现了一个盆地跃迁。

## 1.4 五类响应

$$C = \{\text{elastic},\ \text{rearrangement},\ \text{reactive},\ \text{dissociation},\ \text{unphysical}\}$$

`state.classify` 的判定逻辑（$G_A, G_B$ 是首末键图，$n_A, n_B$ 是碎片数）：

$$
\text{label} =
\begin{cases}
\text{dissociation}, & G_A \ne G_B \ \text{且}\ n_B > n_A \\
\text{reactive}, & G_A \ne G_B \ \text{且}\ n_B \le n_A \\
\text{elastic}, & G_A = G_B \ \text{且 same\_basin} \\
\text{rearrangement}, & G_A = G_B \ \text{且非 same\_basin}
\end{cases}
$$

其中 same_basin 要求键图相同、$|\Delta E| \le$ `basin_energy_eV` 且 Kabsch RMSD $\le$ `basin_rmsd_A`。

第五类 unphysical 不由这里产生，而是由 `reliability.GuardedCalculator` 在**每一次力评估**上
抛出 `GateRejected`——包括 FIRE 淬火内部的每一步。通用 MLP 会在外推区给出看似合理
但完全错误的力，这个门是防止把外推伪影当成化学的唯一手段。

## 1.5 幅度是一个搜索变量

每个方向 $P_k$ 在一组幅度上扫描：

$$P_{k,m} = a_m P_k, \qquad a_1 < a_2 < \cdots < a_m$$

典型行为是

$$a < a_c: \ A \to A, \qquad a > a_c: \ A \to B$$

找到一个"返回/离开"的相邻对之后，`search.py` 做**二分细化**（`refinement_steps` 次）
得到窗口 $[a_{\rm low}, a_{\rm high}] \ni a_c$。

$a_c$ **不是**活化自由能：

$$a_c \ne \Delta G^\ddagger$$

它是一个**反应可及性/易感性**得分，$S_{\rm react} = 1/a_c$，只在同一个扰动家族内可比。
代码里这个窗口记为 `local_brackets`，字段 `meaning` 写着
"local observed window; no monotonicity assumed"——因为实测到过**非单调**返回
（`nonmonotonic_return_observed`），大幅度回到源盆地是可能的。

`high_kind` 三态也要注意：

| 值 | 含义 |
| --- | --- |
| `confirmed` | 到达了另一个已确认的 microstate |
| `boundary_unattributed` | **到达了某个盆地边界，不等于跨过了被探测的那个坐标** |
| `transient_crossing` | 新键图在自由段末尾没能维持住 |

`boundary_unattributed` 这个区分是实测逼出来的：在 3-氧代丁醛上每个 O–H 幅度都停在
$-65$ 到 $-80\ \mathrm{cm^{-1}}$ 的转子势垒上，而质子转移在 $-3186\ \mathrm{cm^{-1}}$。
把前者记成"沿 O–H 离开了"就是为一个没发生的反应提供证据。

## 1.6 三条设计原则

**原则 1：不要重建近似 Hessian。** 扰动的目的不是重构局部二阶导。
$\boxed{\text{响应本身就是信息}}$，非线性响应是主观测量。
（但 Hessian 并没有被赶走——见 03 章：它是响应算子的 $a \to 0$ 极限，是
*validation limit* 而不是 primary observable。）

**原则 2：扰动是探针，不是偏置势。** 循环是
perturb $\to$ observe $\to$ learn $\to$ adapt，系统怎么响应决定下一步搜哪里。

**原则 3：先发现连通性，再要求 TS。** 只有在"不知道产物也能发现连通性"成立之后，
才去谈过渡态、势垒、IRC、自由能、机理排序。

## 1.7 这个框架当前**不**声称什么

两条写在 `search.py` 模块 docstring 里的自我限定，新人必须先读：

**它是采样器，不是枚举器。** 提案基是一组化学信息驱动的内坐标，**故意不是**整个 $3N$
空间的基。反应坐标不在这个基张成的子空间里，任何幅度、任何预算都到不了。没有任何东西
估计"给定预算能找到可达盆地的百分之几"。唯一被支持的读法是"搜索找到了这些反应"，
"这些就是全部反应"不是，再大的预算也不能把它变成。

**两条分析线不是同一件事的独立测量。** 消失幅度处的曲率**认证**候选，有限幅度响应
**刻画**它——但响应探针是用认证给出的不稳定本征向量做种子的，所以一个错的 Hessian
让两者一起错，它们一致不构成互证。真正独立的第二读数必须从别的东西起步：到达时的位移，
或者一个具名的内坐标。

## 1.8 已有的东西与还没有的东西

已经落地并且实测过的：结构化扰动提案与交付验收、响应分类、两层网络与身份、
mode-resolved 淬火、解析/有限差分 Hessian 与极小检验、min-mode 爬升到鞍点、
鞍点两侧下降、幅度二分细化、fail-closed 门控、完整 manifest。

**还是设想、没有实现**（原始方案 §8/§13/§16 里的内容）：

- 学习型扰动提案 $\pi_\theta(P \mid R)$；
- 效用函数驱动的自适应扰动选择 $P^* = \arg\max_P U(P)$；
- 反应导向的主动学习 $A(R) = P_{\rm reactive}(R)\,U_{\rm MLP}(R)$；
- reaction tube（反应轨迹系综的中心流形）代替单条 MEP。

当前的"自适应"只有两条：幅度二分细化，和 reservoir 评分对构象搜索顺序的影响。
氢键先验（`_hydrogen_bonded_donors`）是一个**排序**先验，从反应物自身几何读出，
它说的是"这根键不寻常"，不是"这个反应会发生"，而且**只用来排序，从不用来丢弃候选**。
