# 04 化学身份与反应网络

对应源码：`src/prrs/state.py`、`src/prrs/chemistry.py`、`src/prrs/network.py`。

这一章回答：**"这是同一个物质吗"和"这是同一个反应吗"分别怎么定义。**
这两个问题的答案必须**不读能量、不读力、不读势垒**——它们是关于结构的定义，
不是关于某个模型的测量。

## 4.1 键图编码

`state.encode`。共价半径判据：

$$d_{ij}^{\rm cut} = \texttt{bond\_scale} \cdot \bigl(r_i^{\rm cov} + r_j^{\rm cov}\bigr), \qquad \texttt{bond\_scale} = 1.2$$

**连续权重**（用于配位数等连续描述符）是一个 logistic：

$$w_{ij} = \frac{1}{1 + \exp\!\bigl[12\,(d_{ij}/d_{ij}^{\rm cut} - 1)\bigr]}, \qquad w_{ii} = 0$$

$$\mathrm{CN}_i = \sum_j w_{ij}$$

**离散边集**另有**滞回**（hysteresis），防止在阈值附近抖动生成假事件：

$$(i,j) \in E \iff d_{ij} < d_{ij}^{\rm cut} \cdot \bigl(1 \pm \texttt{bond\_hysteresis}\bigr)$$

上一帧有这条边取 $+$，没有取 $-$（`bond_hysteresis` $= 0.08$）。滞回只在**沿轨迹**
比较时启用；端点身份计算时不带 `previous`，保持无路径依赖。

**活性子集**（`active_atoms`）贯穿全部比较。MVP 设成全部原子，但把这个区分显式保留，
是为了以后反应区能坐在一个大的 MM/QM/MM 环境里而不必重写分析层：溶剂重排不能让
同一个盆地的两次访问看起来像两个盆地，而几千个环境原子的全对距离矩阵既不可负担也无意义。

**Kabsch RMSD**（`aligned_rmsd`）：中心化后取 $X^\top Y$ 的 SVD $= U\Sigma V^\top$，

$$R = U \operatorname{diag}(1,1,\det(UV^\top))\,V^\top, \qquad
\mathrm{RMSD} = \sqrt{\tfrac1n \sum_i \lVert (XR)_i - Y_i\rVert^2}$$

行列式修正保证是**真旋转**而不是镜像——否则一对对映体会被判成同一结构。

## 4.2 化学身份：`chemical_key`

反应网络是**化学宏观态**上的图，构象住在节点内部。这个分层只有在化学身份满足两个
"盲"的时候才成立。

### 盲于构象

绕可转单键的有符号扭转区分 gauche+ 和 gauche−，那是**同一个物质**。把它放进 key
会把一个宏观态劈成两个，重现分层本来要防止的组合爆炸。

**只有构型立体化学**——不断键就改不了的宇称——才进 key。

历史上试过、且都失败的两个替代方案，值得记住：

- **用键长做判据**：把一个硬分类器塞进身份函数里。丙二醛烯醇的 C–OH 距那条线
  $0.0002\ \mathrm{\AA}$，于是相差 $0.0003\ \mathrm{\AA}$ 的两个结构变成了两个化学节点。
- **用扭转刚度做判据**：这只是把线挪了个位置而没有去掉它。同一根 C=C 在分子内氢键
  闭合时测 $4.59\ \mathrm{eV/rad^2}$、打开时测 $0.66$——**而那是同一物质的两个构象**。

### 盲于原子编号

在固定原子映射下，转移甲基上三个等价氢中的任何一个都给出**不同的原子下标集合**，
却是同一个反应。直接用原始边集做 key 会记下三个产物。

所以 key 的图部分是一个**颜色细化哈希**（1-WL），自同构不变：

$$c_i^{(0)} = \text{element}(i), \qquad
c_i^{(t+1)} = \operatorname{hash}\Bigl(c_i^{(t)} \,\big\|\, \operatorname{sorted}\bigl\{c_j^{(t)} : j \in \mathcal N(i)\bigr\}\Bigr)$$

迭代 $N$ 次（$N$ = 原子数）。**等色 = 等价原子。**

限定要写清楚：细化**按构造**是不变的，但**不是一个可证明完备的正则形式**。
对这个尺寸的分子图，实测分开了遇到的每一个情形；而一次碰撞会**合并**两个化学，
不会**发明**一个——失败方向是安全的那一边。

### key 的四个成分

$$\text{key} = \operatorname{sha256}\Bigl(\underbrace{\text{颜色多重集}}_{\text{图}} \,\|\, \underbrace{\text{碎片分子式}}_{\text{连通分支}} \,\|\, \underbrace{\text{构型宇称}}_{\text{立体化学}} \,\|\, \underbrace{[\text{charge, spin}]}_{\text{仅当模型响应}}\Bigr)$$

碎片由并查集（`_fragments`）得出，每个碎片报一个分子式。

电荷和自旋**只在势能真的对它们有响应时**才进 key。实测 MACE-OFF24 对总电荷
$0 / -1 / +1$ 返回**逐位相同**的能量，所以 `charge_sensitive = False`，配置层拒绝非零
`total_charge`——**把带电化学挡在搜索空间之外，而不是让它悄悄溜进来**。
（MACE-POLAR-1-M 在同样三种电荷上跨度 $16.67\ \mathrm{eV}$，对它 `charge_sensitive = True` 才对。）

## 4.3 构型立体化学

### 四面体宇称

只在**四个邻居颜色两两不同**的原子上记录。四个不同颜色恰好就是"真正的立体中心"的条件：
两个邻居同色 $\Rightarrow$ 交换它们是一个自同构 $\Rightarrow$ 没有构型可记。
甲基碳因此贡献零。

按颜色排序邻居为 $n_0 < n_1 < n_2 < n_3$，取

$$b_k = x_{n_k} - x_{n_0}\ (k = 1,2,3), \qquad
V = \det[b_1, b_2, b_3], \qquad
\boxed{s = \frac{V}{\lVert b_1\rVert \lVert b_2\rVert \lVert b_3\rVert}}$$

**除以三条边长很重要**：它不改变符号，但把量纲从"体积"变成"形状"——
$s \in [-1,1]$ 的有符号体积比，缩放分子不变，中心换个元素也不变。不做这一步，
`int(np.sign(...))` 是在读一个尺度未知的数的符号：在近平面的中心那个数是浮点噪声，
**热扰动本身就能翻转记录的构型并铸造一个新的宏观态**。而且 $\operatorname{sign}(0) = 0$
会悄悄变成第三个宇称值，对应不到任何化学。

所以：$\lvert s\rvert >$ `parity_tolerance` $= 0.01$ 时记 $\operatorname{sign}(s)$，
否则记 `"planar"`——理想四面体的比值是 $0.1$ 量级，严格平面是 $0$，真实 sp³ 离这条线远得很。
**一个不动的标记比一个对一半的符号更值钱。**

### E/Z 宇称：哪些键有资格承载

一根键要能记 E/Z，必须**在每一个可容许的 Lewis 结构里都至少是双键**。

`admissible_bond_orders` 枚举**所有**满足中性闭壳价的整数键级分配：

设 $V_i$ 是元素 $i$ 的价（`VALENCE = {H:1, C:4, O:2, F:1, Cl:1, Br:1, I:1}`），
每条边起点是键级 1，剩余价

$$\text{surplus}_i = V_i - \deg(i)$$

$\text{surplus}_i < 0$ 直接判 `degree_exceeds_valence`。然后 DFS 在每条边上放
$\text{extra} \in \{0,1,2\}$（上界 $\min(\text{surplus}_a, \text{surplus}_b, 2)$），
要求所有 surplus 恰好归零。枚举步数超过 `limit = 20000` 报 `enumeration_limit`。

**要的是一个集合，不是一个 Lewis 结构。** 苯的"哪条边是双键"取决于挑了哪个 Kekulé
结构，从单个分配读出的任何性质都是那个选择的伪影；问"什么在所有分配上都成立"才是良定的。
这也是**唯一**与构象无关的表述，而化学身份必须与构象无关。

$$\boxed{\text{locked} = \{e : \text{order}(e) \ge 2 \text{ 在每个可容许分配中}\}}$$

在一个 Kekulé 里是双键、另一个里是单键的边**没有构型可记**；在所有分配里都是单键的边
**承载不了构型**。

宇称本身：对 locked 边 $(a,b)$，各取一端**唯一的最高颜色取代基**（不唯一则无 E/Z 可记），
判别式是两个垂直分量之间的**余弦**，不是点积：

点积带着两个取代基的长度，于是旧的 $10^{-6}$ 截断实际上是"一个用 Å 冒充角度的长度"——
它会在一个离 $90°$ 差得远的短取代基上触发，而在一个长的上永远不触发。
在交叉点余弦为零、符号是噪声，所以带内报告"构型缺失"而不是随最后一位数字翻转。

### 无法解析时

价表**故意小**：第一版必须在 C/H/O 上正确（覆盖每个基准），加上单价卤素（末端且无歧义）。
N、P、S **被有意排除**——它们的价在中性闭壳设定下不是单值的。

表外的元素报 `unsupported_elements`，立体化学记为 **unresolved**——
**不是**"没有立体化学差别"，也**不是**拒绝这个物种的理由。

三件事被严格分开（`Registry.admit` 的注释）：

| | 是什么 | 属于谁 |
| --- | --- | --- |
| **身份内容** | 图、碎片、宇称 | 物质本身 |
| **身份解析状态** | 立体化学**能不能**算出来 | 标注器 |
| **模型域证据** | 势能**能不能**描述这个物种 | 模型 |

只有第三条会拒绝。而且它由**模型声明** `closed_shell_only` 把关，不是标注器的判决：
MACE-OFF 在中性闭壳分子上训练、对总电荷完全无响应（逐位实测），所以把带电或开壳物种
放进网络当产物是错的。**电荷感知的势应当声明 `closed_shell_only = False`**，
同样的结构就会被接纳，立体化学记为 unresolved。

反向读法是禁止的：**未解析的标注不是"域外"的证据，已解析也不是"域内"的证据。**
域属于 `benchmarks/*/model.json` 与 preflight 门控。

## 4.4 反应事件身份：`reaction_event_key`

化学态身份和反应事件身份是**不同的问题**。

key 把状态的每一个冗余都商掉了——**包括**那个让退化重排回到原点的自同构，而且它必须这么做，
否则转移三个等价氢中的一个会铸造三个产物。但正因如此，它**不能**用来判断反应是否发生：
key 对路径是盲的。一个质子从一个氧移到另一个氧，返回的结构 key 完全相同，
而键集**不是**它出发时那个。

所以两者都需要。事件身份定义为：

$$\text{broken} = E_A \setminus E_B, \qquad \text{formed} = E_B \setminus E_A$$

在**两个端点各自的自同构群**的并集 $\mathcal P$ 上取正则形式，并且**商掉方向**：

$$\boxed{\text{form} = \min\Bigl(\min_{\pi \in \mathcal P}\bigl(\rho_\pi(\text{broken}), \rho_\pi(\text{formed})\bigr),\ \min_{\pi \in \mathcal P}\bigl(\rho_\pi(\text{formed}), \rho_\pi(\text{broken})\bigr)\Bigr)}$$

$\rho_\pi$ 把键渲染成带元素标签、无取向的对。方向被商掉，是因为**一条通道的正向观测与
反向观测是两次观测，不是两条通道**——这与"鞍点的两个端点是无向的结构性证据"是同一个处理。

键模式本身**不是全局身份**：两个不同的物质可以在同样的下标上断开和形成同样的元素
（丙二醛和 3-氧代丁醛的 preflight 里都发生过）。所以摘要里再拼上端点图哈希的**无序对**：

$$\text{key} = \operatorname{sha256}\bigl(\operatorname{repr}(\text{form},\ \operatorname{sorted}(h_A, h_B))\bigr)$$

**自同构枚举超预算时抛 `IdentityUnavailable`**，而不是悄悄用恒等置换——那样 key 就取决于
limit 而不是反应了。失败方向仍然是"**多**数通道而不是静默合并不同的通道"。

## 4.5 转移的四格分类

`classify_transition` 用 key 和键差**一起**判断：

| | 键集**没变** | 键集**变了** |
| --- | --- | --- |
| **key 相同** | `conformational_transition` | `degenerate_reaction`（automerization） |
| **key 不同** | `configurational_isomerisation` 或 `key_change_without_bond_change` | `reaction` |

- 键差为空 $\Rightarrow$ 构象变化，**不论几何走了多远**；
- 键差非空 $\Rightarrow$ 反应，**不论 key 变没变**；key 没变时是**退化反应**。

左下格曾被无条件命名为 `key_change_without_bond_change` 并当作缺陷，理由是"key 若只是
键图的函数，这一格不可能非空"。但 key **故意不是**那样：它还带构型立体化学。
所以 **E/Z 异构化合法地落在这一格**，是真实事件，只是能量更高——在 3-氧代丁醛上独立
测到两次：同一根 locked 键宇称从 $-1$ 翻到 $+1$，图哈希不变，比反应物高 $365$–$404\ \mathrm{meV}$。

于是这一格被拆开：在其余成分完全相同的情况下只有宇称翻转的，是
`configurational_isomerisation`；其它任何东西保留旧名并**仍然是待诊断的缺陷**。
拿不到 components 时保守地用旧名。

丙二醛（P1）基准就是为了检验这套东西选的：它的质子转移是**退化重排**，
两个互变异构体 `chemical_key` 相同，所以它**只能**被 `reaction_channels` 的 self-loop
捕获。捕不到就说明自同构商把真实反应事件吃掉了。

## 4.6 两层网络

把每个不同的极小拍平成一个节点，撑不过与真实分子的接触。乙醇在 $47\ \mathrm{meV}$ 内
有三个构象极小；更大的分子有组合多的构象。一个平坦的网络会把全部预算花在枚举构象上，
并在同一物质的构象之间画反应边。所以：

```
chemical node      一个物质，由 chemical_key 标识
  └── microstates  该物质的不同构象，一个有界的 reservoir
```

**准入由 `chemical_key` 决定，绝不由响应标签决定。** 一个等价氢转移被分类为 "reactive"
（因为图变了），但那是同一个化学；只有 key 改变才开一个化学节点。

**双预算**：

| 预算 | 参数 | 语义 |
| --- | --- | --- |
| 化学节点数 | `chemical_max_nodes` $= 16$ | 发现新物质 |
| 每节点 trial | `chemical_trials_per_node` $= 96$ | |
| 每节点构象数 | `conformer_max_per_node` $= 8$ | 构象丰富度**不是**化学发现 |
| 每构象 trial | `conformer_trials_per_microstate` $= 32$ | |

发现第九个已知物质的构象**不得**消耗一个化学节点名额。但构象**保持可搜索**——
反应可及性是**条件于构象的**（anti 可能不反应而 gauche 反应），所以一个有界的构象集合
仍然作为扰动原点保留。这也是 `search.py` 开头那句话的意思：
"whether A reaches B depends on which conformer of A was perturbed"。

### reservoir 评分

$$\boxed{S = w_E\, S_E + w_D\, S_D + w_R\, S_R}$$

（三个权重默认都是 $1.0$。）

**能量项**：以该节点已知的最低构象为地板，Boltzmann 型衰减

$$S_E = \exp\!\left(-\frac{\max(E - E_{\min},\, 0)}{k_B T_{\rm conf}}\right), \qquad T_{\rm conf} = \texttt{conformer\_temperature\_K} = 300$$

**多样性项**：到最近同伴的扭转距离，归一到 $[0,1]$

$$S_D = \min\!\left(\frac{\min_{s' \ne s} d_{\rm tors}(s, s')}{\pi},\ 1\right), \qquad
d_{\rm tors}(a,b) = \sqrt{\frac{1}{|K|}\sum_{k \in K}\bigl[\operatorname{wrap}(a_k - b_k)\bigr]^2}$$

$K$ 是共有的扭转坐标集。用**圆周差**而不是普通差——角度是周期的，普通差不是度规。

扭转 profile（`torsion_profile`）**故意排除对称转子**：甲基转一下自己的扭转变了 $120°$
而产生的结构是原结构的对称副本，把它算进去会让副本看起来"多样"并赢走 reservoir 名额。

**响应项**：奖励响应得**不一样**的构象

$$S_R = \begin{cases}
1, & \text{尚未搜索（trials\_spent} = 0) \\
\dfrac{\#\{\text{该构象独有的 outcome}\}}{\#\{\text{该构象全部 outcome}\}}, & \text{否则}
\end{cases}$$

未搜索的构象被打成**最大信息量**，这是**有意的乐观**：它让 reservoir 成为一个
**不确定性下的在线选择**，而不是对已知结果的一次聚类。

### 自由坐标的商

一个刚度降到零的扭转，把它两侧的结构用一条**零势垒**路径连起来，所以不管坐标差多远
它们是同一个盆地、同一个 microstate。普通 RMSD 说不是。

`free_aligned_symmetric_rmsd` 因此在 symmetric RMSD 之上，**再对那些不携带能量的坐标
上的旋转取极小**。哪些坐标是自由的，由**淬火报告**的 `tier == "free"` 给出，
并且**随几何走**（`free_bonds_of` 从 `structure.info["quench"]` 读）——因为这个判断是
**能量性**的，不能从图上猜。

这就是 03 章 §3.9 的 $\mathcal N$ 在网络层的落地。
