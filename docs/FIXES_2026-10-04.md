## 1. PRRS 续跑来源校验

新增 `src/prrs/provenance.py`。manifest 增加 `calculator_identity`：
factory 身份与源码/运行代码指纹、默认参数、闭包参数、显式 metadata 与本地输入内容哈希。
CLI 的 factory kwargs 被 load_factory 的闭包保留，因此也进入身份。
不能序列化核验的闭包对象被标记为 opaque；此类运行允许首次搜索，但不允许续跑。
外部资源应在 calculator_metadata/CLI kwargs 中显式声明；不能从 Python 任意全局
副作用推断未知外部模型，隐藏依赖仍需调用方提供可核验的来源契约。

`_rebuild_for_resume` 在回滚/删除任何文件之前比较 calculator identity，
并比较 Python/数值包版本（主机与内核字符串不作为数值环境相同的要求）。
换 factory、换 kwargs、同路径换 checkpoint、沿用过期文件哈希或无法核验都拒绝。
原结构、产物、配置与 implementation 哈希拒绝规则保留。

两条新增回归检查先在旧实现上确认失败；修复后真实 kill→resume 的拒绝检查通过，
拒绝前后源 run 所有文件逐字节相同。既有同条件 kill→resume 等价检查仍通过。

**兼容性**：旧源码指纹或缺 calculator identity 的中断 run 不能自动续进新实现。
历史完成结果保留原来源，不做追认或补写。

## 2. PARS 端点曲率和盆地参照

LBFGS 力收敛后额外计算中央力差分 Hessian；仅在设置了刚体消除时投影平移/转动。
记录最低特征值、步长、刚体模数与噪声容差。负曲率端点不接受为极小。
普通 NEB 的最高像点在端点时不交付反应势垒。

新 select 候选携带原 source 与 quench endpoint 的映射几何作为独立盆地参照，
保留在 provenance 中并随代表种子传递。refine 独立弛豫/检查这些参照，
再按映射 RMSD 检查两端，拒绝错盆地。PARS 不 import PRRS，不重算 chemical_key。
旧种子没有参照时明确记录 `basin_identity: unavailable`，不能据此声称身份验收；
需要此项验收时重新 select。

参数按工程检查明确写入 config、RATIONALE 和精修条件：

- `refinement_endpoint_hessian_step = 0.001 A`；
- `refinement_endpoint_curvature_tolerance = 1e-4 eV/A²`；
- `refinement_endpoint_identity_rmsd = 0.05 A`（与已有端点区分尺度一致）。

它们是给定 PES 上的数值验收条件，没有在看到本次真实 P1 结果后调值。
每个检查几何需 6N 次力调用；不是 QM 认证。

原 CLI 测试势存在源端点停在鞍点、另一通道沿谐振方向返回同盆的问题。
修正解析势为以原子源 x 坐标为原点的 x/y 双阱，给两个夹具通道真实不同的端点。
新增独立能量有限差分验证力为 −梯度，避免只让状态断言变绿。

## 3. 不确定度值与覆盖

NaN/Inf/负的不确定度在任意阈值配置下都返回 FAILED，结果能以严格 JSON 落盘。
配置拒绝阈值时要求每个精修像点有测量，unavailable/partial 均为 UNRESOLVED_MLP。
关闭阈值允许没有 committee，但仍记覆盖状态且不接受无效数值。
非有限的 refinement 数值配置在构建配置时拒绝。

## 4. PARS 来源与精修条件分组

新增独立 `pars/provenance.py`，记录 factory/calculator 源码、实际 calculator 参数、
可检查状态与已加载模型 state_dict 内容；另可通过 factory 模块的
`calculator_metadata()` 或 `--calculator-metadata JSON` 声明外部文件/设置。
本地文件每次重新算内容哈希。加入 PARS 全源码与数值包版本指纹。
不透明状态报错，不能以同一 factory 字符串充当模型相同的证明。

恢复精修时需构造 calculator 验证身份，身份不符不进行 force evaluation 或覆写。
无法核验的旧结果要显式 redo。未知条件的遗留记录在汇总前拒绝。

保留 `--only --redo`，允许逐候选另立精修条件；不再承诺整目录只有一种条件。
`refined_groups.json` 给出 homogeneous 标志、每组条件与候选清单；
flat `refined_paths.json` 保留原列表形态并给出 conditions_sha256 归属。
混组 CLI 明确提示，比较应在组内。种子哈希用于候选身份，不作为组间条件差异。
