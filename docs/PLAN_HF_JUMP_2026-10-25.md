## 1. 起点：已测到的事实

b05 E2 的 4 个括区（第一轮 sA `6-9`、`10-13`，sB `10-13`，fp32 sA `10-13`）实际是同一个几何区间 q ∈ [1.289, 1.489]：

| | 左支（反应物侧） | 右支（产物侧） |
| --- | --- | --- |
| 括区端点 E（eV） | −18880.127 | −18881.619 |
| 中点 q = 1.389 处 E / 反力（eV/Å） | −18880.027 / +0.46 | −18881.30 / −3.69 |

- 两支在中点相距 1.04 Å：q 驱动的约束极小路径在这里不连续（滞回），`refine_ts_ef` 按设计返回 `branch_unresolved`。
- 左支在中点已只比旧 E2 鞍点（−18880.018～−18880.020 eV）低 9 meV，而反力仍为正。旧 E2 鞍点是旧精修器（完整谱）得到的，不在任何一条 q 连续支上被证实。
- b05 的反力噪声 σ 还没测（b04 是 0.0034 eV/Å；b05 能量处是 2 个 fp32 量子，不能照搬）。

## 2. 范围与不做的事

做：§5.2 原文的两步——①「先缩小扫描步长，分别延续两侧分支；若仍不能形成连续的定位区间，保存双侧几何并返回明确的分支未决结果」；②「之后再比较有限幅度响应驱动的 E/F 局部鞍点更新；Dimer 可作基线」。

不做：
- 不平均两支几何、不跨支插值求根，不把能量突降当成越过 TS（§5.2）。
- 不接 D2 调度、恢复（属 HF-4）；不改 C1/C2、旧 `certify`、PRRS 共享原语。
- 不新增锁 / hash / 自动拒跑类门。下面 J1 的分支终止判据是搜索本身的判断，阈值按 §3 从实测推。

## 3. 施工步骤

### J0：b05 反力抖动实测（只测，不改代码）

`benchmarks/explore_d2/hf_ef_rf_jitter.py` 加一个 CASE 参数，在 b05 左支中点 q = 1.389 上重复 B、C 两项（8 次扰动重收敛；收紧 τ）。得到 b05 的 σ_RF 和同支两次收敛的最大几何差 δ_geo。
- 用途：给 `refine_ts_ef` 传 `reaction_force_sigma`；给 J1 的“同支”判据提供几何噪声尺度。
- 成本依据：b04 同项 1182 forward、145 s（2080 Ti）。

### J1：双侧分支延续与终止点定位（新原语）

新文件 `explore/src/explore/ts_branch.py`，函数 `continue_branches_ef(atoms, intent, bracket, factory, config, ledger, task, *, settings)`，返回 `BranchResult`（可 `to_dict()`）。

1. 从括区两端各自出发，向对侧以步长 Δq 做约束松弛延续（复用 `ts_ef` 的 `_Constraint` 与同一 BFGS 设置；需要把 `refine_ts_ef` 里的 `relax` 闭包提成模块级函数，行为不变，`test_ts_ef.py` 照常全过）。
2. 每一步判“仍在同一支”：本步对齐位移 `d_k = RMSD(x_k, x_{k-1})`，与该支前几步的位移尺度比较。光滑支上 `d_k ≈ |dx/dq|·Δq`；判据是 `d_k` 超过 `max(c·median(d_{k-m..k-1}), c·δ_geo)`。c 和 m 取值在解析台和 b04 上标定，并写明依据（相对量，不写死绝对 Å）。
3. 判到跳变时不前进，而是在 `[q_{k-1}, q_k]` 内把 Δq 折半重做，直到 Δq < Δq_min。终止点 q* 的不确定度就是 Δq_min，记为“该支在 q* 处终止”。Δq_min 按 J0 的 δ_geo 与 `|dx/dq|` 定。
4. 结果三类，全部保存两支逐点几何、E、反力、横向力、约束残差与成本：
   - `continuous_maximum`：某一支在终止前反力由正变负。把该支上变号的两点交给 `refine_ts_ef`（同支括区，满足其前提），得到 E/F 候选。
   - `hysteresis`：两支在各自终止点前反力都不变号。返回终止区间 `[q_R*, q_L*]`、两支在终止点处的几何与反力，状态写明分支未决（§5.2 首版的交付物）。
   - 预算 / 步数 / 能量上限 / 约束失败：按 `ts_ef` 现有口径记。
5. 测试（解析台，在 `test_ts_ef.py` 的耦合双键势上加一个带折叠的变体）：
   - 有折叠时报 `hysteresis`，终止点误差 ≤ Δq_min；
   - 无折叠的连续最大值走 `continuous_maximum` → 候选；
   - 完整谱 / 模型 Hessian 禁用；外部计数 = 账本；
   - 两支在同一 q 出现时不插值。

### J2：从终止点出发的 E/F 鞍点更新，Dimer 作基线

J1 返回 `hysteresis` 时，鞍点不在任何一条 q 约束极小支上，需要不受 q 约束的 E/F 鞍点更新。

- J2a（基线，先做）：ASE 3.29 `ase.mep.dimer`（Hessian-free），从左支终止点几何出发。初始方向取“同一 q* 处右支几何 − 左支几何”（对齐后），只作初值。记录收敛、完整力、方向漂移、步数与成本。
- J2b（本项目方法，后做）：用有限幅度响应方向（`prrs.runner.lowest_response_direction`，HF 记录 §3 表中“有限幅度 E/F 响应方向工具”）驱动的局部鞍点更新，与 J2a 在同一初值、同一预算下比较。此项的中心更新怎么写、幅度怎么定，需要单独的小设计，先交用户看再施工（§5.3：幅度要验证稳定区间）。
- 两者的候选都只作搜索结果，之后走与 b04 v2 相同的独立核验：完整 Hessian 阶数、两侧下降与事件标签，并与旧 E2 鞍点比较 Kabsch RMSD 与 ΔE（同一 fp32 模型；旧第一轮鞍点是 fp64 升格算的，比较时注明）。

### J3：有界真实模型对照（冒烟级）

`benchmarks/explore_d2/hf_jump_bounded.py`，读冻结 journal（只读，不 `open_run`），在本机或 180/181 GPU 上跑：
- b05 E2 四个括区：J1 →（`hysteresis` 时）J2a →独立核验；
- b04 对照：J1 应走 `continuous_maximum`，结果应与 v2 的 b04 候选一致（RMSD、ΔE）。

成本依据：b04 / b05 单括区的 `refine_ts_ef` 实测 34–211 forward、6–22 s；延续一侧按 0.2 Å 区间、Δq 0.01 Å 计约 20 点 × 10–30 步 ≈ 200–600 forward，加折半与 Dimer，估每括区 ≤ 3000 forward，按 b05 fp32 实测约 0.03–0.1 s/forward，单括区数分钟。超过这个量级就停下报计划，不算冒烟。
