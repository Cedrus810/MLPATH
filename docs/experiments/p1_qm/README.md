## 协议

与 `../sn2_qm/README.md` 完全相同的两段式：r2SCAN-3c 出几何与频率，
ωB97M-V/def2-TZVPD 在同一几何上补单点。SN2 上这套协议复现文献到 0.4–0.9 kcal，

## 归因：285 meV 是模型的，不是方法的

| | 值 |
| --- | --- |
| A_θ[E_OFF24]：PRRS 在它自己找到的几何上 | **419.1 meV**（`runs/p1_round8`，13/13） |
| E_OFF24 在 DFT 几何上 | **410.4 meV** |
| T[E_QM] | **134.4 meV** |

**两张势能面的鞍点位置几乎重合。** PRRS 在 MACE-OFF24 上找到的四个 TS，
对 DFT TS 的对称感知 RMSD 全部是 **0.0151 Å**（`chemistry.symmetric_rmsd`，
自同构群 2 元 = 两个氧的对换）；内坐标上 r(O···O) 差 0.042 Å、
转移中的 r(O–H) 差 0.020 Å。所以那 285 meV 是**纯能量的，不是几何的**。

**419.1 − 410.4 = 8.7 meV 不是搜索误差界。** 鞍点在正交的 3N−1 维里是极小、
只沿反应坐标是极大，所以在偏离几何上取值可高可低；410.4 < 419.1 只说明
DFT 几何相对 OFF24 鞍点主要偏在反应坐标方向。
**"PRRS 找到的确实是 OFF24 自己的鞍点"的证据是解析 Hessian**（order 1 + 力容差收敛）。

所以：

- **P1 的 13/13 没有被推翻。** 它忠实报告了 MACE-OFF24 的势能面。
- **那张面在这个反应上偏高 3 倍。**
- 虚频同理：MACE-OFF24 的 −3186 cm⁻¹ 对 DFT 的 −909 cm⁻¹，是势垒顶太陡的另一面。
  （本征值意义上是 12 倍，不是 3.5 倍 —— 见 `benchmarks/README.md` 规矩 6 与
  `../sn2_qm/README.md`。）

这是那个拆分第一次真正产出归因，而它证明的方向是**有利于方法的**。

## 与 SN2 合看：为什么默认模型选 POLAR-1

| | 中性有机质子转移（本文档） | 离子 SN2（`../sn2_qm/`） |
| --- | --- | --- |
| MACE-OFF24 | **+276 meV** | 做不了（对电荷逐位无响应） |
| MACE-omol-0-4M | **−1.8 meV** | **+10.5 kcal/mol** |
| **MACE-POLAR-1-M** | **+12.1 meV** | **+2.1 kcal/mol** |

> **两个数不要混。** 上表的 `+276 meV` 是**固定几何**下的模型误差（同一模型在 DFT 几何上的单点 410.4 对 QM 的 134.4）。
> **P1 的势垒是 419 meV，相对 QM 的偏差约 285 meV** —— 那是 PRRS 在**自己找到的几何**上的值。
> 涉及 P1 势垒时用后者。


omol-0 在中性有机上甚至比 POLAR-1 更准，但在离子化学上崩了。
**POLAR-1 是唯一两边都成立的**，这是用户 2026-09-04 定"**从 P4 起统一用 POLAR-1**"的依据。

一个先验被这两组数推翻：**"专用模型在自己的域内胜过通用模型"在这里不成立。**
MACE-OFF 是专门训练在中性有机分子上的，而它在中性有机分子的质子转移上
比两个 83/82 元素的通用模型差一个数量级。

## 能说与不能说

**不能说：**

1. **n = 2 个反应。** 不是基准，是两次测量。
2. **这不是 T[E_m]。** 三个模型只在 DFT 几何上做了单点，
   没有让它们各自优化出自己的鞍点。omol-0 与 POLAR-1 的"自己的 TS 在哪"未知。
   要 ORCA `ExtOpt` 驱动 MLP，尚未做。
3. **P0–P3 的冻结结论不因此改写。** 它们是 MACE-OFF24 上的方法验收，
   这份文档说的是那个模型的能量偏差。两件事，两行。
4. r2SCAN-3c 的 def2-mTZVPP 无弥散；这里是中性体系所以影响小，
   但 SN2 那边靠第二段单点才对上文献。

## T[E_m]：让 ORCA 的优化器在 MACE 面上自己找鞍点

2026-09-04 追加。`scripts/mace_engrad.{sh,py}` + `scripts/mace_server.py`，
经 ORCA 的 `ExtOpt` 接口。这一段补的是那个拆分的**第一行**：

```
A_θ[E_m]  vs  T[E_m]      ← 搜索方法好不好用   ← 这一节
T[E_m]    vs  T[E_QM]     ← 模型准不准         ← 上一节
```

**为什么用 ORCA 而不是 geomeTRIC**：`T[E_m]` 和 `T[E_QM]` 用**同一个 T 算子**，
才能把"不同优化器"从"不同势能面"里摘出去。这两件事正是这个比较要分开的。

### 两个算子彻底不同

| | A_θ[E_m] | T[E_m] |
| --- | --- | --- |
| 方法 | min-mode following：沿最低模反转力，其余极小化 | **RS-P-RFO** |
| 坐标 | 笛卡尔 + 质量加权 + 刚体投影 | **内坐标**（DLC/TRIC） |
| 起点 | 幅度扫描里的瞬时穿越帧 | **独立初猜**：把 H 放到两氧中间，既不是 PRRS 的也不是 DFT 的 |
| 步长 | `min_mode_step_A` + 回溯 | trust radius |

### 结果

对称感知 RMSD（`chemistry.symmetric_rmsd`，自同构群 2 元）：

| | RMSD |
| --- | --- |
| **T[E_m] vs A_θ[E_m]** | **0.0012 Å** |
| T[E_m] vs T[E_QM] | 0.0152 Å |
| A_θ[E_m] vs T[E_QM] | 0.0151 Å |

内坐标：

| | r(O···O) | r(O1–H) | r(O2–H) |
| --- | --- | --- | --- |
| T[E_m] ORCA RS-P-RFO / MACE-OFF24 | 2.3312 | 1.1915 | 1.1906 |
| A_θ[E_m] PRRS min-mode / MACE-OFF24 | 2.3313 | 1.1910 | 1.1912 |
| T[E_QM] DFT r2SCAN-3c | 2.3728 | 1.2107 | 1.2105 |

用 PRRS 自己的解析 Hessian（**同一套刚体投影**，两个几何一视同仁）：

| | 负本征值个数 | λ₁ eV/(Å²·amu) | 波数 |
| --- | --- | --- | --- |
| T[E_m] | **1** | −37.375048 | −3188.0 cm⁻¹ |
| A_θ[E_m] | **1** | −37.411205 | −3189.6 cm⁻¹ |

刚体地板残差 ~10⁻¹⁷；转动本征值与 `ω²(g·x⊥)` 的期望对到 1e-17，
即 `HANDOFF.md` §4 那个梯度扣除机制在这两个几何上都成立。

### 这说明什么

**两个完全不同的算法、不同坐标系、独立起点，落在同一个鞍点上，差 0.0012 Å、
虚频差 1.6 cm⁻¹（3189 分之 1.6，0.05%）。**

而它们各自离 DFT 鞍点 0.0151 Å —— **彼此的一致程度是各自与 DFT 差距的 12 倍**。
这正是那个拆分要看到的形状：

- **第一行（方法）：`A_θ[E_m] ≈ T[E_m]`。** PRRS 的 min-mode following
  在这个体系上找到的就是这张面上的那个鞍点，换一个独立算子验证过了。
- **第二行（模型）：`T[E_m]` 与 `T[E_QM]` 差 0.015 Å、势垒 285 meV、
  虚频 −3188 对 −909。** 分歧全在这一行。

−3189.6 正是 P1 冻结记录里那四个虚频的第一个（`-3189.6 / -3188.2 / -3187.3 / -3186.7`）。

### 工程记录

- **ExtOpt 下 `Freq` 与 `NumFreq` 都失败**（`ERROR (SHARK): Failed to read input file`），
  因为频率任务要走属性积分，而外部程序没有波函数。
  几何优化本身没问题（`Opt` 14 步 HURRAY，`OptTS` 13 步 HURRAY）。
  **所以 Hessian 用 PRRS 自己的解析版本 —— 这反而更好**：比 ORCA 的数值 Hessian 准，
  而且和 P1 冻结结果用的是同一套投影。
- **100% 的时间花在重载模型**：ORCA 自己报
  `External energy and gradient ... 293.791 sec (100.0%)`，
  `Geometry relaxation ... 0.041 sec (0.0%)`。
  9 原子的 MACE 求值是毫秒级，checkpoint 加载 + CUDA 初始化约 5 s/次。
  `scripts/mace_server.py` 是为此写的常驻服务端（OPI 的 `OpiServer` 管进程生命周期），
  客户端在 `PRRS_ENGRAD_SERVER` 设置时走它。**本轮结果是在无服务端下取得的**，
  服务端已验证可 ping 通但尚未用于生产运行。
- ExtOpt 文件的读写走 `opi.external_methods.interface.ExtoptInterface`，
  不是手搓格式。单位契约验证过：能量与直接调 ASE 差 3.3e-11 Ha，
  梯度范数逐位相同（0.0248121955）。

## IRC：双向路径与端点核验（2026-09-04）

**IRC 在本项目里第一次真正执行。** `PRRS_STATUS.md` §3.7 要求存在性与生效由执行证实，
在此之前只有文档。ORCA 6.1.1 on kasuga02，`! r2SCAN-3c TightSCF IRC`，
`InitHess calc_anfreq`，32 核，**21 分 5 秒**，31 个路径点，`THE IRC HAS CONVERGED`。

两侧端点各自 `OPT FREQ`：**虚频 0 / 0**，都是真极小。

| | r(O1–H) | r(O2–H) | r(O···O) | RMSD→min | chemical_key |
| --- | --- | --- | --- | --- | --- |
| r2SCAN-3c 极小 | 1.6080 | 1.0150 | 2.5356 | 0.0000 | `420aa40908c8fe43` |
| IRC 正向端点 | 1.6074 | 1.0150 | 2.5352 | **0.0004** | `420aa40908c8fe43` |
| IRC 反向端点 | 1.0150 | 1.6074 | 2.5352 | 0.1862 | `420aa40908c8fe43` |

**正向端点就是那个极小。反向端点是它的精确镜像** —— 内坐标的两个数原样对调。

反向那个 0.1862 Å **不是分歧**：`symmetric_rmsd` 用的自同构群是在极小的图上算的，
而极小处的 O–H 键打破了两个氧的等价，所以镜像映不过去。内坐标是这里的证据。

### 通道确认不靠 key —— 退化反应两端 key 本来就相同

```
broken = [[0, 5]]     formed = [[4, 5]]     方向商 True
event_key = a04410b76e16b117
```

原子 0 与 4 是两个氧，5 是转移的质子。**质子从 O0 移到了 O4。**

**`a04410b76e16b117` 正是 P1 冻结验收记录的 event key**（`HANDOFF.md` §3）。
所以：**QM 的 IRC 独立复现了 PRRS 在 MACE-OFF24 上找到的反应事件身份。**
两张势能面的势垒差 3 倍（419 对 134 meV），事件身份逐字一致 ——
这正是 §5 那条"scope 内的量稳健，不稳健的恰好是声明不负责的部分"的又一次实测。
