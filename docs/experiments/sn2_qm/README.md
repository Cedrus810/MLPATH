| | 方法 | 耗时 |

| 能量单点 | ωB97M-V / def2-TZVPD / DEFGRID2，在上面的几何上 | ~15 s |

**r2SCAN-3c 单独用会把中心势垒错 11 kcal/mol**（−7.99 对文献 +3.00）——
meta-GGA 在 SN2 上的自相互作用误差。但它的**几何是好的**：
单点搭上去之后复现文献到 0.4–0.9 kcal。

def2-mTZVPP 没有弥散函数而这是阴离子体系，所以第二段用带弥散的 def2-TZVPD。
文献值就是检验这一点的外部刻度。

## 驻点性是**测量**的，不是论证的

这一点是与 `runs/sn2_probe.json` 的关键区别。那个探针的 D3h 点由两参数对称子空间内
的能量极小得到，驻点性从对称性**论证**，残余梯度从未测量（见 `benchmarks/README.md` 规矩 6）。

这里：

| | 收敛 | RMS grad | MAX grad | 虚频 |
| --- | --- | --- | --- | --- |
| CH₃Cl | HURRAY | — | — | **0** |
| 离子-偶极复合物 | HURRAY | 2.47e-05 | 3.96e-05 | **0** |
| D3h 鞍点 | HURRAY | 1.14e-05 | 2.13e-05 | **恰好 1**，−314.42 cm⁻¹ |

鞍点几何是标准 D3h，r(C–Cl) = **2.3645 Å** 两侧相等；次低模 +195.87 cm⁻¹。
**这一组数满足报 cm⁻¹ 的前提。**

## 能说与不能说

**能说：** 在这一个反应的这三个几何上，POLAR-1 的中心势垒误差 2.1 kcal/mol，
omol-0 是 10.5。两者的复合物结合能都在 1 kcal 以内。
2.1 kcal 落在 ACS Catal. 2026, 16, 8053 报告 UMA-S 对 ωB97M-V 的 1.7–2.8 kcal 同一带。

**不能说：**

1. **n = 1 个反应、3 个点。** 这不是基准，是一次测量。
2. **这不是 T[E_m]。** 它只说"模型在 DFT 几何上的能量"，不说"模型自己优化出的鞍点在哪"。
   后者要 ORCA `ExtOpt` 驱动 MACE，还没做。
   参考：omol-0 自己的 TS 在 r = 2.4236 给 +13.24，这里 +13.85 —— 接近，
   所以它的误差**不是**几何造成的。POLAR-1 自己的 TS 在 2.2815 给 +4.53，这里 +5.48。
3. **这不评方法。** `A_θ` 一步都没参与，PRRS 在这份文档里没有出现。
4. 一个意外：**omol-0 训练在 OMol25 上，而 OMol25 正是 ωB97M-V 的数据集**，
   它却在这个反应的势垒上错 10 kcal。"训练在同一个泛函的数据上"不保证具体反应上准。
