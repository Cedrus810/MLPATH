## 为什么问这个

`PRRS_STATUS §2.6c` 的四项无参考诊断只在乙醇的极小点和鞍点上做过，结论明写着
「这只是**一个体系的两个几何**，成键/断键区（缺口 8）未测，不可外推」。
P0–P3 四个基准全是分子内质子转移，碎片数从头到尾是 1 —— **PRRS 至今没有在断键区
确认过任何东西**。上逆 DA 之前先花几分钟问一句：那个区域的势能面还能用吗。

**这不是补上缺口 8。** 它是一条线上的一次检查，和 §2.6c 的局限完全同类。

## 体系

环己烯 C6H10（ETKDG + MMFF 起手，MACE 松弛到 `fmax = 9.4e-4`，
$E = -6389.348502$ eV）。图上识别出的环序为 `[0,1,2,3,4,5]`，C0=C1 是双键
（1.3271 Å），逆 DA 断的两条 σ 键是 **C2–C3 与 C4–C5**，都是 1.5260 Å
（对称，符合预期）。产物侧是丁二烯（C5-C0=C1-C2）+ 乙烯（C3=C4）。

## 扫描：对称约束松弛，1.55 → 3.20 Å

两条断裂键同步拉伸到同一 $d$，`FixInternals` 固定，其余全松弛，逐点接续。

```
d (A)   1.55    1.70    1.85    1.95    2.00    2.04  |  2.05    2.20    2.60    3.20
E-E0    +14.3  +596.9 +1962.3 +3783.2 +4856.7 +5512.5 | +4933.4 +4395.7 +2877.3 +2067.9   meV
edges     16      16      14      14      14      14  |   14      14      14      14
```

**两件事必须分开说。**

### 1. 那个 −579 meV 的跳是扫描的分支切换，不是模型的粗糙

1.90 → 2.20 Å 用 0.01 Å 重扫，二阶差分（meV）：

```
+8.5 +7.6 +6.4 +4.8 +3.0 +0.7 -1.9 -5.0 -8.6 -12.6 -16.3 -19.4 -22.9  -712.1  +563.0  -4.2 -3.7 ...
                                                                       ^^^^^^^^^^^^^^^
                                                                       d = 2.04 -> 2.05
```

除这一处外整条曲线光滑。单步 $\Delta E = -579.1$ meV 出现在 2.04 → 2.05。

**判定它是哪一种，只需要一条刚性线。** 取 2.04 与 2.05 两个**松弛后**的几何，在
笛卡尔空间线性插值 101 点，不做任何松弛 —— 这条线上的任何折角只能是势能面的：

```
E 沿刚性线   +4933.4 ... +7533.6 meV   （中间隆起 2.6 eV）
|二阶差分|   最大 4.7733 meV，平均 2.8791 meV，最差点 t = 0.48
```

两个几何之间隔着一座 **2.6 eV 的山**，也就是说它们在正交的 $3N-1$ 维里根本不相邻 ——
约束松弛在 2.04 → 2.05 之间换了分支。而那条线上的能量**光滑**：2.6 eV 的跨度上
二阶差分最大 4.8 meV，相对量 $2\times10^{-3}$。

**所以：在这条穿过断键区的线上，MACE-OFF24 是光滑的。** 这是本探针要的答案。

### 2. 那个 +4.9 eV 不是逆 DA 的势垒，一次都不要这样引用

对称同步约束是一个**被规定的**反应坐标，不是这个势能面自己的。它会分支切换（上面刚
证明了），而且强制两条键等长把体系按在一个非最低路径上。实验上环己烯逆 DA 的
$E_a \approx 2.9$ eV；这里的 4.9 eV 高出近一倍，差额属于坐标，不属于模型。

**这恰好是 PRRS 存在的理由**：找 TS 不该靠人规定坐标，该靠 min-mode following。
所以这条曲线只用来回答"平滑吗"，绝不用来回答"势垒多少"。

### 3. 顺带的一条：身份层在 1.85 Å 就判断键断了

`edges` 在 $d = 1.85$ 从 16 掉到 14，即共价半径判据在这里认定两条 C–C 已断 ——
比这条坐标上的最高点低 3.5 eV。这不是问题，但**逆 DA 上路时要知道**：碎片数变化的
事件会在能量还在爬升的时候就被记到，`classify_transition` 看到的"断键"位置和能量上的
过渡态位置不是同一处。P1–P3 的质子转移里没有这个现象，因为那里碎片数从不变。

## 同一探针在 MACE-POLAR-1-M 上（2026-09-04，模型切换之后补做）

用户已把 P0–P3 冻结在 OFF24、**P4 起统一 POLAR-1**。平滑性是势能面的属性、不是反应的
属性，**不跨模型转移**，所以上面那个 go/no-go 不覆盖逆 DA 真正会跑的模型。脚本
`rda_polar1.py`，产物 `rda_polar1.json`，端点由 POLAR-1 自己松弛
（$E = -6383.912369$ eV，`fmax = 9.1e-4`；拿 OFF24 的几何喂它会测成几何迁移，P3 §5）。

POLAR-1 更该查而不是更能放过：P3 §3.13 实测它的刚体地板残差 `2.2e-06` 对 OFF24 的
`3.2e-16`，差十个数量级，与它的 float32 权重一致。

```
d (A)   1.55    1.70    1.85    2.00  |  2.10    2.20    2.25    2.40
E-E0    +13.9  +590.2 +1628.6 +2806.4 | +2846.9 +3012.3 +3011.8 +2857.2   meV
edges     16      16      14      14  |   14      14      14      14
```

**结论与 OFF24 同型**：曲线上有一处 −672.9 meV 的单步台阶（$d = 2.09 \to 2.10$），
除它之外 |二阶差分| ≤ 4.4 meV；两个相邻松弛几何之间的刚性线中间隆起 **3.1 eV**，
而线上 |二阶差分| 最大 6.50 meV、平均 3.77 meV。**台阶是约束松弛的分支切换，
势能面本身光滑。** 身份层同样在 $d = 1.85$ 判定两条 C–C 断开（16 → 14 条边）。

### 但两个模型在这个区域差 2.5 eV，这才是真正的新信息

同一条（被规定的、不该当势垒引用的）坐标上，最高点：

| | 峰值 E−E₀ | 位置 |
| --- | --- | --- |
| MACE-OFF24 | **+5512 meV** | $d = 2.04$ |
| MACE-POLAR-1-M | **+3012 meV** | $d = 2.20$ |

**2.5 eV 的跨模型分歧**，比 P3 §3.12 在质子转移 TS 上看到的 3.7 倍（+316 / +85 / +96 meV，
跨度 0.23 eV）大一个数量级。**这不能读成"POLAR-1 更准"** —— 环己烯逆 DA 的实验
$E_a \approx 2.9$ eV 与 POLAR-1 的 3.01 eV 接近，但这条坐标是被规定的、还发生了分支
切换，在一个错的坐标上和实验对上可以是巧合，不构成证据。

能读出来的只有一条，而它足够重要：**断键区的跨模型分歧远大于质子转移区，
而那正是从来没有任何外部参照的区域。** §2.6c 那句"无参考诊断只能查不一致、不能查不准"
在这里从一句方法学告诫变成了一个具体的、量到 2.5 eV 的缺口。

### 下一步已经排好

183 上有校准过的 ORCA（r2SCAN-3c 出几何+频率 → ωB97M-V/def2-TZVPD 单点，气相 SN2 上
复现文献到 0.4–0.9 kcal），所以尺子第一次存在。`rda_refs_build.py` 冻结四个几何
（$d = 1.55$ 对照 / 1.90 / 2.05 / 2.20，取自 POLAR-1 的松弛行走）并在**同一批几何上**
读两个模型各自的解析 Hessian 谱，产物 `rda_refs/`。ORCA 在同样这四个几何上算 r2SCAN-3c
解析 Hessian（不再优化），三者的谱并排比，才是第一次真正测断键区的**曲率准不准**。

按 §2.6g，这四个几何都不是驻点，所以转动的三个本征值带梯度项、不是模型误差，只记录不比较。

## 结论

| 问题 | 答案 |
| --- | --- |
| MACE-OFF24 在 C–C 断键区会不会发疯 | **不会**。沿刚性线 \|二阶差分\| 最大 4.77 meV |
| MACE-POLAR-1-M 呢（P4 起用的那个） | **也不会**。最大 6.50 meV，尽管它的刚体地板差十个量级 |
| 那两个台阶（−579 / −673 meV）是模型问题吗 | **不是**，两个模型上都是约束松弛的分支切换 |
| 可以上逆 Diels–Alder 吗 | **可以**，两个模型都过 |
| 4.9 / 3.0 eV 是势垒吗 | **不是**，是被规定坐标的产物；实验 $E_a \approx 2.9$ eV |
| 缺口 8 补上了吗 | **没有**，但第一次被量到了：断键区跨模型分歧 **2.5 eV**，比质子转移区大一个数量级 |
| 曲率在那里准吗 | **未知**。自洽 ≠ 准确；ORCA 参照已排（`rda_refs/`） |

**没有回答的**：二阶导在这个区域**准不准**。和 §2.6c 一样，无参考诊断只能查不一致、
不能查不准，而这里连 D1–D5 那四项都还没做 —— 只做了能量的光滑性。如果逆 DA 真的上，
在它的 TS 上重跑一遍 §2.6c 的 D1–D5 才是补缺口 8 的那一步。
