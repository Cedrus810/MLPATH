## 用户决定（2026-11-02，原文）

> 具体这样定：
> - 粗松弛先取 2e-3；两侧反力同号、且各自都超过实测的符号分辨界线，才允许提前收括区。其余继续到 1e-3。
> - 保留几何、约束残差和双侧反力差检查。 粗阶段不通过就继续精松弛；暂不采用文档里“同号即可取消反力差门”的部分。同号本身不足以证明两侧在同一条支上。
> - 0.003 + 3σ 先作为待验证公式。 同点重复松弛测到的是随机抖动，还要比较粗、精松弛的反力偏差；重复性好也可能存在一致偏差。
> - 验收用冻结括区的新旧同机对照。 同时检查失败意图和原本成功的对照，跑完整个后续二分，统计救回数量、后续卡点、候选一致性和计算成本。
> 候选的完整力、横向力判据保持现行值。若剩下的失败仍集中在近根松弛，再做 O5 的优化器对照。

## 1. 规则（按上面的决定）

每个二分中点：

1. 两侧（from_left / from_right）先各自松弛到粗阈值 τ_c = 2e-3。
2. 粗阶段**全部**满足下列条件时，按符号收括区，不再精松弛：
   - 几何：两侧对齐 RMSD ≤ `branch_rmsd_A`、步间位移 ≤ `branch_step_A`（与现行相同）；
   - 约束残差合格（`_relax` 内已检查）；
   - 双侧反力差 ≤ `branch_force_limit()`（与现行相同，不取消）；
   - 两侧反力同号，且各自 |RF| > 符号分辨界线 B；
   - 两侧都不满足 `stationary`。若有一侧已满足候选判据，就走现行路径，使候选判定与现行完全一致。
3. 任一条不满足：两侧从粗阶段的结构与曲率出发，继续松弛到 1e-3，之后完全按现行逻辑处理（分支检查、候选、括区、`force_resolution_unresolved`）。
4. 候选判据（完整力 0.01、横向力 0.003、约束残差）不变。

开关：`EFSettings.midpoint_coarse_transverse_fmax_eV_A` 与 `midpoint_sign_bound_eV_A`，两个都给才启用，都不给就是现行行为。启用时 provenance 写 `HF-EF-bracket-v4`，不启用仍写 `HF-EF-bracket-v3`；旧运行不追认。D2（`HFSettings`、manifest）先不接，等验收通过再定。

## 2. 界线 B：待验证公式 B = 0.003 + 3σ_c

先测两样：

- **随机抖动 σ_c**：同一中点、同一 q，对起始帧加 0.01 Å 随机扰动后重复松弛（8 次）。取第一帧横向力 ≤ 2e-3 时的反力，算标准差。
- **粗、精一致偏差**：在同一次松弛里，先记下第一帧 ≤ 2e-3 时的反力，再继续松弛到 ≤ 1e-3，记下这时的反力。看两者之差（带符号）的均值和分布，以及它与 RF 符号的关系。还要用 journal 中已有的 197 个收敛中点离线算同一个量。

判定公式要不要修改，比较的是一致偏差和 3σ_c：如果一致偏差与 3σ_c 同量级或更大，B 就要把偏差也算进去，并报告用户。

样本：收敛中点按 |RF(1e-3)| 分层（< 0.01、0.01–0.05、> 0.05），每层 8 个；失败中点每个意图 1 个（22 个）。

**结果（11-02）**：σ_c 全体中位 0.0040、p90 0.0073；粗、精偏差均值 −0.0006、标准差 0.0047，未见一致偏差。用户 11-02「可以」：**B = 0.025**（= 0.003 + 3 × p90 σ_c）。数字见 DONE_LOG 11-02。

## 3. 代码与测试（CPU，解析台）

- `ts_ef.py`：上面的规则与开关；设置校验（两个开关要么都给，要么都不给，粗阈值 > 精阈值）。
- 测试：
  - 不启用时，行为与现有全部测试相同；
  - 启用但 B 很大（永不提前收）时，状态、候选、括区与不启用时相同，只多出粗阶段帧与费用；
  - 远离根的中点提前收括区，候选与现行一致，费用更低；
  - 粗阶段反力差超门、几何超限、一侧已满足候选判据时，都转入精松弛，不报分歧；
  - 精松弛失败仍为 `transverse_not_converged`。

## 4. 验收：冻结括区新旧同机对照（GPU，正式运行前先报计划表）

- 输入：22 个失败意图（各取最后一次失败的那块）加对照项（原本出候选或原本中点收敛的项，按种子抽）的冻结 HS 括区。
- 新旧两版（不启用 / 启用）在同一台机器上各跑一次完整 HS（延续 + 全部后续二分）。
- 统计：救回数量；后续卡点（在第几个中点、|RF| 多少）；候选一致性（对称 RMSD、能量差，与旧候选及对照组比较）；forward 成本。
- 若剩下的失败仍集中在近根松弛，再做 O5 优化器对照（另立计划）。

## 5. 验收结果（2026-11-02，183）

对照 15 项（不是 22 项：可用的不同意图只有 15 个）新旧候选一致（ΔE ≤ 1 个 fp32 量子，RMSD ≤ 0.0017 Å）；失败 22 项救回 2 项（能量与新 E2 鞍点同段，身份与连接未查）；16 项仍卡，卡点后移到 |RF| < B 的近根中点的精阶段；成本持平（18.2k / 18.5k forward）。2 次粗阶段被反力差门（冻结 σ 0.0025 → 0.0106）挡下，粗阶段实测 σ_c 更大，只报告未改。下一步按用户决定做 O5 优化器对照（未开始）。数字见 DONE_LOG 11-02。
