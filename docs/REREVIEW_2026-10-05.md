## P1：PRRS → PARS 丢失 charge/spin，错误电子态也能返回 CI 成功

位置：`pars/src/pars/adapters/prrs_run.py:136`、`pars/src/pars/cli.py:191`、
`pars/src/pars/refinement/ase_neb.py:537`。

导入只保留元素、坐标和能量，没有把逐帧 `atoms.info["charge"]` / `["spin"]`
或 manifest 的 `total_charge` / `multiplicity` 放入电子态契约。
代表文件与 NEB 模板又重新构造 `Atoms`，仍不设置 charge/spin。
即便手工给代表 extxyz 加电子态字段，当前后端模板也不会继承它们。
PARS 保留 calculator/model 指纹不能补回这两个依赖构型的 PES 输入。

完整 `select → refine` 复现：源轨迹、端点及 manifest 均声明 charge=-1、spin=3。
解析 calculator 读取结构电荷，势能为
`(1+abs(charge)) * [0.25*x²*(x-2)² + 0.5*(y²+z²)]`，缺电荷时默认 0。
带电势垒应为 0.5 eV；实际所有 NEB/Hessian/下降计算收到的 charge/spin 均缺失，
返回 `ci_neb_converged`、约 0.249999980 eV 和 `connectivity_check.status=matched`。
这证实同一个 calculator 类和权重下，电子态输入丢失仍能给出成功标签。

项目内 b04 calculator 明确由结构提供电荷；安装的 MACE calculator 也默认
从 `info["charge"]` / `["spin"]` 读取 total_charge/total_spin。
本次没有运行真实 POLAR-1，不能据此宣布 b04 历史结果受到污染。

验收：从源 manifest 和每帧/端点交叉核对电子态，经 trace/candidate、代表文件、
seed reader、后端所有构型与输出完整传递；冲突应在计算前拒绝。
加入带电/非单重态全 CLI 回归，并独立核对已知势垒。
不得依赖任意 factory 自行补盖电子态来关闭通用交接缺口。

## P1：Hessian 力差分采样绕过不确定度拒绝门

位置：`pars/src/pars/refinement/ase_neb.py:138-155`。

`_curvature` 对每个坐标的正负扰动只读取 forces，并仅校验 Hessian 有限性；
不检查这些计算的 `force_uncertainty_eV_A`。
后续 band 与下降检查只覆盖各自的构型，不能补验已被覆盖的 calculator results。
这影响端点、独立盆地见证、攀爬像点和下降落点的曲率验收。

复现势 `E=0.25*x²*(x-2)²+0.5*(y²+z²)`，band 与下降都在 x 轴。
轴上不确定度为 0.005 eV/Å；仅横向 Hessian 扰动处设置 NaN 或 1000 eV/Å。
拒绝阈值设 0.01 eV/Å。两次各有 28 个异常曲率采样，但均返回
`ci_neb_converged`、0.25 eV、连接 `matched`，记录最大不确定度仍为 0.005，
band coverage 为 `complete`。
本反例没有故意修改 forces，因此没有证明错误鞍点阶数；它证明接受所依赖的
曲率证据使用了按配置应拒绝、或数值无效的不确定度样本。

验收：在每次正负位移 force evaluation 当场检查有限、非负、覆盖与阈值，
保留端点/鞍点/下降落点各自的采样诊断。NaN/负值拒绝；启用门时缺测或超阈值
不得继续交付曲率成功与反应势垒；异常恢复坐标并保留失败证据。

## P2：分类过滤先于权威结果核验，冲突记录能静默漏掉路径

位置：`pars/src/pars/paths/ingest.py:28-31`；
对比 `pars/src/pars/adapters/prrs_run.py::_trial_record`。

`ingest_run` 先用 attempts.jsonl 决定是否接纳，只有被接纳的记录才进入
`load_trace`，触发 result/ledger 一致性检查。
将某个试验的账本 classification 从 reactive 改为 elastic，保持 result.json
为 completed/reactive：导入正常完成，遗漏该试验；显式 load 同一试验才报错。
因此上一轮分类一致性修复没有覆盖过滤路径，并可能把损坏工件误报为正常跳过。

验收：读取权威结果并检查轻量身份/分类字段后再过滤；无需读取所有被跳过的轨迹。
skipped 统计与未导入通道成员清单使用同一已核验的记录视图。
加入双方向冲突与 status 冲突回归，仍允许一致的 elastic/unconfirmed 正常跳过。
